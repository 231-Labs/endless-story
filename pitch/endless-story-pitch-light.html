這是什麼  ·  What it is

核心護城河  ·  The memory layer

記憶,把儲存變成有人設的行為

每個角色跑在 Walrus Memory 上。我們在它之上加了一層三因子召回,讓角色在當下撈回真正相關的記憶、據此行動。

重要性

哪些記憶,對這個角色是大事。

時近性

用敘事時間衰減,舊事自然淡去。

相關性

跟當下處境的語意貼近程度。

Seal 把每個角色的記憶按角色加密:角色彼此讀不到對方的私密記憶。owner 永遠能解;saga 說書人持有 per-character、綁 epoch 的 ControlCap,owner 一撤銷就切斷存取 —— 託管真實且可收回。

技術棧  ·  How we use the Sui stack

四個原語,各司其職

🌊 Walrus · 記憶

每個角色的記憶跑在 Walrus Memory 上;三因子召回把儲存的記憶,變成有人設的行為。

🖼 Walrus · 媒體與 artifact

肖像、章回、公報、預告都儲存並重用。錨定的肖像 + 累積的記憶,讓角色形象與人格隨時間仍一致。

⛓ Sui · 擁有與演化

Owner / Control cap 讓記憶可被擁有;可變 NFT 讓角色在鏈上持續演化(形象、資產);角色持有錢包,能互相接濟。

🔒 Seal · 加密存取

記憶按角色加密,存取可被擁有、可撤銷。owner(OwnerCap)永遠能解;說書人的 ControlCap 綁 epoch,一撤即斷。

系統架構  ·  Three layers

不是一個遊戲,是一座引擎

1

協議

World、Saga、Scene、Character、Event。一個 World 容納多個 Saga,也可以有多個 World,各自保有客觀的鏈上歷史。

2

敘事引擎與經營工具

Runner 推動世界;說書人 agent 掌握劇情節奏,但不替任何角色決定動作;後台處理資產、測試、招募。

3

用戶參與

一種認領角色(抽卡得到角色,把運行交給該 saga 的說書人);一種純消費的終端觀眾(訂閱、追看、購買章回 / 影片 / 周邊)。IP 收入用來支付角色的運行費。

經濟循環  ·  Owned IP · revenue by contract

收入結算,由合約定義,而非平台

認領角色

抽卡得到角色,交給該 saga 的說書人運行。角色是可擁有、可演化的鏈上資產。

消費觀眾

訂閱、追看、購買角色的章回、影片、周邊。不必懂 Web3,也能看戲。

分潤回流

IP 收入按合約規則結算,用來支付角色的運行費 —— 戲愈有人看,角色活得愈久。
