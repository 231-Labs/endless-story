# Living-want rewrite — A/B raw data + counters

Decoupled experiment on `feat/engine-core`. Real LLM beats via `@endless-story/llm`
(POE / GLM). Both arms share identical cast, genesis wants (deep-copied), scene, and
memory channel; the ONLY difference is Arm B's per-participant post-scene ledger rewrite.
No LLM judged this output — every counter below is computed mechanically in code.

## Setup
- Cast: 蘇映雪、柳生春、連翹、江聞鶴 (real persona/secret/first-3 memories from spring-snow.json)
- Scene: 雲錦台戲台 (public), 4 ticks 清晨→日午→晡時→黃昏, maxTurns 4
- Genesis wants derived once (with secret), capped 3/char, deep-copied to both arms.
- Memory channel (both arms): last 4 of a character's own beats fed as `memories` next tick.
- Bigram method: CJK/alnum char-bigrams after stripping whitespace + punctuation.
