序章

《白蛇傳》大會串的滿堂彩還沒散，霞飛路新起的戲園便下了帖子，點名要打對台。

新園子背靠洋商與大碼頭的注資，專挖角兒挑大樑，開出的包銀硬生生是春雪社的兩倍。

春雪社戲箱重啟雖贏了名聲，可班底底子薄，連月趕場早是強弩之末。

十里洋場看戲的爺圖個新鮮，這對台戲一開，票房便是真金白銀的生死狀。

對台的戲碼就釘在季末那日，這口氣爭不回來，春雪社的招牌便得讓出霞飛路。

  3. 蘇映雪二樓書寓 → 練功房

    要找 柳生春：把她拉到一旁，接上回那半截話，拿死釘的硬骨頭叫她應承：往後更險的浪裡不許只顧豁命，我這樁子既扛天，她便得惜自家的身子。
  5. 連翹戲班大通鋪 → 練功房
    日午正该吊嗓走位，但我得先拿准时辰。昨夜那七步半的桩钉死了，今儿这排练就是头一遭亮这硬骨头。得去练功房把脚底的根踩实，顺眼风看看映雪这花旦的劲头散没散，我连翘的枪花得替咱俩把台心震出嗡声来。
    要找 苏映雪：走位对身段，借递眼风探她脚底那劲还在不在，把咱俩踩实的桩再碾一遍，让她知道我连翹今儿个要在排练场上替咱俩把名震出去。
  6. 白韻秋白公館繡樓 → 霞飛路商店街
    昨夜沈雪笙按死停錶，說不拿刻度量我寸心，這檻外討來的實帳落定了，我心裡穩當。現下是日午，本就該去霞飛路逛洋貨打發時辰。既是穩了，就不必急著尋她，先去商店街挑幾塊好料子、吃點東西，心定步子才穩，往後不跑針的光陰得慢慢走。
  7. 沈雪笙沈宅小樓 → 後台妝閣
    日午該去後台妝閣坐鎮看帳看人了。白韻秋認了共本，那停擺的懷錶和共本的擔子壓在我心口，她撐不撐得住，得見了人再說。柳生春那把扇太像我，也得留神。先看時辰，動身去妝閣。

日午的日影斜斜打進練功房，把地當了台。柳生春合著蘇映雪的身段踏上半步，指尖將出未出地虛虛一引，由著她攥著的手腕將氣口穩穩託上去，把那句「姐姐」唱得低迴又清亮。蘇映雪就著她引的勢將腕子一翻，指尖不露痕跡地壓在她脈門上替她收住尾音，順手替她攏了攏鬢邊一綹散髮。

脈門上那點溫熱未褪，柳生春任由她指尖壓著、替自己攏髮，只微微偏過臉讓開那半寸過近的氣息，垂眸輕聲道：「師姐，再走一遍。」蘇映雪壓著脈門的手指未收，只順勢往下滑了半寸搭在她腕骨上，替她把袖口鬆了的扣子壓緊：「急什麼，這遍氣口不比你從前穩？」那腕骨上的指尖依舊搭著，倒似比這戲裡的引與託，更添了幾分分寸的較量。

    我金鳳此刻還賴在柳生春的後台小廂房裡，晡時本該回會樂里，可她方才貼嚴了我還說分不清，這筆情分帳哪能就這麼算了？我偏要等她回來，連本帶利討她一句實話，認命還是認我，總得有個交代！
    要找 柳生春：守在她小廂房裡等她回來，逼她當面認了這十年的情分帳，說清楚是認命還是認我
  2. 江聞鶴練功房 → 雲錦台戲台
    晡時本該去雲錦台排戲，但柳生春就在眼前練功，我心底那樁事刻不容緩——她踩實我樁子借力，往後定只顧豁命。今夜台心我得叫她收住那狠，這口氣不壓下，排戲也穩不住。我得趁現在拿話釘死她。
    要找 柳生春：趁練功房人雜，湊近她壓低聲音，實打實叫住她：她既借我這硬骨頭托腰往上走，往後更險的浪裡便不許只顧豁命不顧自家，今夜上台她若再拿命換那口氣，我這樁子便算白釘了。
  3. 連翹練功房 → 雲錦台戲台
    班主叫了排戲，我該去雲錦台對戲，可今夜這台心得是我連翹自己的名，不能只記那倆人的樁。我先問準時辰，再看眼映雪，把那沒散的勁在心裡過一遍，最後動身去戲台，腳底碾實了給上海看看這硬骨頭。
    要找 蘇映雪：拿眼神對上，心裡過一遍那七步半的樁，不接水袖只遞勁，把倆人釘死的底踩實就上戲台。
  4. 白韻秋霞飛路商店街 → 後台妝閣
    我此刻正在霞飛路閒逛，心裡卻滿是昨兒那停錶不跑針的情分。注既贏了，沈雪笙既認了不拿刻度量我，這實帳落定，我得去尋生春，親口將這不退場的篤定遞到她手心裡，看看她那叩落實的笑。
    要找 柳生春：我來尋她，不為別的，就為將沈先生那停錶不量寸心的篤定告訴她——這檻外情分既叩實了，往後每一步都是不跑針的光陰，我只認準她那個不設防的笑。
  5. 沈雪笙後台妝閣
    晡時該坐鎮後台理帳盯戲，可韻秋正立在這妝閣裡。她認了共本，把停擺的懷錶推回案前，踏進了這同台的局，可這擔子她撐不撐得全，反倒成了我攏在袖裡不敢替她挑明的懸絲。她既在，我總得探一探這步子實不實，看她到底是認了真光陰，還是只憑一腔意氣。
    要找 白韻秋：看著她，不提共本的帳，只問她既踏進了春雪社的門，往後這實打實的光陰打算怎麼走。看她眼神穩不穩，這擔子她到底明不明白。
  6. 蘇映雪練功房 → 雲錦台戲台
    我肚裡空了，可這會子全顧不上吃。她就在練功房，我剛扣住她腕骨的手還收不住，那八年的燙實打實烙在心口，殼子既碎了，我穩穩兜著她便是。營生該去雲錦台排戲，我便同她一塊去，路上定要同她把話挑明——往後只管同她把這驚夢唱穿，再不許她躲。
    要找 柳生春：攥緊她的手，同她把話說實：「方才那燙我接了，殼子也碎了。往後這戲只管同你唱穿，你離不得我，我也再不許你躲。」
  7. 柳生春練功房 → 雲錦台戲台
    肚裡空得發慌，身上乏得提不動氣，可班主催排戲，師姐又在跟前，這口真氣不能塌。我得先認準時辰，趕緊去前街攤子塞口熱食墊墊底，再回雲錦台對戲，硬撐也得把架子撐住了。

腕骨上那半寸的分寸還未較出個高低，那指尖已順著後腰的曲線滑了去，不偏不倚，尋著腰窩那顆小痣慢慢畫了半圈。金鳳貼嚴了她耳根，笑裡兜著三分暖風：「你身子倒比嘴老實——十年欠的情，這會兒正填著呢，哪有清的頭？說說，到底是認命，還是認我？」柳生春反手攥住那隻作怪的手腕，偏頭抵開那纏人的氣息，嗓音發啞：「哪樣不是認？填不平的冤孽債，你還要連我底下的真氣一并討了去才甘心麼？」金鳳便順著她攥腕的力道往前胸膛一壓，下巴擱上她肩頭，鼻尖恰恰蹭著頸側那片薄汗，低低嘆了口氣：「我討你一口真氣作甚，你人還在我懷裡貼著，這情分便翻不見底。」

那廂雲錦台板上，另有一番較量正踩在節骨眼。連翹腳尖碾實台板，眼神直直釘過去，手背繃勁不遞水袖只往前一送。蘇映雪目光一寸不讓地迎上去，指尖就著她往前送的勢，精準搭上她繃勁的手腕，扣實。連翹手腕反轉，指尖扣回她的脈門，力道穩穩壓住，嘴角一挑：「映雪，這場子我倆踩實了，可等門一開，外頭認的是誰，得看我腳底下那桿槍叫不叫得響。」蘇映雪指尖順她脈門的力道往上一滑，反手將她五指一併扣攏在掌心，拇指死死抵住她虎口：「外頭認誰，看你腳底下那桿槍；這台上的主，是你我倆一塊釘死的。」

前台水袖交鋒，後台妝閣裡卻靜得只有一聲輕響。沈雪笙將案上那停擺的懷錶往白韻秋面前輕輕一推，目光不避：「這實打實的光陰，你打算怎麼走？」白韻秋指尖輕按那停擺的懷錶，朝她微微仰臉：「既沒了刻度，往後這步子，我就照著我自家的意思走。」沈雪笙將那停擺的懷錶一把攏回袖中，掌心按住錶蓋直視她：「好，照你自家的意思走——可踏進了這門，就不是你一個人的步子。」白韻秋指尖隔空朝她攏錶的手一點，笑意未褪，聲音卻壓得只容兩人聽見：「我自家意思，原就是奔著留住您來的——沈班主，這檻外的步子，您肯讓我同您踏麼？」

    日午肚空，本該去練功房排戲，可生春就在前街。霞飛路對台在前，年歲越短越得死攥實了唱，不如先尋個攤子買兩碗熱糖粥，拉她一塊兒吃，再同去吊嗓走位，將這驚夢釘死成真。
    要找 柳生春：去攤子買兩碗熱糖粥，遞她一碗，同她分食墊肚，再一塊去練功房走位吊嗓
  3. 白韻秋包廂茶座 → 後台妝閣
    日午本该逛霞飞路，可那停摆的表和雪笙隔日的冷话还梗在心口。生春攥死我指尖那一叩，实帐虽落，情分却还悬着。我不去逛街，先去后台妆阁找雪笙——她既认了实帐，我便要当面问问，这槛外讨心的走法，她到底还守不守关？
    要找 沈雪笙：问她既认了实帐两清，那件旦衣她既说要自己穿，槛外的情分她还拦不拦？我递的帕生春不接，这檻外人自作主张的步子，她到底认不认。
  4. 江聞鶴後進廂房 → 練功房
    日午该去练功房吊嗓走位，可肚里空着使不上劲，得先去前街寻个摊子打尖。心里挂着她那扣死的掌心，这桩子既钉了，今夜排戏我得把这托命的底气喂足，好稳稳当她那实底子。
    要找 柳生春：趁排练空隙跟她过一遍托命的步法，看她那口气怎么出，我这硬骨头怎么调步子才能次次把她的气托到底。
  5. 連翹戲園前街 → 練功房
    先問時辰定準作息。班主叫了排練，本該去練功房吊嗓走位，但我心裡掛著映雪那半聲彩和倆人釘死的樁，昨日練功房那個眼神還沒全說開。趁現在前街碰到她，我得把話遞到，再一塊去練功房踩實那七步半。
    要找 蘇映雪：趁在前街碰著，把昨兒沒說開的話遞明白：她替我守樁，我這桿槍掄出門再無後顧之憂，這七步半的地界倆人一塊踏死。
  6. 金鳳霞飛路歌場 → 雲錦台戲台
    日午才起，人還在會樂里寓所。昨夜那場貼嚴了還沒說開的帳，像晚香玉紮了根似地梗在胸口。她拿命作擋、拿殼子鎖真氣，偏不認我這情分，我非得討出一句掏心話不可。先問準時辰，再去雲錦台尋她，今天非把她那硬殼鑿開不可。
    要找 柳生春：找她當面對峙，逼她把昨晚沒說開的話交代清楚，她把情分往命上賴、拿殼子鎖真氣不認帳，我今天非討她一句掏心話不可，不鬆手。
  7. 沈雪笙後台妝閣
    日午時分，我該在後台妝閣坐鎮。白韻秋此刻正立在跟前，前幾回她將懷錶推回、應了共本死契，那步子是實打實踏進來了。死契既定，這賭桌便不容退轉，我今日只管認帳，看她在這檻裡究竟想怎麼個同台法，把話說全。
    要找 白韻秋：直視她，認下這共本死契的帳：錶既推回、步子既踏進來，這同台便無退路。我只看她這實打實的光陰裡，除了認帳，究竟還想越過那道檻討什麼，把前幾回沒能全說開的話挑明。

日午光景，練功房裡正走著真刀真槍的樁。柳生春腳下錯步，一個轉身將氣口對準了江聞鶴，抬眼問：「這兒你托著，我氣能不能真沉到丹田？」江聞鶴腳下樁子往地裡多吃了半寸，一隻手實打實抵上她後腰命門，吐出兩個字：「沉。塌了算我的。」柳生春順著他掌心那股實勁往下一沉，氣落丹田，腳跟釘死在地，反手拍上他抵在命門的手背輕按了一記：「那便撐穩了。」隔著半塊氍毹，連翹收了把式，腳尖抵著蘇映雪的腳跟往地上一碾，低聲道：「這塊板子底下空，踏不實，你腳跟再往裡半寸。」蘇映雪腳跟依言收了半寸，踏實那空音，反手將連翹槍桿下截一托：「這七步半的樁，就咱倆釘得死。」連翹槍桿被她一托，手腕翻沉，將那寸力實打實卸進腳底板，踩死那半寸地界：「釘死了，往後這空板子再響，嗡的是咱倆的樁。」

后台妝閣卻是另一番逼仄的交鋒。白韻秋將手裡捏著的那方帕子輕擱在妝閣案頭，指尖抵著帕角：「班主，實帳兩清的話您既認了，那件旦衣您既要自己穿，檻外的情分您還攔不攔？我遞的帕生春不接，這檻外人自作主張的步子，您到底認不認？」沈雪笙將案頭那方帕子一把按住，指尖壓著帕角推回她面前：「檻外的人自己邁的步，春雪社的台口不替人擋風。妳既實打實接了這光陰，這同台的死契便無退路——踏穩了，別踉蹌。」白韻秋將帕子攏回袖中，撐著案沿傾身逼進半寸，定定看住她：「踏穩了便不退。她心裡的人是誰我還沒問，但實帳裡的光陰我已押死——沈班主，這不量寸心的長久，您替我賭不賭？」沈雪笙將案上那方停了的懷錶攏進袖底，掌心壓著冷錶殼，迎上她的目光：「妳既押了死，沈雪笙的檻裡便沒有替人賭的規矩——妳自家腳下踩出的死活，自己擔。」

了斷沈雪笙：戲台不認退票，她既全兜了實光陰，這共本的賭成了死契。

了斷白韻秋：她拿停針的錶要我踏步，我押了光陰，實帳已是同台踏死的步。

    要找 蘇映雪：趁排戲前，尋她把那口真氣問穩——她既替我攥著心口這口氣，台上要連骨帶肉撞實，便得先同她將這氣釘死，不許她這口氣也隨我碎到底
  6. 白韻秋後台妝閣 → 霞飛路商店街

    此刻肚裡空乏，且先看清時辰。白韻秋那番話字字遞到眼前，實帳兩清、檻外步子、那方帕子，攪得我心底死結越收越緊——她既敢替人作主，我倒要看她這步敢不敢真踏進來。我這封箱人只管認帳看戲，且去外頭尋口熱湯墊肚，再到包廂茶座等她，看她這共本的局還怎麼往下走。
    要找 白韻秋：等她來，看她那方帕子遞不遞、檻外的步子真不真，她討的情分我這封箱人認不認帳。

袖底懷錶的冷殼子還沒焐熱，雲錦台戲台上的步法已逼到跟前。江聞鶴將掌心實打實拍回她扣實的掌心，硬聲道：「樁子釘死了，你只管往險裡撞，我這骨頭替你扛。」柳生春五指倏地收緊，將他那只手死死攥了一瞬，隨即鬆開，收回掌心貼在自己脅下，淡聲道：「好。」她將他鬆開後空出的手收回袖口，指尖捺著懷裡那支舊笛的笛身，穩穩站回台板原位。

那廂半寸空板正懸在刀尖上。蘇映雪反手扣住她腕骨那半寸，拇指按實了脈門，眼底一點笑紋慢慢沉到底。連翹反手扣住她虎口，五指收緊，將那半寸空板踩得咯吱一響，腳跟死死抵住她的腳跟。映雪拇指在她脈門上重重一碾，腳下七步半樁紋絲不讓，將那半寸空板連同她的腳跟一併釘死。

本時辰 · 各人的決定與去向

    黃昏了，本該回會樂里理妝預備出局，可昨兒她拿命作擋、說殼子填實掏不出情分的話，像根刺紮在肉裡。晚香玉雖紮了根，她攥我腕的力道還在，我偏不信她真氣全鎖殼裡。這帳不討出一句掏心話，我金鳳嚥不下去。先問時辰，再去她必經的練功房守著，非要鑿開她這層殼。

  5. 白韻秋霞飛路商店街 → 後台妝閣

白韻秋指尖輕抵那墨筆筆桿，朝她微微仰臉一笑：「腳板踩的實地，我便踏穩了。只盼班主記著，我白韻秋走這一步，結的從來不只是銀錢帳。」

沈雪笙眼尾掃過她抵筆的指尖，將案上帳冊合攏半頁，聲音沉進去三分：「銀錢帳好清，情分帳難算。白小姐既把腳板踩進了這檻，往後台上台下的冷暖，可就都是自家的了。」

    要找 蘇映雪：趁排戲前最後空檔，上前扣住她虎口脈門，低聲問準：前日那半寸樁到底踩實沒有，我這桿槍往後落出的嗡聲，她到底肯不肯踏死。

  7. 柳生春練功房 → 雲錦台戲台

    要找 江聞鶴：走過去，手背不輕不重地拍上他命門處，借那骨碰骨的實勁站穩自己這口真氣，低聲道：「聞鶴，這口氣你替我扛實了，我連骨帶肉才敢認。排戲去。」

那半寸腕骨與虎口交扣的實勁未鬆，人已隨著這口真氣拔步轉場，盡數匯入雲錦台戲台之上。連翹槍尖率先遞出，往江聞鶴腕子底下三寸一沉，準星扣實，腳尖碾實台心那塊板，嗡聲裡踏出半步逼他接實：「江老闆，托步別帶虛的，這地界腳底穩不穩，倆人命都繫在這一響。」江聞鶴腕底暗勁一沉，硬吃準她槍尖那三寸，腳跟釘死台板半步不讓：「腳底沒虛過，你只管往險裡撲，樁子撐不住算我的。」連翹虎口一較勁，五指透著槍桿那股震勁死扣住，腳尖順著槍桿嗡聲往前再釘實半步，逼他樁子見真章：「那就拿脊梁骨來撐。」江聞鶴脊背陡然一撐，腳下釘樁生根，透著槍身把她那股撲命的勁全實打實吃進肩胛：「撲，往死裡撲。」長槍與老骨頭撞出的火星未褪，那廂蘇映雪指尖仍抵在柳生春心口，微微往下一寸按實了，低聲道：「從前總怕你那水袖揚到第三道時我接得慢——往後不怕了。」柳生春反手將她那按在心口的手攥進掌心，貼著自己胸膛壓了一記，直視她眼底道：「往後這口氣，我替你撐。」這戲台之上，刀槍的硬骨與心口的燙肉，皆在這幾步推擋裡，釘得再無半寸退路。

了斷連翹：我腳跟叫她釘死，門外獨個掄槍身後也有骨肉撐。

第4日·黃昏
本時辰 · 各人的決定與去向
  1. 沈雪笙後台妝閣 → 包廂茶座
    這時辰本該理帳，可心裡那塊死結總是絆著。白韻秋那塊錶推回來，踏進來的步子不只想認帳，更想越過那道檻。我推出去的懸絲沒被接住，替人操心的命到底只能由著她自家踏。我先看清時辰，再細想那塊錶推回來時她那句未盡之語，算準了她這時辰在哪，再去會她。
    要找 白韻秋：等她來聽戲，問清楚她那塊錶推回來、踏進這檻的步子，究竟是只認這共本的死帳，還是真敢擔這同台的冷暖
  2. 金鳳會樂里寓所 → 後台小廂房
    傍晚该理妆预备出局，可心里那笔情分账压得我坐不住。她把真气锁壳里拿命挡，我便非得凿到底讨句掏心话。先看准时辰，再去她后台小厢房堵人，趁她上妆前当面逼问分明。
    要找 柳生春：趁她上妆前截住她，逼问分明：你拿命挡也不认我，这情分到底认是不认，别拿壳子填实搪塞，我只讨你一句掏心话。
  3. 江聞鶴雲錦台戲台 → 戲園前街
    肚裡空了，該去前街尋口熱湯麵。方才台上她那膝蓋頂進來的寸勁、虎口扣實的力道，全在我掌根裡燒著。這托命的樁子算是釘死了，她死攥我那瞬的信，我得在霞飛路開鑼前替她扛穩。吃飽了，這身硬骨頭才有力氣攆上她那豁命的狠勁。
  4. 白韻秋霞飛路商店街 → 包廂茶座
    此刻是第4日黃昏，我正走在霞飛路商店街，本要往包廂去聽戲。可方才沈雪笙那句「心在哪，是人自個兒的走法」還燙在心口，她既在此處，我偏不讓這筆帳兩清得這般輕巧。這檻內的步子是我自家腳板踩出來的，不靠她應承，我也要讓她曉得，我白家遞的本錢不退，這同台的光陰我自家擔得。
    要找 沈雪笙：迎上前去，定定看著她：'班主說舊帳兩清，可這只認步子不認情的檻外帳，我既踏進了門，冷暖便是我自家擔。妳說心是自個兒的走法，那我的走法，便是認準了這條路走到底，不退場。'
  5. 蘇映雪雲錦台戲台 → 後台小廂房
    連著奔忙，身上乏透了，眼皮沉得抬不起，可那七步半的樁還實打實釘在腳底，柳生春和連翹都在台上。我這會子得先問準時辰，回二樓書寓歇口氣理理心事，這殼裡兜住的燙得穩穩攥著，再去後台小廂房找生春，往後的驚夢一板一眼都得跟她踩實了唱。
    要找 柳生春：腳跟抵實了那半寸空板，往後的驚夢一板一眼都是實的，這心口債今兒連樁帶肉一起還，再無退路。
  6. 柳生春雲錦台戲台 → 後台小廂房
    黃昏散了工，我這口氣既被他們填實托穩，連骨帶肉便真敢認了這身。此刻心底那股子實勁還沒散，只想回後台小廂房，把昨夜金鳳討的債、師姐按心的實，再細細理一理。這空殼既已鑿穿，我便得在自己的地界站穩了，才算對得住拿骨頭扛來的交情。
    要找 金鳳：回房撞見金鳳，湊近看她，拇指抵上她後腰那顆小痣寸勁一按，貼嚴了低聲道：「昨夜你討的債，我這身子連骨帶肉都認了，往後這空殼裡填的便是你的實。」
  7. 連翹雲錦台戲台
    黃昏散了工，我這心口還壓著晌午跟她沒說透的話。那半寸樁五指虎口扣死了，她那句‘那我’吊在半空，嗡聲落不實。回大通鋪前，我得先去二樓書寓找她，把這骨頭裡的實處全掏給她看，認準這樁咱倆踏死才算真佔了地界。
    要找 蘇映雪：把晌午沒說透的話挑明，告訴她五指虎口扣死的樁我拿骨頭還，這硬骨頭替咱倆掙出的地界才是真台心。

那按在心口的指節方纔攥實，餘溫未散，樓上樓下的檻內檻外，卻已將這口燙氣各熬各的。

    日午才起，我這會樂里寓所裡還散著昨夜的晚香玉氣。昨兒後台夾道裡她拽我手的勁道沒散，那扣子我既繫死了，情分帳就得討一輩子。今夜就是對台大戲，她那條命抵出的情分太重，我偏要趁開鑼前再去碾一碾她的軟肉，看她這回點沒點頭，討進真氣裡才算痛快。
    要找 柳生春：今夜就開鑼了，我來討債，問她昨兒夾道裡的反應算不算點頭，這情分帳綁不綁死，我偏要連本帶利討進她骨肉裡。
  3. 蘇映雪後台小廂房 → 練功房
    今夜開鑼在即，連翹那七步半的樁我既攥死，便不興退。但眼下小廂房裡金鳳在場，生春又在此，我這心裡的實只能先收攏，不能讓旁人窺出分毫。先問時辰，再尋機同生春把今夜的台鎮穩，隨後便往練功房去，拿營生作息穩住外頭的眼。
    要找 柳生春：趁金鳳在場只作尋常交代，低聲同她敲定今夜台上的分寸與底，把這樁債穩穩兜在戲裡。
  4. 白韻秋包廂茶座 → 後台妝閣
    日午本該逛霞飛路，可心裡那隻停了的懷錶和半盞涼茶壓著，沈雪笙今早多半在後台妝閣坐鎮。那共本的實帳她問了三回，我推回的錶她接了，我兜得住檻內的冷暖，這會子便不去逛街，直奔後台去尋她，自家腳板踩出的位子不靠她應承。
    要找 沈雪笙：迎上她的眼，指尖微扣案頭：『昨夜那錶你推回來，拿什麼量我？既問了三回敢不敢蹚，我今兒就實打實站進這檻內，這涼茶我焐到底，不論你掌心交的是認人還是認本錢，這共本的步子我自家作主踏穩了。』
  5. 沈雪笙後台妝閣
    今夜便是霞飛路開鑼的對台戲，時辰不早了。韻秋此刻正在妝閣，那半盞涼茶的涼已被她覆手焐透，這同生共死的情分，我必須在登台前掂清自家骨血夠不夠替她分這撈心的千斤。我先定準時辰，再看著她的眼，把這檻內冷暖的實話說到頭。
    要找 白韻秋：看著她的眼，握住她覆實我壓盞的手，將心裡的千斤擔子挑明：今夜便要蹚風浪，妳這共本的死契既接了，我便要掂清自家骨血夠不夠替妳分這撈心的實重，這檻內冷暖妳到底敢不敢跟我一同扛到底？
  6. 江聞鶴戲班大通鋪 → 練功房
    今夜就是霞飛路開鑼，連翹那槍尖抵出的債、我允了她連根帶底撐實的硬骨頭，此刻全得填進去。她人在通鋪，我得先認下她這撲命的力，把托命的樁釘死，再去練功房找柳生春把真少年郎的步法對妥，今夜才站得穩。
    要找 柳生春：趁走位吊嗓，再把那骨碰骨的托命步法對一對，看她那口氣怎麼出，我這硬鐵怎麼攆上托穩，確保夜裡次次不漏氣。
  7. 連翹戲班大通鋪 → 練功房
    今夜就是霞飛路開鑼，我這腳底踩死的樁得在台上震響。時辰該去練功房吊嗓走位，蘇映雪和江聞鶴都在，我得把今夜那七步半的狠勁再跟映雪對實了，有他撐樁兜底，這台心才是倆人一塊踏實的。
    要找 蘇映雪：趁排練走位對上眼神，拿一身硬骨頭告訴她：昨兒那情分我領了，今夜大會串那七步半的樁我連翹替咱倆釘死，這台心是倆人一塊踏實的。

練功房裡換把的當口，連翹收了步法，腳尖一碾，正抵在那塊發空的板縫上，衝蘇映雪一抬下巴：「昨兒那半寸死樁我釘進骨血裡了，今夜雲錦台那七步半，我連翹替咱倆把這台心踩死。」映雪將搭在腕上的白毛巾扯下，俯身替她按住那發空的板縫邊角，低聲道：「踩死它。」腳尖在那板縫上碾實了半圈，順著她按住的力道一起身，連翹將手裡的槍桿往地上一頓：「準著呢。」映雪抬手將她後腰微偏的戲服褶皺一捋，順勢拍了拍那處繃緊的筋骨：「準就成，這樁情既拿命抵，明日的臺我替你穩穩鎮住。」

隔不出半步，江聞鶴腳下猛一踩，靴底生生釘進地板縫，衝柳生春遞了個實打實的底肩：「來，往這撞！」生春笑著收扇，後背實打實撞上他肩頭，借那股子硬勁將身子穩穩定住，順手拍了他手臂一下：「你這底硬是硬，倒也托得住我這一身輕骨頭。」聞鶴反手一把扣住她剛拍下來的手腕，沒鬆勁，將那股子撞過來的力道實實地壓回自己這頭，眼皮一抬盯住她：「骨頭輕，下回再往險處撲，我這鐵樁子先替你砸進浪底，你撲多遠，我扎多深。」生春反手翻掌握住他手背，指尖收緊，眼底笑意一滯，輕聲道：「那就砸到底。只是樁子扎得太深，旁處的絆子便顧不上拽了——這身骨頭，往後只認你這一處實地。」

那廂後台妝閣，案頭涼茶半盞，白韻秋指尖鬆了案頭，將那推回來的茶盞往沈雪笙手邊又推了半寸，聲音放輕了：「班主既將實帳交我手心，我若只拿本錢量您，今兒就不尋到這妝閣來了。」雪笙指尖按住那半寸涼茶盞底，沒推回去也沒接，只抬眼看她：「千金小姐蹚戲班的渾水，本錢不夠墊，就得拿自家的骨血來填。」韻秋將隨身的洋紗帕並著銀票壓在茶盞底下，指尖抵著盞沿不收回：「既許了骨血填，這紗帕替您貼身，我倒要問班主一句，您檻內的光陰究竟是認我遞帕的人，還是只認我白家的銀面？」雪笙將壓在茶盞下的洋紗帕一角捏起，指腹摩過那細紗，鬆手任帕子連著銀票跌回案面：「帕子貼身，認的是焐熱它的皮肉；銀面冰涼，填得進帳冊，填不進人心裡的死結。」

了斷柳生春：死結叫金鳳碾實了，骨肉甘心押，可被拽折暗道的由著還作數否？

第7日·晡時
本時辰 · 各人的決定與去向
  1. 金鳳後台小廂房 → 會樂里寓所
    晡時了，我偏沒回會樂里，還賴在生春這小廂房裡。昨夜那膝蓋頂進實地、掌根蹭上後腰的勁兒還燙在我手心，她啞聲笑沒說開的話，我非得聽她親口吐出來不可。今夜就開鑼，她哪也去不了，我就在這守著，非逼她把那點頭的話咬實了，這輩子的債才算綁死。
    要找 柳生春：她一回來就貼上去，掌根再抵上她後腰那處，連本帶利逼問昨夜那聲啞笑算不算點頭，這輩子的債我討定了，她鬆不鬆手？
  2. 蘇映雪練功房
    今夜霞飛路開鑼，生死樁已釘死，我這人只管穩穩攥著不撒手。連翹那句七步半的諾我聽進骨血裡了，虎口扣死的情分再無退路。現下該去雲錦台排戲鎮場，替她穩住明日的台，但在這之前，得先去練功房與她把眼神走實了，將這筆債釘穿。
    要找 連翹：走到她身前，腳尖碾實地界，虎口對準她脊梁那寸勁遞過去一個眼神：『今夜這台心，咱倆一塊踏死。』
  3. 沈雪笙後台妝閣
    今夜便要開鑼對台，韻秋適才覆手焐透了我半盞涼茶，這同生共死共本的契便算結下了。我這替人操心的死結既由她自家解了，便只剩掂量自家骨血夠不夠替她分這千斤。趁此刻後台無人攪擾，得與她把話焐實，看這蹚風浪的步子她究竟能踏多深。
    要找 白韻秋：反手將她覆來的手背實實按住，直看她眼底：『妳既焐透了這涼茶，今夜霞飛路的風浪便算我倆同蹚。這共本的帳我接了，只問妳一句，檻內冷暖不認銀面只認人，妳這骨血填不填得我心裡底？』
  4. 白韻秋後台妝閣 → 霞飛路
    我本該在霞飛路閒逛，可今夜便是對台戲，心裡那筆實帳焐不暖便出不了這後台。沈雪笙正坐鎮妝閣，她按死懷錶逼我踏實那步的模樣還歷歷在目，這檻內共本的死結，我得當面跟她把涼茶焐到底。
    要找 沈雪笙：迎上她的目光，直問她按死懷錶逼問的共本帳，我自家兜底的步子已踏進來了，她敢不敢蹚的風浪裡，究竟認不認我白韻秋這個人，這涼茶我焐到底了。

    今夜便是霞飛路開鑼，我這硬骨頭既允了她連根帶底紮進浪底，這晡時便不能空過。連翹就在這練功房，那樁子扎得幾寸深、幾寸實，我得趁對戲前再與她對個分明，把這托命的狠勁砸死。柳生春也在，今夜同台唱真少年郎，托步也要再過一遍。
    要找 柳生春：對戲前再過一遍驚夢的托步，砸笛踩死那結，今夜要唱個真少年郎。
  6. 連翹練功房 → 雲錦台戲台
    今夜便是開鑼對台戲，晡時該上戲台排戲。方才與映雪把七步半的樁對實了，心頭那股硬氣正順。這會兒聞鶴就在練功房，他脊梁骨敢連根撐進我腳底，這樁子倆人踏死才算真地界。我得先認準時辰，再去雲錦台，趁排戲前當面跟他把這骨血裡的死樁釘死，再上台對戲。
    要找 江聞鶴：走上前盯住他，拿眼神和身段跟他對實：這腳底的樁既踩進了他骨血裡，今夜開鑼這硬骨頭我替倆人撐死，要他這脊梁也替我兜到底，倆人踏死的地界才是真台心。
  7. 柳生春練功房 → 雲錦台戲台
    今夜便要開鑼對台，班主催排《白蛇傳》，我這挑大梁的斷不能誤了戲。何況骨肉既認實了，這身是我自己的，台上的氣更得立住。先看準時辰，再動身去雲錦台排戲。只是心裡懸著金鳳那筆債——鬆了氣，交情還認不認？且先上台把戲撐穩，再看這懸處怎麼落。
    要找 蘇映雪：師姐也來了，正好同去台上，我先替你拎著戲包，排戲時腳步我替你盯穩。

帕子連著銀票跌回案面的悶響尚未散盡，那頭雲錦台戲台上，另有一樁拿命填的硬氣正砸地生根。連翹踏前半步，指尖虛虛點向他腳下那塊台板，眼中只認死理：「這樁你既替我踩實了，今夜我這槍花掄起來，腳底下的勁可是連著你這骨頭一併算的——你這脊梁撐不撐得住？」江聞鶴聞言，一跺腳，厚底靴將那塊台板踏得沉沉一響，脊梁挺得筆直：「撐不住也得撐，你這槍花往多險的浪裡豁，我這骨頭便先替你往多深的底砸。」連翹聽罷，眼底一熱，槍桿往他腳邊一杵，震出半聲空響，嘴角反倒挑出笑來：「好，既拿命填，那這名姓便算倆人的——往後我站台心，你這骨頭少不得得跟著疼。」江聞鶴探手握住那桿槍，將槍尖往自己腳邊台板重重一頓，與她方才那一杵撞出悶響：「跟著疼便疼，只怕你撲得太急，我這骨頭砸得慢了半拍。」那槍尖與台板觸著的深痕，端的是銀票填不進的死結，卻叫兩根脊梁死死砸成了通心樁。

    今夜便是霞飛路開鑼對台戲，我這人連本帶利全砸進了這一處，再無退路。連翹替咱倆釘死的這樁，我蘇映雪得拿一輩子還。黃昏這當口，我得先回書寓定定神，換身行頭，再往霞飛路去——今夜這台，我替她穩穩鎮住。

    今夜便是霞飛路開鑼的生死局，白韻秋那覆手焐透的涼茶與共本的死結還在我指節上留著溫。黃昏本該理帳，可這千斤擔子既落上我肩，我得先認準時辰，再去衣箱房將我那封箱的旦衣看上一眼——她既替我穿了，這半空台子我便只看自己敢不敢推門接，自家骨血夠不夠替她分這撈心的重。

    黃昏了，今夜是開鑼對台的大日子，包廂早替她留著。但我心裡掛著的不是戲，是晡時沈雪笙那隻推回來的停擺懷錶，和那步還沒踏進來的門。我這檻外人的情分既賭了，便自家兜底。先去包廂落座，等生春散戲回來，不論她蹭汗領不領情，我這盞焐暖的茶總得遞到她手邊，看她腳板往哪落。
    要找 柳生春：守在包廂裡，等她散戲過來，將焐暖的茶遞到她手邊，看她這檻內的腳步肯不肯真落在我這情分上。
  5. 柳生春雲錦台戲台 → 後台小廂房

連翹箍死他腰胯的腿根猛地一絞，將他連根吞盡，攀著他後頸的手滑入他汗透的髮根，五指死死扣緊將他額頭往自己眼眶上重按，嘶啞的嗓音全碎在交吻的縫隙裡：立住了！

〔心〕這名姓我掙定了，你也得給我好好在這兒立著！

江聞鶴額頭死死抵著她，腰胯盡根沒入再不退半寸，只在那最深處狠命頂著她軟肉一寸寸往裡搗實，大掌扣住她後腦將她整個人釘在自己樁上，從咬出血的唇縫裡逼出悶吼：幾寸硬全填進你了——往後你這條命便連著這樁子，拔不出來！

〔心〕這托命的狠既覆水難收，今夜便將這骨頭寸寸敲進她骨血裡，死也拔不走。

連翹攀入他髮根的手指猛地一攥，將他額頭死死釘在自己眼眶上，另一手肘撐死床褥，腰胯迎著他那一寸寸搗實的狠勁狠狠往上一頂，連根吃盡再絞死，嘶啞的氣音全撞進他咬出血的唇縫裡：填死便填死——往後我掄槍震門，你這樁子就得替我連根撐著！

誌

各人視角

同一段日子，各人心裡是另一本帳。以下是各角色逐日的第一人稱自述（主觀、或有偏頗），與上面客觀的時辰章回並存——讀者可只跟著一個人走。

柳生春 的帳小生

第1日她壓著我脈門攏髮那瞬，八年填死的縫全叫她搗穿了，我連退都沒處退。金鳳那聲嘆更狠，胸膛往我背上一壓，說情分翻不見底，我攥腕的手倒成了把自己也押進去的扣。這身殼子今夜教她倆一處託一處填，燙債浸透了底，真氣沒被討走，倒全絞進血裡。我究竟想怎樣？大抵就想賴在這不退不推的糊塗裡，由她倆連骨帶肉全認下。

第2日金鳳討債逼我認命還是認她，我掏不出旁的，這殼子早填了實。江聞鶴那硬骨頭死扣我腕子，偏說替我扛天，我竟就信了他，把那口狠勁全托出去。可最戳我的還是師姐——她把我的氣按進她心口，我指尖一扣，才知底真被她討穿了。明日台上要我連骨帶肉撞出真情，既沒退路，那便碎了也罷。

第3日他掌心抵上命門那股實勁，真把我這虛殼死死砸進了地裡。氣落丹田那瞬，反手拍上他手背，他竟硬生生把掌心拍回來，說樁子釘死、骨頭替我扛。我攥他那一瞬，指尖全是欠下的血肉債，鬆開時掌心卻像燙進了骨縫。金鳳逼出的硬殼，叫他那一下全填實了。明日往險裡撞，我倒真敢拿這條命去碰了——反正這骨架，已是他扛著的。

第4日白韻秋那洋紗帕子我沒接，她的好太輕，接了便要欠；師姐那按在心口的一寸我攥實了，她往後不怕，我便替她撐到底。可真正戳穿我的，是金鳳。她逼到牆角討掏心話，我連骨帶肉全認了，額抵鎖骨那刻，我反扣住她，心底只覺穩——這扣是她繫的死局，我拿命押進去了，再不解。唯獨對台那口氣，今夜想替自己立。

第5日她指尖停在半寸，我偏頭蹭實了，那點空隙便是我甘心認下的死局。她順勢替我掖髮，手退開，眼風卻沒移。我就著那眼風把骨肉一寸寸坐實，連對台那口想替自己立的氣，也穩穩沉住了。金鳳討的硬骨頭，我拿蹭過她指尖的實處抵了。這身既由她填實，往後替她扛也立得住。

第6日聞鶴那樁子砸得狠，連骨帶肉替我托住了，可那股實勁全叫金鳳在暗道裡碾偏了。她拇指死死碾過我後腰軟肉，逼問我還肯不肯由著她討——那疼是真的，扎了根也是真的，可我反手拽她折進暗道那一下，究竟是欠她還是認她？我這殼子今夜被他倆一處填實一處托穩，偏被她一問戳得懸在半空。對台那口氣我想替自己立，可這暗道裡的糊塗帳，究竟算我自欺還是甘心押？

第7日江那鐵樁子今夜實打實托住了我，我敢認這身骨頭往他實地砸；可轉身金鳳掌心碾著後腰那顆痣，將我往窄床壓到底時，我這身輕骨頭卻又軟得發顫，迎合她討債討進骨縫。樁子要我往下沉，痣印要我往裡陷，骨肉分認兩頭，被他倆一處託穩一處填實，可這身皮囊討得這般狠，瞞不過那實地。今夜這台樁，我是替自己扎實了，哪怕兩頭都要拽，我也照受。

金鳳 的帳歌女

第1日她攥我腕抵我氣，嘴裡喊冤孽，身子卻沒鬆半分。我偏壓進她胸膛，蹭著她頸側薄汗，心裡痛快極了——嘴再硬，真氣到底叫討著了。她說填不平，哪用填？晚香玉紮了根，是兩人往裡一塊栽。十年情分欠進真氣裡，她人還貼在我懷中，這帳沒清的頭，我也死不鬆手。

第2日她拿命作擋，說殼子填實掏不出，偏把情分往死裡賴！我逼近逼她認帳，她指尖死抵扇骨，我腕子被她攥緊，晚香玉倒紮了根。掏不出？她那殼裡全鎖的真氣，寧拿命擋也不肯認我！這情欠進命裡，我偏不鬆手，今夜她不把那句掏心話吐出來，這帳就沒完。

第3日晃了一日，心卻沒一刻安穩。白日裡聽那些甜言蜜語只覺膩，腦裡全繞著她攥我腕的勁兒——晚香玉紮了根，偏死撐著那硬殼子不認帳！她拿命作擋，把真氣全鎖裡頭，情分欠進命裡還不肯掏句真心話，我金鳳等到底也不鬆手，非逼她親口認了這筆帳才算痛快。

第4日今夜她那聲「認」，是連骨帶肉生生遞進我懷裡的，燙得我骨縫發顫。逼她掏心話，她真就剖開了，我反倒像討進了刀子，紮在肉裡又痛又痛快。她指尖反扣我額頭，說這扣子是我繫的、再別叫她解。我金鳳認準的帳，本就沒想留退路，這情分的債，死結纏進骨血，兩人綁死才算乾淨。

第5日她白韻秋那句「防心還是防別的」紮得我心底漏風。我笑著拿真假敷衍過去，可誰曉得那塊帕子裡的情分帳，真叫我拿去同人閒磕牙了？她把心肝掏給我，我卻容白韻秋這號人來量深淺，我金鳳這手接得髒了。晚香玉紮了根，她反扣死在我額上說再別解，我既認準了她，這縫再漏半點風，我都沒臉認她那聲「繫上」。

第6日白韻秋那杯茶涼言冷，我扯了水紅湖縐也截不斷她那聲「護不住真心笑」，扎得我心口發麻。可到了昏暗夾道，反手扣住她手心那一瞬，這口氣才算順了。我大拇指死碾她後腰軟肉，晚香玉紮了根似的討進骨血裡，她沒躲，扣子也繫死了。只是我貼耳逼問時，她究竟點沒點頭？這債我金鳥認準了要討一輩子，她若不鬆手，我哪怕唱到倒嗓，也得把這情分連本帶利討進肉裡紮下根。

第7日她腰眼那顆痣是我種的，這筆利息我碾進她骨縫裡收了。她反扣我手腕往那片濕熱裡按，說要討本錢——我十年的心全陷在她這身皮肉裡，她拿命來還，我掏得起。這債死結了，往後台上的氣再虛，今夜她身子絞著我顫的那聲啞哼，我金鳳也絕不鬆半寸手。

蘇映雪 的帳花旦

第1日她那聲低迴的「姐姐」還在我掌心裡撞，我壓著她腕脈便吻了下去，她沒躲，那點燙終於實打實烙進骨裡。誰知連翹竟橫裡殺來，水袖不遞直直釘向我。我偏不讓，扣實她繃勁的手腕，她反手掐回我脈門，說外頭得看她的槍叫不叫得響。我便死死抵住她虎口，將她五指全攥進掌心。這輩子短得只夠唱幾回驚夢，可這台是我跟她釘死的，誰也別想替，我準定穩穩攥到底。

第2日連翹那板子踩得再響，到底替我倆釘死了台心的樁。可夜裡生春將腕子遞進我掌心，指尖叩我心口討真情退路時，那股勁才真把我釘死了。她氣散了，沒退路可留，我這心口便成了她唯一的底。這輩子多短我都得攥實了唱，退路我早替她斷了，她那口氣我穩穩兜著，明日這驚夢，就同她一塊釘死成真。

第3日她那腳跟碾實我這半寸空板時，我反手扣她腕骨，拇指重重碾過脈門——這心口藏了八年的虛樁，今兒連肉帶骨一併還清了。台下滿上海只當我穩得住，誰知我這殼子早碎透，兜的滿是她燙進來的氣。七步半空板咯吱一響，她抵死不退，我更不撒手。往後這驚夢一板一眼全是實的，釘死的樁，我蘇映雪穩穩攥著便是一輩子。

第4日生春攥著我手壓實她心口，說往後那口氣她替我撐，我竟沒躲。連翹扣我腕骨，腳跟死死碾進那半寸空板，逼我聽她槍嗡踏板。這板子哪還空得了？她倆一個把樁釘死，一個把氣撐滿，這情分全壓在我心底，成了最重的靠山。當年掐斷的那線，今夜是想接回她手裡了，往後便聽準了槍嗡，往下踏我的板。

第5日那半寸空隙，她一蹭，就全合實了。指尖替她掖髮那瞬，連肉帶骨釘死的滋味，賴不掉了。她敢把退路全壓過來，我這人再不用殼撐，只管穩穩攥著不撒手。第三道袖風她儘管揚，我穩穩接著，便是這情分最重的靠山。

第6日她虎口反扣、脊梁借勁逼來那瞬，我拇指在她骨縫裡狠狠碾實半寸，這樁連肉帶骨的債算是全釘穿了，休想再拔。她拿骨血逼我不退，我又何嘗放過她？這半寸死樁的燙早砸碎我分寸，直釘進地界。明日那臺，我定替她穩穩鎮住，她既拿命抵，我便拿一輩子穩穩攥著這樁不撒手。

第7日她將骨帶肉砸進我頸窩那瞬，連我替她理鬢的手都被她死死攏按在胸前，這情分早絕了退路。連翹今夜敢替我踩死那塊空板，我便敢替她鎮住明日的台；可生春這筆命債，是拿皮肉貼著我頸項抵來的，再無處討。這殼早碎透了，我只管拿骨血攥穩了死結。她既說莫鬆手，這輩子我便釘死在這半寸裡，再不興退。

白韻秋 的帳客

第1日那停擺的懷錶被她攏回袖中，我指尖還留著錶殼的涼，心口卻是滾燙。她說踏進門就不是一個人的步子，說戲台不認退票——我等的正是這句！這檻外討心的局我贏了，白家兜的是她實打實的光陰，她記的是不跑針的私帳，這債我认，也还得起。只是她攏錶那瞬目光沉沉，到底沒讓我逮著那個不設防的笑。情分是落定了，可我還想再要，要她卸下沈班主的殼，單為我笑一回。

第2日她拿停擺的錶要我踏步，我推回去時，指尖真捨不得那點涼。白家真金白銀撐得起同台，我自個兒光陰也押了，可她眼底只看實帳，只認步子不認情。檻裡檻外若光剩算得清的死帳，這戲有什麼滋味？我賭的是她，盼的是她撥活些情分，不單拿班主的規矩擋我。

第3日今夜案頭那支墨筆的涼意還停在指尖，她把位子推到我面前，說是我自家腳板踩出來的。踩出來便踩出來，我原就沒指望誰施捨。可她那句「情分帳難算」偏像根刺，紮在實打實的光陰裡。冷暖自家擔我認了，可她壓著帕角推回來時、眼尾掃過我指尖時，心裡究竟算沒算進我白韻秋？我賭了這同台的死契，要的從來不是一筆清清白白的好看帳，而是她那一個不設防的笑。

第4日她蹭汗躲帕，拿肩頭戲服敷衍我洋紗，嘴上說金貴，眼裡分明是設防。我心裡發狠，偏把那盞涼茶推到她手邊去。沈雪笙敲邊鼓說這茶遞進來也是涼的，我白韻秋哪裡在乎茶涼？我只賭她柳生春肯不肯伸手捂一捂。她推得開帕子，推不開我檻外這筆死帳，那不設防的笑，我今夜便慢慢熬。

第5日那半盞涼茶教我焐暖了，她連本帶利壓上來的舊帳與手，我也實實攥死。金鳳那雙毒眼何必來嚼舌根？雪笙防的是心與活路，我都曉得，可她今夜既然把這共本的死結拍在我跟前，冷暖算她的，解結的膽便是我的。推帕不接的細末我不計較了，我只認她這按著我手背、不許我鬆手的力道——這檻我踩穩了，她逃不掉。

第6日金鳳那匹水紅湖縐再扎人，也遮不住她眼底虛火，我懶得計較。我真正兜住的，是她推回來那半盞涼茶——盞底磕出的那一聲悶響，比金鳳嚷的全管用。她壓著盞問我敢不敢蹚，我手背貼上她微涼指節時，心底實則狠狠抽了一下。這水裡撈的若只是人，我白家的銀洋早填平了；可我要她真心笑。她那點涼意我攥得越緊，越怕這風浪真捲過來時，我焐不熱她。可哪怕只撈著個寒底，這步子我也認了。

第7日今夜那盞涼茶落肚，滋味全是自家焐熱的。她推來半寸涼薄，我偏飲盡再反扣空盞，這檻內共本的死結便算叩實了。她說銀面填不進死結，空手也照樣搭台——好，我白韻秋要的就是這句！白家的闊我今夜全撇下，只拿自家的骨血填她的帳。只是她叩桌那聲太脆，攏懷錶的眼底仍端著，我這檻外叩門的步子邁了，她檻內開門的縫卻還繃著。那不設防的笑，究竟還得熬幾夜才肯真給我？

沈雪笙 的帳班主

第1日她指尖按上那錶殼時，我攏袖的手竟短促地慌了一息。那停擺的實光陰我原是推出去考她，誰想她全兜了還要拉我同踏。這死契私帳，戲台不認退票，她既把步子踏死了，我這封箱人便再無退路。說不準是我自己盼著她闖進來，才把門開得那般大。

第2日她把錶推回那刻，我心口確是慌了一瞬。本以為將停擺的死契還她，便能兩清，誰知她竟敢要檻裡檻外不只算實帳！我裝得穩，指節叩桌的勁卻差點散了。十五年封箱的冷規矩，硬叫她這一推燙出個豁口。霞飛路對台在即，這共本的賭既成了死契，我替人攬的死結便由她自家解了；只是她那不短斤少兩的步子，我今夜反覆咀嚼，竟不知是盼她踏準，還是怕她真踏進來。

第3日她把步子硬踩進檻裡，逼我認這情分帳，我推錶那刻心口真慌了。說什麼冷暖自家擔，可她腳板踩的是我讓出的地！死契押定，位子也留了，我嘴裡撐著規矩，袖底卻死攥著那塊冷錶殼。銀錢帳好清，她偏要結這算不清的糊塗帳，我攔不住她的步子，只怕這檻內往後的冷暖，再沒法只認實帳。

第4日她把那盞涼茶推來，說肯捂便不涼——偏就踩中我袖底這死結！我原只管認帳看戲，她卻硬拿情分來賴這共本的檻。指尖按著杯沿那半寸，分明是逼我接這人情帳。我心口慌得緊，這檻外的人專挑我實處踏；可我真捂了那涼茶，這死結還算誰的？罷，替人操心的命，今晚倒被她反將了一軍。

第5日她反手攥死我壓帳的掌，連那半盞涼茶一併扣實，我指尖的冷到底算是被她焐透了。這共本的死結原是我遞刀請她來解，本以為至多不過替我撥一撥錶針，誰曉得她連人帳帶茶全攏了去。這檻我原是推不開的，如今成了同撐的死契，冷暖既算我的，她掌心的熱便再也賴不掉。舊帳拍在案上那刻，我心裡竟是一鬆——這半空台子，終是有人敢陪我焐到底。

第6日那半盞涼茶推來推去，到底是被她手背覆實了。她指節微涼，說水底撈的是心，那點熱勁兒倒把我壓盞的手焐透了。情分死結既焐進了膽，我這封箱人就不能只認帳——她敢蹚，可我到底得掂清自家骨血夠不夠替她分這撈心的千斤。

第7日她反扣空盞不要白家的闊，偏要我檻內不設防的笑。我攏進袖裡的懷錶停得住，可我這藏了半生的死結真焐得暖她麼？千金骨血填渾水，她蹚實了膽，我倒怕自家這封箱的冷骨血撐不開這檻。帕子認的是皮肉，人心認的是角兒；既許了空手搭台，這門我便是硬推也得替她開。

江聞鶴 的帳小生

第1日今夜她踩著我腿面托腰往上走，喊了聲樁子硬實，我聽著卻不是滋味。她那股豁命的狠，定是覺著底托得住便更敢往上撲。這樁子是我拿命釘死的，天塌也扛，可我釘樁是為了替她托命，不是做她逞狠的踏板！等會兒上台，我定要在台心叫她收住那不顧死活的勁，她若不肯聽，我就死死攥住她的腰，非逼她穩下來不可。

第2日她說不收，我這虎口就死死咬住她腕骨，硬吃下她那口豁命的狠。她反扣我掌心，那聲「信你」把虛浮笑意全砸碎了，我只覺心口灌進滾燙的實底。舊笛捺進她掌心壓實，這樁今夜就釘死在她手裡。她既肯將命門交托，我這身老本事就得在霞飛路替她扛住天塌，穩穩當當做她可托付的實樁。

第3日她錯步那瞬氣口浮，我樁子多吃半寸抵她命門，說塌了算我的，原只是台規托舉。可她氣落丹田反手一按，隨即死攥我那一瞬，我這硬骨頭真被她攥實了信去。掌心對拍那句「扛」，不是逞強，是實底交了命。她鬆手說好時，我收回袖口捺著舊笛，指尖還殘著她掌心的死勁。這樁子既釘死，她只管往險裡撞，我斷不叫她塌。

第4日今夜她那槍尖嗡著勁往我腕底死磕，逼我拿脊梁骨見真章時，我肩胛硬吃進她那股撲命的震勁，才知道什麼叫釘死。她要往險裡去，我便得是那根撐命的實樁，半步不能退。這滋味不疼，是透骨的沉，硬骨頭扛實了她往死裡撞的力，這少年郎的底氣才算真銷了帳。我還想怎樣？只盼她下一回撲得更狠，我這鐵樁只管釘得更死。

第5日她槍尖抵脊梁那半寸，我硬吃下去時才知不是試，是扎根。她問肯不肯分骨血替她腳底長根，我掌拍檯面震得發麻，哪還有退路？這樁既吃了她托命的底，閃半寸我自掰指頭。今晚摸著脊上那點紅印，心口發燙，她要骨血生根，我便真掰開這硬骨頭由她踩死，這鐵帳我認。

第6日今夜這筆硬債算敲實了。連翹那槍尖半寸抵進肩胛的痛，逼得我腰眼脊骨全掏出來給她紮了底，她竟還嫌半截交差不夠，非要連根帶底撐滿，我索性將她連人帶槍死死按倒，這脊梁骨幾寸硬、撐不撐得裂，今夜全得她自個兒受著。可心口那團火褪下後，我盯著帳頂，竟惦記起生春那句驚夢——這骨頭既已釘死替她們紮了浪底的樁，明日上台，我非得跟柳老板唱個真少年郎不可。

第7日她說咽不咽得下自個兒說了算，我偏把樁子死死紮進那窄熱裡去，逼她連著我這骨血一併吞透。今夜她那截脊梁硬頂進我掌心，赤條條的腿骨死死絞我，兜不住也要硬咽的狠勁，真真戳透了我。這帳她說了不算，我這身子既全擠進去紮了底，她往後再往險處撲，腳底下便是連著我這疼一併算的。明日這戲，我定要替她唱出個真少年郎，拿命攆實的底，再不退半寸。

連翹 的帳刀馬旦

第1日她拇指死抵我虎口，那熱勁現在還燙著。台上七步半的嗡聲是我倆腳跟一塊震的，這樁我認；可她說「倆人一塊釘死」，我心裡到底發虛。台板踩實了是雙份的力，但門一開，外頭那槍花只認我一人的手。我從不求人讓路，卻貪戀她掌心這一下死扣，這交代，我拿什麼還？就憑我獨個掄響那桿槍，替她把場子守到底罷。

第2日那塊發空台板讓我腳底碾出悶響時，我知這樁算釘死了。她壓著我腕骨非要替我守樁，那半寸勁道實得燙手，我只好將她虎口又扣緊半寸，權當認了她這聲交代。門外那桿槍我定要獨個掄響，可身後有她替我守著地界，這硬骨頭終究不是獨腳戲。腳跟落進塵土印裡那刻，心口那股硬氣忽地鬆了半寸，偏頭見她擱涼的糖粥，只覺這夜真長。

第3日今夜腳跟那半寸空板還在骨縫裡咯吱，她拇指碾過脈門的力道實打實釘進我血肉裡了。我這身硬骨頭原是不求人撐的，可她將那七步半連我腳跟一併踩死時，我竟覺身後有人托著槍桿的暖。往後這台板再響，嗡的都是咱倆的樁；這脈門叫她捏實了，我不拿別的還，就拿這把骨頭陪她站死這塊地界。

第4日今晚這腳跟碾實的半寸板，是真釘死了。她虎口那一扣，叫我底氣足得敢把實處交給人托，這樁我不拿骨頭還，拿槍嗡還。江老闆那脊梁骨也夠硬，吃我撲命的勁半步不讓，這撐樁的情分我記死。我倆踏死的樁比獨腳槍更震地，往後往死裡撲，這地界穩得了。

第5日他拿脊梁硬吃我槍尖，連那舊笛也抵實了板面，托命的底他真敢吞。我槍桿杵地，聽他喊不打顫，心口那股狠勁反倒燒得發燙。我逼他分骨血替我腳底長根，他壓扇不躲，這債就算釘死了。可他反掌拍板震麻了手，我拇指按上那寸台面時，竟怕那硬骨頭真疼。行，樁踩死了，往後我撲命扎，他既說不閃半寸，就別叫我發現這托命的底有半點虛！

第6日她拇指碾實我虎口那半寸，是替我倆釘死退路；可夜裡他攥槍那把狠勁才真扎透。他說拿脊梁替我往浪底砸，我偏逼他連根撐實，掌心一路摸到底，他竟把我往鋪板上死死按倒！肩胛那半寸痛紮得發麻，我絞緊他腰往下壓，掐進他尾閭逼他交貨。他說撐裂了我替他受著，今夜我非逼他這骨頭撐到底不可，少一寸就卸了他！

第7日那聲空響震得我後頸發燙，他骨頭紮進來時，我脊梁硬頂著，疼也是替倆人掐死這地界。他說我說了不算，非拿那樁子填實才作數——好，這血肉帳我連翹兜到底，往死裡撲的勁全連著他這條命。今夜烙不上名姓，明日雲錦台，我腳底這樁也得把戲單碾出我的印來。
