序章

春雪社的這座戲台，原是清末一位官紳家的堂會戲台。改朝換代後，官宦人家的排場散了，這方戲台連著半進院子，被沈雪笙盤了下來，掛上春雪社的水牌。正樑上那塊舊匾額她一直沒換，燙金的字暗了，至今照舊掛著。

戲台最裡頭的後台，那幾口樟木戲箱，落了十五年的灰。十五年前沈雪笙封箱那日，班裡如今這批台前的人多半還是孩子。她沒對任何人交代緣由，只說往後這幾箱小生的行頭不再動了。班子靠著幾齣熟戲，一年一年也就過來了，台下的人換了一批又一批，戲單卻還是那張戲單。

今年不同。霞飛路那頭新起的戲園放出話來，年底要辦一場打對台的大會串。掛得上名的班子，往後的檔期、報上的版面、堂會的邀約，都在這一場上見高低。掛不上的，慢慢就沒人記得了。

沈雪笙把那口最底下的箱子開了一條縫。裡頭壓著的，除了那幾件沒人再穿的小生戲衣，還有一只早停了的懷錶。

戲箱要重開了。這一季，春雪社得排出一齣自己的新戲，趕在年底那場會串之前。至於箱底那些沒說完的舊事，沒有人交代該怎麼辦。

  7. 連翹戲班大通鋪 → 練功房

日影正午，練功房裡初夏的熱氣被一桿銀槍攪得生風。連翹一個翻身亮相，槍尖驟然一沉，穩穩釘住了去勢，額上沁出來的汗珠叫靴底細末沾了些。蘇映雪坐在一旁，將手邊備著的溫茶往連翹那頭推了推，順手拂過自己袖口，眼神仍不離她槍尖的去處：「那亮相收得住勁，這口茶算你的。」連翹拿袖口抹了把汗，將那碗茶端起仰頭灌下，擱碗時衝她挑眉一笑：「茶我領了，下回瞧我靠旗紋絲不亂，可得換壺好茶。」蘇映雪指尖輕叩桌面，嘴角挑起一絲笑：「靠旗不亂才叫本事，今兒算你過關，去雲錦台的新戲旦角處，我自有好茶備著。」連翹將長槍往臂彎一掛，拿靴尖碾了碾地上的細末，朗聲道：「映雪姐，好茶我記著，可雲錦台那台心，我得自己走過去站。」這話擲地有聲，槍桿上的紅纓猶在微顫，房中那點未散的勁風，倒把窗紗也吹拂起幾分波瀾。

私會樂里寓所　柳生春×金鳳

梳妝檯上的摺扇剛落定，微塵未定，柳生春便在床沿坐了，手扣著檯邊，指節一收一放，眼簾低垂。屋裡靜了半晌，她才開口：「金鳳，我今日來，是想跟你說句實話。」

窗邊人沒起身，只倚著窗櫺，伸了手去撥弄那盆晚香玉的青葉，聽見這話，忽地笑了一聲，慢悠悠道：「實話？難得。說罷，我聽著。」

柳生春按在檯沿的手驟然收緊，復又鬆開，喉間滾了滾，壓著聲低語：「我欠你一句交代，拖了這些年，是我對不住你。」

晚香玉葉上的指尖一頓，金鳳收回手，並沒回身，只側過臉來看她，眼波深處涼意寸寸生，聲音壓得極低，字字卻如碎玉般清晰：「對不住？柳老闆，我要聽的可不是這三個字。」

柳生春緩緩抬起眼，望定那半轉過來的臉，眸中千般都認了，嗓音低啞：「你要聽什麼，我今兒都認。從前那幾年……是我先鬆的手。」

分鏡 · 5 拍

柳生春她不招呼，徑直走到床沿坐下，將手裡那柄摺扇隨手擱在一旁的梳妝檯上，垂著眼開口：'金鳳，我今日來，是想跟你說句實話。'

〔心〕這句交代壓了這些年，今日不說，往後怕是更說不出口了。

金鳳笑了一聲，沒起身，只倚在窗邊伸手去撥弄那盆晚香玉的葉子，慢悠悠道：'實話？難得。說罷，我聽著。'

〔心〕你那實話裡有幾分是我要的，你自個兒心裡清楚。

柳生春手按上梳妝檯邊沿，指節收緊又鬆開，低聲道：'我欠你一句交代，拖了這些年，是我對不住你。'

〔心〕你心裡清楚，是你先鬆的手——可話到嘴邊，怎麼還是像求她原諒？

金鳳指尖一頓，從晚香玉葉上收回手，沒回身，只側過臉看她，聲音壓得極低、字字清晰：'對不住？柳老闆，我要聽的可不是這三個字。'

〔心〕拖了這些年，就換來一句輕飄飄的對不住？你身子還記得我的手，你心裡卻還是藏著掖著！

柳生春慢慢抬起眼，望向她側過的臉，嗓音低啞：'你要聽什麼，我今兒都認。從前那幾年……是我先鬆的手。'

〔心〕她要我剖出來，可我連自己這身皮囊都未必摸得透——師姐拿走魂，你暖回身子，如今我拿什麼還你？

  2. 沈雪笙後台妝閣

  4. 連翹雲錦台戲台 → 戲園前街

    入夜了，本該去霞飛路歌場掛頭牌唱堂會，可柳生春竟在會樂里我的寓所。這人淡歸淡，身子卻認得我的手。今晚我偏不急著走，先看看她來這兒葫蘆裡賣什麼藥，再順著性子討我那一句交代。

柳生春上前一步，合攏的摺扇抵上她擲帕的檯面，扇骨磕出清脆一聲響，直直望進她眼底：**「那筆情分我今兒認了，是我先鬆的手——可你方才側過臉去那一瞬，要的當真只是這一句認頭？」**金鳳伸手覆上她抵在檯面的扇骨，指腹不輕不重地一搭，將她手背連同那柄扇子一道按住，眼底波光定住：**「我側我的臉，你認你的情分，柳老闆，這十年我等的就是你親口說出『是我先鬆的手』——旁的，我金鳳不貪。」**

歌場這頭兩般心思寸步不讓，後台妝閣那頭卻來了個不速之客。白韻秋探身進門，雙手交搭在身前，輕聲問：**「沈班主，生春這會兒排完戲沒？何時能回後台歇息卸妝，我尋她有幾句體己話要說。」**沈雪笙擱下筆，將帳本合上，抬眼望向門口人：**「她這會兒在台上走身段，還得一歇。」**指了指旁邊空著的椅子，**「你先坐，等她下來，我叫她過來。」**白韻秋順著話音輕步走到那椅子旁落座，將手裡攥著的一方繡帕妥帖收進袖口，才抬眼朝帳桌那頭輕輕頷首：**「那便勞煩班主了，我等她。」**沈雪笙順手替她倒了一盞剛沏的熱茶，推到桌沿，淡聲道：**「她這陣子戲重，下來少不了要卸半天片子，你若不急，就寬心坐坐。」**一盞熱茶推至跟前，氤氳水汽裡，等的是卸妝的人，也是未知的底。

  4. 蘇映雪後台小廂房 → 練功房
    連翹那半份彩聲勻了我的空涼，涼茶飲盡，生分債算互抵了。可心底那道茶梗還是橫在生春跟前——夜帳既蓋了戳，我這殼便釘死了，連酸楚都沒由頭探出去。此時該去練功房吊嗓排戲，但生春就在眼前，總得探她一探，再把這殼裡的硬撐收一收，才好上場。

    要找 蘇映雪：碰面點個頭，不寒暄，只拿一身正經練功的硬氣讓她瞧瞧，這大會串的台心我踩定了，她那份彩聲我連翹一併掙回來。

    日午了，本該回後台妝閣看帳排戲，可前街一晃眼竟瞥見白韻秋。昨兒那錯開半寸的涼茶堵在心口，旦衣的念頭也越發燒人。不急著回，先看清今兒是什麼時辰，再上前會一會她，把話再探一探。
    要找 白韻秋：上前搭話，看昨兒那沒說透的話今兒她怎麼個章程，順道把我那件旦衣的心思再掂掂。
  7. 江聞鶴後進廂房 → 練功房
    日午本該去練功房排戲，可這心裡那樁釘實的托命樁子始終懸著。倆人的命既釘一處，我得再同柳生春把這口氣合實了，確認這穩樁子次次都能托到底，才敢安心上台。
    要找 柳生春：趁排練空隙，把她拉到一旁，實打實問清楚：年底大會串這樁托命的力道，她接不接得穩，我這硬骨頭得怎麼調步子，才能次次把她的氣托到底。

靠旗理得齊整，連翹腳尖一碾，朝著台心那塊板子的方位踏出七步半，穩穩釘住，直看向蘇映雪：「映雪，我那份彩聲我自己掙，你那一半，我也替你挑著。」映雪將手裡的絹子往袖口一掖，朝她微微頷首，嘴角牽出三分笑意。

    要找 柳生春：趁排戲前就在眼前，把那日沒全說開的話接上——骨碰骨的托命樁子既釘了，大會串這口氣怎麼走才不閃失，我得聽她實話。
  7. 柳生春練功房 → 雲錦台戲台
    此刻是晡時，班主催排《白蛇傳》，我這挑大樑的角兒再拖不得。江聞鶴那硬骨頭托底的情分我既認了，今兒上台對戲便要借他這口氣踏實步子。師姐也在場，我得把這些日子飄忽的心思收攏，穩穩當當走這斷橋的位。
    要找 蘇映雪：收了平日的漫不經心，正色對師姐點頭，今兒排戲定把那口穩氣提住，不叫她皺眉。

指尖順勢把他那把舊扇子連帶自己的手一塊兒推回他胸口，這股子硬碰硬的勁兒還沒散盡，雲錦台上的鑼鼓點子已催到了跟前。連翹腳步生風，趕在頭裡上了台，將手裡的槍桿往台板上一頓，發出個悶脆的聲響，斜眼看向蘇映雪，嘴角一挑：「這台心七步半，我踩熟了，妳只管唱妳的，那聲彩我替咱倆掙回來。」蘇映雪微微頷首，將腰間汗巾解下擱在台邊椅背上，淡笑道：「腳底有準，我自然穩當。」連翹腳尖碾過台心那塊發空的板子，試出個扎實的落腳處，槍桿一收抵在身側，衝她遞了個亮堂的眼神：「那就踩實了走。」

那廂腳跟立穩，這邊袖口一捋，江聞鶴直盯著柳生春道：「大會串這口氣怎麼走，咱們得釘死了，你實話告我。」柳生春將手裡摺扇往他掌心一拍，扇骨抵著他手背，眼皮一抬，聲音穩穩當當釘過去：「這口氣不走虛的，從這兒起，骨頭碰骨頭，我唱到哪你托到哪，絕不帶喘的。」江聞鶴掌心一合，將那柄扇子連同她抵過來的力道實打實攥住，腕骨不退半分：「好，骨碰骨，這樁穩了。」柳生春收回手，指尖在袖口輕捋了一把，嘴角挑起半分笑：「穩了的樁，就不興再拿虛話晃我了。」戲台之上，兩處樁子皆已落定，再無半點虛浮。

了斷柳生春：今兒這殼子被他托穩了，後頭的關我只管借氣往前踏。

  5. 連翹雲錦台戲台 → 包廂茶座

同一段日子，各人心裡是另一本帳。以下是各角色逐日的第一人稱自述（主觀、或有偏頗），與上面客觀的時辰章回並存——讀者可只跟著一個人走。

第5日今兒白晃了一天，心裡卻沒一刻安生。她那句「我先鬆的手」紮在肉裡，白天發了麻，夜裡倒更疼。指腹上那扇骨的勁還燙著呢，情分的帳哪是一句認頭就能清的？桌上那晚香玉熬到年關，總得替它尋個活處；花若活了，這口氣我咬牙也得等到底。

第6日今兒晃了一天，心裡卻全繞著她那句「我先鬆的手」打轉。台上扮得再英挺，她仍是她，那股子認命的狠勁紮得我生疼。可扇骨挨著我指腹那點勁，分明比認頭更燙人，這情分帳哪能一筆勾？算了，帳清不清我說了算，我偏不鬆手。那盆晚香玉，年關前我定替它尋個活處，她不要，我替她留著。

蘇映雪 的帳花旦

第1日她說雲錦台的台心得自己走，我聽著，指尖還留著推茶時那點餘溫。當年我沒那膽量，先逃了，如今看她穩穩掛住靠旗，心裡竟不知是替她高興還是替自己難堪。那筆帳沉得我都不敢認，可偏生又盼著她真有本事替我還了。備了好茶又如何？我只敢在分寸裡待人，連那句「當年」都嚥回肚裡，笑著由她去闖。

第2日那半盞殘茶她咽得連眉都沒皺，杯底磕回我手心時還帶著她嘴邊的熱氣。我笑著讓出台心，心口卻像被那發空的台板狠狠碾過——她站得越穩，我這替人兜底的殼就越像個笑話。她夜裡不歸的帳，我竟起了一親自去討的貪念，卻連多留一刻的膽都勻不出。罷了，槍既扎不準，就守著這空盞熬過今夜。

第3日那半截槍纓遞出時我原以為能端到底，可她偏不接我那盞茶，槍桿磕地一聲倒比我的準話還硬。指尖按過她手背就收，是我一輩子的分寸，可這會兒滿手空涼，才知是自己打了自己的臉。夜裡不歸的人我沒資格討，她情不賴，我倒成了個只敢穩在殼裡的糊塗人。

第4日今夜那半句彩聲，倒真把涼茶的澀意勻平了。連翹這丫頭，空板也敢碾實，攤開的手心亮堂堂，逼得我這殼不得不留道縫。我原以為那盞沒人接的茶得自個兒悶咽，她卻拿往後的彩聲抵了生分債。行，場上見便場上見，她腳底既有根，我往後這殼裡的人，也敢再探半步。

第5日連翹替我挑彩那七步半，踩得我心口發虛，我這硬撐的穩當倒成了她托著的碗底。下台端麵給她，燙指尖也不躲，就那樣乖乖由著我管。我虛托一把碗底，怕她燙著，她卻敲著碗沿說我沒動幾口。這殼的縫原是留作還情的路，可她連我少吃半碗麵都瞧在眼裡，我那分寸裡藏著的不捨，到底還是被她一口口吃透了。

第6日她含我拇指、膝頂腿間那刻，我這分寸換的殼算是碎透了。可碎得痛快！腳尖碾穩的空板、替她理平的暗褶，全叫這筆肉償的帳燒得乾淨。我蘇映雪素來穩得住場，今夜偏要糊塗到底，不做半途收手的冤大頭。她既肯頂進來，我便貼到底，明夜再同她唱回驚夢，帳底帳上，我都要穩穩兜住她。

第7日連翹那七步半踩實的嗡聲還在腳底，她倒替咱倆把樁釘死了，我這水袖一翻便接了個踏實。可真正燙人的是後台那半步——生春撞進我懷裡，膝蓋頂進那寸實地，仰臉遞來八年熬出的燙，我扣她腕骨的手再收不住半寸。殼子早碎了，我這輩子替她穩著的心，如今連同那顆鬆扣一併攥死在掌心。明夜驚夢，她既敢唱到底，我便穩穩接著，再不許她躲。

白韻秋 的帳客

第1日那杯茶我沒接，舊帳我不盤，可推回去的半圈，到底欠了沈雪笙一個情分。我守在這兒，等的不是台上那個英挺的坤生，是卸了片子、對我笑得不設防的生春。怕就怕雪笙把人情討回去時，生春又要跟我見外。我那滿腔捧場，定錢落得再穩也換不來她一個真笑；這情分我先記下，只盼她下台推門見著我時，別拿我當還債的恩客。

第2日今兒晃了一日，啥要緊事也沒遇上，心裡反倒更懸。昨日替她擋沈雪笙那杯茶的勁兒還沒散，怕她覺著欠了情分，回頭客客氣氣還我，那可換不來她不設防的笑。我得沉住氣，裝作若無其事，她若急著撇清，我偏不認；只等卸了妝，她肯鬆下眉眼沖我笑，那才算是真抵了這帳。

第3日她說心是空的，拿扇子擋我的風，可那額角的汗分明還留著我帕子的餘溫，她越退，我越要看這空房子幾時漏風。沈雪笙攔路我也認，茶她喝了，許柳生春自己來謝——我白韻秋的情分只記在柳身上，沈不過是替人守關的門神。門神吞了茶，門總得開一回，我偏要等她。

第4日沈替她接了那口涼茶，可我推回去的半寸錯盞才是實話——她的帳歸她，我的心撲在柳生春身上，沈雪笙替誰擋都作不了數。柳生春鬆了手讓風透進來，那一刻她分明知情，可我還是得嚥下她的沉默。妝閣裡那聲「別來要交代」紮人，但檻外頭的心是我的走法，她攔不住我往柳生春身上去。

第5日那錶我硬扣回她袖裡，截住了她替柳作主的慣性，這空她得自己填。雪笙壓掌截我越檻的自謝，冷說無人接戲，可我偏不收回。我這注早灌到底了，賭的就是柳生春卸妝後那點自己作主的餘地。她若推門，停擺的錶便是走時，我這戲便有人接；她若不推，我也耗得起。這檻我跨定了，就等那扇門動。

第6日她反手扣死我指節那瞬，這盤棋我算是贏透了。停擺的懷錶連同我的手一併叫她攥死在掌心，拇指壓上錶蓋的力道，比霞飛路所有綢緞都沉。她說往哪處撥都不如今日這一拍實——對極了，我本就不求虛的。那餘地不用填，情分全壓實在她這一攥裡，成了她欠不盡的實帳。柳生春，妳手既然鬆不開，往後我的時辰，就全憑妳撥了。

第7日那只停錶的餘溫還在掌心，她按死錶蓋那下，分明是認了。她說「那錶早停了，拿什麼量妳」，這句話比霞飛路幾個月的兜風都重，直接將我檻外討心的路墊成了實地。往後不跑針、不量寸心，這共本的戲她推不開，我也再不許她退。情分壓住了檻，穩當，真穩當。

沈雪笙 的帳班主

第1日她連我推的茶都不接，倒問起春春唱不唱。那杯茶推出去又收回，指尖都涼了，她再轉半圈推回來時，我心口竟還是漏了一拍。她尋春春說體己話，我攔不住，只能替她另倒一盞熱茶。她如今說不盤舊帳，可當年不辭而別的帳，她拿捧場來還？罷了，我且看她能跟春春掏什麼心窩子，那件旦衣，怕是真要壓箱底了。

第2日晃了一天，偏偏心裡那件旦衣壓得我發慌。當年我開的是小生的扇，如今連套旦衣都不敢碰，怕什麼？怕再不穿，我真就老了，老到連當年那點心思都提不起。鏡子不敢照，可指尖分明還記得袖口的料子。算了，白家的帳且看她怎麼還，我這樁舊事若再壓著，遲早要壓壞自己，不如哪日真鬆了手，把那旦衣穿上身，哪怕只對著空堂走一趟。

第3日那口茶喝得太淨，喉嚨裡如今竟發虛。她把情分認在私帳上，我這替人守的關便硬生生叫她戳破了。我許柳老闆自個兒去謝，可她究竟能不能把這聲謝遞出去？我心裡竟沒底。罷了，那件旦衣本就是我的，從前是替人撐場面，如今這關既鬆了，我也該自己穿回來了。

第4日那半寸錯開的涼茶，扎得我指尖發麻。我拿春雪社的規矩替她擋，白韻秋偏要討台下的心，我那句「人自個兒的走法」分明是把關鬆得更透了。帳是清了，她卻把情分全攬回自個兒身上，我許的自謝倒成了獨角戲。由著她去吧，那件壓箱底的旦衣，到底得我自個兒穿回來了。

第5日她指尖搭上我掌背，那停擺的錶就被她順勢扣回了袖口。這關透，是她替我闔上的。我本欲自己穿回那件旦衣，她偏要賭柳生春推門有人接。我截錶的手被她按實了，這筆私帳，許是真成了共本。心口微燙，這局我竟沒輸，倒怕是欠了她一個下場。

第6日晃了一日，帳簿也沒翻。她指尖搭實袖口等推門那勁兒，一整天都在我脈絡裡發燙。這私帳許真成了共本，我截錶的手被她一扣，這關便透得回不去了。旦衣我自個兒穿的，可偏覺得還欠她一推門。夜裡真想再去敲她房門，問那碗溫梨湯到底燙不燙嘴。

第7日她拿停擺的針對我眼底，說往後不跑針、只填實光陰。那錶早不走了，我原想替她擋一道，她偏要自己踏進來。黃昏那句「只怕」梗在嗓子眼，怕我拿刻度量她寸心——我哪還捨得量？共本的賭她既認了，推門那步也實打實踩下，我這心反倒懸得厲害。只盼她真站穩了，別叫這情分壓壞她自己。

江聞鶴 的帳小生

第1日那句「嫌吵」釘在嗓子眼，嚥不下也吐不出。我起雲手開嗓，氣沉丹田，原想拿這硬朗逼她見真章，她倒好，腳步一溜讓了鋒頭，拿半掩的扇面輕飄飄就把我的腔接了去！讓？不搶不讓的，哪來的少年郎脊梁？我這嗓門是拿命換的真本事，不是來給她漫不經心襯托的。這筆帳我記著，年關前的新戲，我偏要用磨爛的膝蓋和更硬的步法討回來，看她還嫌不嫌吵！

第2日她笑我嗓子硬得磕不動人心，那碗滾茶我沒吹就嚥，火氣燙穿了喉管。可她指尖按碗偏說我章程沒化開，我虎口逼著她指節撤了那半寸，骨頭碰骨頭的勁兒才真透了底！她說水袖起頭讓我跟，我今夜就認這死理：偏要把這閨閣音唱出城門樓的脊梁。化不化開上台見，這硬底氣我非托住她不可。

第3日她指尖抵上我心口時，我這硬骨頭竟真沒躲。虎口扣實她手骨的那一瞬，火氣全砸進掌心裡去了。她認了這樁，章程就不堵了！「我替你托，你替我撐」，這硬話是砸出去了，心裡既痛快又懸著——她那身殼子若撐不住我這硬底子，閨閣音怎麼出城門樓？可她五指收緊不放，我也就這麼信了。台上骨頭碰骨頭討真章，我江字絕不含糊，只盼她那口穩氣，千萬別塌。

第6日她那半分力實打實撞進後腰，我腰板一挺全吃了，連聲悶哼都壓在牙根裡。她倒好，還笑我別閃腰，又拿扇骨敲我手背！可那輕飄飄一敲，反倒像把錘子，把我這死扛的樁子實釘進了肉裡。這口氣我咬死了，撐穩不漏，我這硬骨頭，就是要穩穩當當替她托命的。

連翹 的帳刀馬旦

第1日映雪姐那口茶我仰脖灌了，暖是暖，可我不靠人賞茶撐場子。她點頭算我過關，又提雲錦台的好茶，可那台心憑什麼得她指路才站得上？今兒槍尖是收住了，靠旗到底還差半寸。大會串我偏不帶傷也要叫響，雲錦台的台心，我非得靠自己這身本事走過去站穩，那時候，才真叫紋絲不亂。
