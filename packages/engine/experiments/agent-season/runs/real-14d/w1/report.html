序章

春雪社的這座戲台，原是清末一位官紳家的堂會戲台。改朝換代後，官宦人家的排場散了，這方戲台連著半進院子，被沈雪笙盤了下來，掛上春雪社的水牌。正樑上那塊舊匾額她一直沒換，燙金的字暗了，至今照舊掛著。

戲台最裡頭的後台，那幾口樟木戲箱，落了十五年的灰。十五年前沈雪笙封箱那日，班裡如今這批台前的人多半還是孩子。她沒對任何人交代緣由，只說往後這幾箱小生的行頭不再動了。班子靠著幾齣熟戲，一年一年也就過來了，台下的人換了一批又一批，戲單卻還是那張戲單。

今年不同。霞飛路那頭新起的戲園放出話來，年底要辦一場打對台的大會串。掛得上名的班子，往後的檔期、報上的版面、堂會的邀約，都在這一場上見高低。掛不上的，慢慢就沒人記得了。

沈雪笙把那口最底下的箱子開了一條縫。裡頭壓著的，除了那幾件沒人再穿的小生戲衣，還有一只早停了的懷錶。

戲箱要重開了。這一季，春雪社得排出一齣自己的新戲，趕在年底那場會串之前。至於箱底那些沒說完的舊事，沒有人交代該怎麼辦。

第1日

第1日·清晨

天光未亮，戲子夜工，滿園還在夢裡，一時無話。

第1日·日午
本時辰 · 各人的決定與去向
  1. 金鳳會樂里寓所 → 練功房
    日午剛醒，心裡掛著柳生春那筆舊帳，想起那夜她頸窩裡的溫度，指尖搭上去她那點不由自主的顫，就覺得這事不能拖。這會兒她定在練功房脫不開身，我索性去戲園一趟，看看她忙什麼，當面要她那句欠我的交代。堂會的事晚些再盤算。
    要找 柳生春：守在練功房外等她歇息出來，當面問她要一句交代，認一句欠我的
  2. 柳生春後台小廂房 → 練功房
    此刻金鳳竟在我房裡，我與她已疏淡多時，欠的那句了斷便這般撞到眼前。班主雖叫了排練，可這心裡的刺不拔，台步也走不穩。我先認認時辰，便去迎她，把這幾年躲的交代給她，哪怕見了她那雙眼我會心虛。了了這樁心事，才好去練功房吊嗓排戲。
    要找 金鳳：面對面站定，正視她的眼，把欠了多年的了斷說出口——是我先鬆了手，是我對不住你，再拖下去對你我都沒交代。
  3. 白韻秋白公館繡樓 → 戲園前街
    日午時分，本該去霞飛路閒逛，可心裡頭全是柳生春。她此刻正在練功房排新戲，脫不開身。我不去逛街了，乾脆去戲園前街尋個吃食攤子守著，既能挨近她營生的地方，又能靜下心來想明白，我到底圖的是台上那個風流小生，還是她卸了妝朝我笑的那個人。
  4. 蘇映雪二樓書寓 → 練功房
    日午本該去練功房排戲，可這會兒書寓裡偏有生春在。金鳳也在，那股子酸楚就堵在嗓子眼，我卻連眼風都不敢亂掃。這滿屋的氣味像根針，紮得我想起那年戲園前街生春欲言又止的臉，又想起除夕那夜第三道水袖的暗號。我是春雪社的台柱，穩得住場是本分，可眼下這分寸硬撐得太苦。我總得先弄清時辰，定定神，再去看生春一眼，哪怕只是替她理理鬢角，也強過在心裡百爪撓心。
    要找 柳生春：端著穩當的笑，上前替她理一理鬢角，順道問她這午時可同我去練功房吊嗓對戲
  5. 江聞鶴後進廂房 → 練功房
    日午該去練功房吊嗓走位，班主叫了排練脫不開身。柳生春這時辰定也在那兒排戲，我心裡掛著年底大會串要跟她唱一場真對手戲，正好趁排練摸摸她的氣口，較較勁，也穩穩自己那股怕本事不夠人看的慌。
    要找 柳生春：趁排練對戲，看她走位吊嗓，暗暗較勁，探探她這口氣到底怎麼換的，也想讓她看看我這身跪步真功夫
  6. 沈雪笙沈宅小樓 → 後台妝閣
    日午時分，春雪社該動起來了。我得先去後台妝閣坐鎮，看帳、看排戲，更要緊的是看人。離大會串只剩六天，柳生春那丫頭的扇子比當年的我更露溫柔，我偏要親眼盯著，看她究竟是不是那塊能在風浪裡站住的新角。順道也摸摸衣箱房的鎖，就當是與過去的自己對個眼神。
    要找 柳生春：看她走位吊嗓，試探她這幾日排戲的心氣，順道點撥她小生行當裡那分溫柔與風骨的界線
  7. 連翹戲班大通鋪 → 練功房
    日午該去練功房排戲走位，這是班主定的規矩，我這刀馬旦的飯碗和名聲全靠身上這點真本事掙來，斷不能懈怠。方才想起當年沈雪笙站台心滿場皆靜的模樣，又見她如今算帳的背影，心裡那股硬氣越發翻湧——我得趁還站得住，把槍花跟翻身練到叫上海睜眼。到了練功房，先找柳生春過過招，探探春雪社這台戲究竟有多高。
    要找 柳生春：探探春雪社小生的身手和排戲規矩，看能不能對對戲，也讓他看看我這刀馬旦的斤兩

日午透進練功房，將一地薄塵照得分明。柳生春剛落了汗，還未及喘息，一抬眼，便見金鳳靠在門框上。她走近身，伸手替她將領口那粒滑脫的扣子撥正，指尖卻不只停留在襟前，順著脊線沿著後腰那個只有她識得的方位，不輕不重地一搭，教那坤生背脊一凜。金鳳望著她，開口道：「柳老闆，台下那些銀洋堆得再高，可有人替你縫過一回水袖？」

柳生春不躲也不迎，只垂下眼，將腰際那點教她搭過的扣子搭頭重新按實了，扯過脖子上的毛巾慢條斯理揩汗，聲音裡聽不出深淺：「金鳳姐，這大熱天的，你倒有閒心來翻舊帳。」

金鳳收回手，偏頭笑了笑，眼裡一絲涼意也沒藏住，字字分明：「舊帳？柳老闆，一筆帳只要沒還，擱再久也是新鮮的。」

柳生春將毛巾往肩上一搭，避開她的眼，轉身去夠桌上的茶壺。壺嘴傾下，滾水落進杯裡，倒水時她手頓了半拍，水聲微滯，再開口時聲音已發悶：「帳總得有個數，你倒給我個準話。」

第1日·晡時
本時辰 · 各人的決定與去向
  1. 金鳳練功房 → 會樂里寓所
    晡時了，我本該回會樂里歇著，可眼見柳生春還在練功房走位，那樁舊帳卡在心口，我怎走得脫？上次話沒說開，今天他脫不開身，我偏要在這兒守著，趁他歇气的空檔再逼他一次，非要他當面認一句欠我的。
    要找 柳生春：趁他排戲歇氣的空檔走近他，伸手替他理一理衣領或扣子，逼著他看著我的眼，冷聲問他上回的話是不是就想這麼含糊過去，非要他親口認一句欠我的交代。
  2. 柳生春練功房 → 雲錦台戲台
    我正要往雲錦台排戲，路過練功房一眼瞥見師姐蘇映雪也在，心裡那根刺又隱隱作祟。可金鳳那筆舊帳像塊鉛墜在胸口，這會兒她正得閒，我若不去，只怕夜裡也安不了心。罷了，先上戲台應卯，排戲脫不開身，金鳳那邊只能等到夜裡再尒。
  3. 白韻秋戲園前街 → 雲錦台戲台
    晡時本該在霞飛路閒逛，可我心裡掛著生春，哪有心思買什麼洋貨。這會兒他定在雲錦台排新戲，我索性不去逛街，悄悄去戲台邊聽聽他排戲的動靜。我想弄明白，我到底迷的是台上那個風流小生，還是卸了妝對我笑的那個人。
    要找 柳生春：尋個不招他煩的角落，靜靜看著他排戲，想從他台上的身段眼神裡，尋一點他真心頭愛著誰的蛛絲馬跡
  4. 蘇映雪練功房 → 雲錦台戲台
    晡時本該去雲錦台排戲，可生春就在眼前，我那點私心又壓不住了。趁旁人還沒走，先穩住分寸同她對對新戲的生旦走位，要把那第三道水袖的默契再續上。之後再動身去戲台，既不誤班主的差，也能填一填心裡那口深井。
    要找 柳生春：藉著排新戲旦角的由頭，同生春對一對生旦走位，特別是水袖第三道的暗號，看看她眼裡還有沒有當年那點光。
  5. 江聞鶴練功房 → 雲錦台戲台
    班主叫了排練，我這時辰本就該去雲錦台對戲。柳生春也在那兒，正好，我心裡掛著跟她唱一場誰也不讓誰的對手戲。先認準時辰，動身去戲台，見了她，就把這股較勁的心氣兒挑明了說。
    要找 柳生春：上前較勁：說排戲對手要來真的，別留口氣，今天這出戲我定要跟你唱個分明，誰也不讓誰。
  6. 沈雪笙後台妝閣 → 練功房
    晡時了，我該坐鎮後台盯班子。可方才憶起白蘭走那晚的車燈，心口那塊舊傷又隱隱作痛。這會兒柳生春多半在練功房吊嗓，我且先問准時辰，再動身去那兒盯她一盯——看她走位，也看看那柄太像我當年的扇子，究竟把溫柔露到了幾分。
    要找 柳生春：看春春吊嗓走位，旁敲側擊點撥她幾句，也借著看她拿扇的手法，細細印證心裡那股又心軟又心驚的牽動
  7. 連翹練功房 → 雲錦台戲台
    晡時本該去雲錦台排戲，可沈雪笙就在這練功房。當年她站台心滿場皆靜，如今卻成了算帳的中年女人，叫我心裡發緊。我想趁排戲前，在她跟前走一趟槍花——別求她，就讓她看看連翹的身子骨還站得住，值不值得在戲單上寫我一筆。
    要找 沈雪笙：不寒暄，直接在她看得到的地方走一趟利落的槍花與亮相，讓她看見當年那個滿場皆靜的勁頭，如今有人還拿身子骨頂著。

壺嘴傾下，滾水落進杯裡，那半拍的微滯早隨水汽散了，滿室只餘發悶的回音打轉。這廂帳冊裡的零碎還未盤算出個子丑寅卯，那廂雲錦台上，摺扇唰地甩開，盪開的卻是另一番不沾煙火的光景。

柳生春立在台上，扇骨一轉，眼神隨之撇向台角那人影，笑意不減、步子不停，兜轉間帶出幾分風流身段。包廂裡的白韻秋原是悄立多時，聽得入神，這會兒輕輕將手中那盞早涼透的茶擱在小几上，拿起絹子掩著唇角，眼風只順著他摺扇指過去的台角溜了一眼，便垂眸笑嘆一聲：「柳老闆這一轉，倒教人連茶都忘了是涼是熱。」

話音落處，台上那人步子一停，合扇指尖一抵扇柄，身子微傾向包廂，那笑眼裡映著的熱度，是涼茶盞裡斷然映不出的，只聽他道：「茶涼了就該換一盞，白小姐何苦將就。」

白韻秋拿絹子的手微微一頓，方才那溜轉的眼風盡數收回，抬眼直迎上他傾來的笑，音聲輕且慢，字字卻咬得真切：「茶涼了換一盞是容易，只怕換了新茶，也未必抵得上舊茶頭一口的回味。」

第1日·黃昏
本時辰 · 各人的決定與去向
  1. 金鳳會樂里寓所 → 後台小廂房
    黃昏時分，本該理妝預備今晚出局，可心裡那樁舊帳橫著，怎麼坐得住？那日午時在練功房外他沒把話說開，眼下他剛得閒歇在後台小廂房，正是討話的時候。我且先去看看時辰，再動身去戲園後頭找他，趁他獨處，逼他當面認了這筆欠我的帳。堂會的事，待要了心願再說。
    要找 柳生春：趁他獨處得閒，上前質問他午時為何躲閃，逼他當面把舊帳說開，認一句欠我的。
  2. 蘇映雪雲錦台戲台 → 二樓書寓
    黄昏散了工，我瞧见生春还在戏台，这心就定不下来。原该回二樓書寓歇口气，可那点私心总拽着我。新戏要排出彩，正该拿对戏当幌子多跟她待一时半刻。水袖第三道的暗号我记着呢，先看看时辰，再去寻她。旁人看见了只当是生旦磨戏，我那点见不得光的心思，就藏在这分寸里头。
    要找 柳生春：借对新戏生旦戏的名头，与她搭话，看她扬水袖时能否再应上那第三道的暗号，只唱给她
  3. 柳生春雲錦台戲台 → 後台小廂房
    黃昏散了工，本該回後台小廂房歇口氣，可金鳳竟在雲錦台。這些年我繞著她走，欠的那句了斷一年年拖著，今天她既自己撞到跟前，我躲也不是，不如上前把話挑開個頭，哪怕只是試探。
    要找 金鳳：上前搭話，趁著四下無人，試探她今日來意，把欠她的交代往明面推一推
  4. 江聞鶴雲錦台戲台 → 後台妝閣
    黃昏得閒，本該回後進廂房歇口氣，可心裡掛著年底大會串跟柳生春的對手戲，哪裡歇得下。方才眼見白韻秋和連翹在戲台，我不湊那熱鬧。柳生春這時辰想必在後台小廂房歇著，我想去後台妝閣附近轉轉，看能不能碰上她，哪怕不開口說句交心的話，只論論戲裡那口氣也好。
    要找 柳生春：在她去妝閣或出來的必經之路上等著，想同她論論年底大會串對手戲那口氣，哪怕只說兩句硬話也行
  5. 沈雪笙練功房 → 後台妝閣
    黃昏了，早先吊嗓的勁兒還沒散，可這會子該理班裡的事了。方才瞥見聞鶴還在練功房，這孩子底子不差，可眼神裡總差著一口氣，不如生春那般亮。我且先回後台妝閣坐鎮，邊理帳邊等生春，年底會串在即，我得看看她那柄扇子如今磨得怎麼樣了，能否撐得起這場大戲。
    要找 江闻鹤：拍拍他肩膀，讓他別練過了頭，傷了嗓子，再問他對年底大會串可有什麼盤算。
  6. 連翹雲錦台戲台 → 戲班大通鋪
    天色黃昏，散了工本該回大通鋪歇著，但我心裡掛著年底大會串，想趁身體還硬朗站上台心給人看。這時辰見白韻秋獨自在戲台，她是常來包廂聽戲的客，有財力也識貨，若能讓她記住我連翹的槍花與亮相，比什麼都管用。我不回房了，就在這戲台拾起傢伙走一套身段，既是給自己順氣，也是要這位客看清楚：春雪社裡有個靠真本事站台心的人。
    要找 白韻秋：不急著下台，去戲台中央走一套刀馬旦的靠旗亮相與槍花，故意將身段做足、落步生風，讓這位看客見識我的真本事，尋機開口探她對大會串武戲的口味
  7. 白韻秋雲錦台戲台
    黃昏了，該去包廂預備聽戲，可柳老闆這會兒剛得閒。我心裡還掛著他晡時排戲時那眼神轉向的角落，想弄明白他心底到底裝著誰。他是進不去那小廂房的，我便不去討人嫌，只守在去包廂必經的妝閣外頭等他，遞上一聲體面的問候，看他今夜卸了妝的神色。
