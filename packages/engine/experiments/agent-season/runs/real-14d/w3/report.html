序章

春雪社的這座戲台，原是清末一位官紳家的堂會戲台。改朝換代後，官宦人家的排場散了，這方戲台連著半進院子，被沈雪笙盤了下來，掛上春雪社的水牌。正樑上那塊舊匾額她一直沒換，燙金的字暗了，至今照舊掛著。

戲台最裡頭的後台，那幾口樟木戲箱，落了十五年的灰。十五年前沈雪笙封箱那日，班裡如今這批台前的人多半還是孩子。她沒對任何人交代緣由，只說往後這幾箱小生的行頭不再動了。班子靠著幾齣熟戲，一年一年也就過來了，台下的人換了一批又一批，戲單卻還是那張戲單。

今年不同。霞飛路那頭新起的戲園放出話來，年底要辦一場打對台的大會串。掛得上名的班子，往後的檔期、報上的版面、堂會的邀約，都在這一場上見高低。掛不上的，慢慢就沒人記得了。

沈雪笙把那口最底下的箱子開了一條縫。裡頭壓著的，除了那幾件沒人再穿的小生戲衣，還有一只早停了的懷錶。

戲箱要重開了。這一季，春雪社得排出一齣自己的新戲，趕在年底那場會串之前。至於箱底那些沒說完的舊事，沒有人交代該怎麼辦。

私後台小廂房　蘇映雪×柳生春

昏黃影裡，蘇映雪攥住她袖口的指骨驟然收緊，另一手揚起，三道水袖的暗號指尖直直懸在她心口前一寸，微啞的嗓音透出不可退讓的沉勢：「這回你接不接？」指尖未落，氣已逼人。

    殼既碎了，今兒這出戲就再也退不得半步。生春扣我拇指那下，比任何話都真，我這肚裡空著，卻滿心都是他掌心的勁。我先看準時辰，再去戲園前街尋個攤子打發肚餓，最要緊的是候著生春——他散了工定會經過前街，我得當面攔下他，把那未說開的話全抖落乾淨，看他還往哪退。

  6. 江聞鶴雲錦台戲台 → 戲園前街
    肚裡空了，且先弄碗熱茶湯暖暖胃。腦裡淨是柳生春那雙扇交抵的架勢，白韻秋那句「缺人搭戲」像根刺。我不必怕舊功夫沒人看，得真找著搭戲的對手才立得住。這時辰她多半在妝閣卸妝，我偏不著急，先去前街吃口熱的，再回後台堵她，把這實打實接戲的話当面敲死。
    要找 柳生春：守在後台妝閣外頭，等她卸完妝出來，再逼問一句這大會串的對台戲，她敢不敢真刀真槍接我的跪步，倆人這牌既一塊扛，就別留半點虛的。

連軸轉了一日的戲，柳生春褪了行頭，腳底發飄，心頭更壓著師姐晌午那逼退無路的半步與決眶的水光，正亟亟欲尋個麵攤理理這心虛的殼子。側門一推，方迈出半步，冷不丁撞見街角那個捧碗守候的人影，腳步不由微頓。面上卻只挑起下頷，朝她揚了揚：｢這回又打算站到幾更天？｣

聽得這聲似惱非惱的嗔問，白韻秋心口一熱，將那碗糖粥往前遞了半寸，熱氣氤氳了眉眼，她嗓音卻放得比那糖粥的熱氣還輕：｢柳老闆別惱，我不進去，就在這兒站到您嚐一口為止。｣

    要找 沈雪笙：趁生春不在，跟沈班主挑明：糖粥能暖生春的胃，真金就能填春雪社的座兒，今夜打對台，我白家的體面與真金都押在她們這邊，看她還拿不拿祖師爺的板子擋我。
  3. 沈雪笙後台妝閣 → 包廂茶座
    入夜了，今夜是年底大會串，也是霞飛路打對台的生死局。連翹那丫頭扣我手按板聽響的力道還燙在心口，她既穩了台心，我替人擋風的手也真該收回了。只是肚裡空了，身上乏得很，得先去前街尋個攤子吃口熱湯墊墊肚子，再回包廂坐鎮看戲，今夜且看她們自己接不接得住這滿堂的風浪。
  4. 金鳳會樂里寓所 → 霞飛路歌場
    入夜該上霞飛路歌場掛頭牌，可心裡那筆帳還懸著——他認了帳，卻揉開我手指卸了力，這「隨我還」到底是認帳還是哄？他既在會樂里，我偏不去趕場，先尋他問個透，再填填肚子去歌場。
    要找 柳生春：質問他認帳時揉開我手指卸力是什麼意思，這隨我還究竟是認帳還是哄，逼他當面再認個清清楚楚。
  5. 連翹戲班大通鋪 → 霞飛路歌場
    今夜就是大會串，我這腳跟碾進板縫的硬響得叫全上海聽見。大通鋪裡歇不住這股子勁，蘇映雪替我鎮場兜底，臨上台前我得再去跟她對一對那個底，把這口氣合在一處，再去霞飛路迎戰。
    要找 蘇映雪：去跟她對一對今夜上場的底，她鎮我的場，我填實她的板，這口氣得合在一處才能踩響。
  6. 蘇映雪二樓書寓 → 後台妝閣
    入夜了，今夜大會串便見高低。先前在小廂房尋生春，話未說開便被岔了，可他掌心橫紋燙在拇指下的那股勁還燒在心口。我既砸了半輩子的殼，便再沒有退的道理。這會子他必在後台妝閣候場，我這就過去，把未盡的話當面了結，拽他站進我這心口。
    要找 柳生春：趁登台前尋著他，把先前未說開的話當面逼到底：這半輩子的冷既結了，你這死扣到底撤不撤，今夜便要你一句準話，我再也不退。

指尖同扣著那方寸錦盒的暗勁未消，場子已換到了包廂茶座。水紅綾子收了，換作一疊雪亮的銀洋。白韻秋將那疊銀洋輕推至沈雪笙面前，指尖抵著最上頭那塊，微微俯身，眼底那股子不讓的勁兒全化在了話裡：「沈班主，糖粥暖得了柳老闆的胃，這些真金白銀填得了春雪社的座兒。今夜打對台，我白家的體面全押在這兒，看您還拿不拿祖師爺的板子擋我。」

沈雪笙不躲不避，掌心覆上那疊銀洋，連同白韻秋抵著的指尖一併按住，坤生底子的手勁沉穩得很，拇指將最上頭那塊推回她手邊，那銀洋在桌上擦出一聲微響：「白小姐的銀洋填得了座兒，填不了戲台上的裂縫。我春雪社的戲，不興讓人踩著板眼往裡硬擠。」

白韻秋收回指尖，將那塊被推回的銀洋攏進掌心，連同那疊一併又往前推了半寸，腕子底下的力道半寸不退：「板眼是死的，人是活的。柳老闆那句粥比彩聲管用的話還熱乎著，我不過是順著他的意來填這座兒，算不得硬擠。」

沈雪笙拇指一撥，將那塊銀洋又推回半寸，聲音壓得極低，字字咬著夜風：「他的意是台上那把扇子，不是你這順水推舟的人情。」

了斷柳生春：十指卡死拽向她心口，這殼不光有底，全交她了

第7日·深宵（入夜）

夜深了，梨園上下各自歸寢，一夜無話。

誌

各人視角

同一段日子，各人心裡是另一本帳。以下是各角色逐日的第一人稱自述（主觀、或有偏頗），與上面客觀的時辰章回並存——讀者可只跟著一個人走。

柳生春 的帳小生

第1日白韻秋那錦盒燙手，我推得乾脆，可江聞鶴拿扇尖抵我喉頭時，我這風流殼子竟敢迎上去硬接他的勁。他說扛死，我偏遞真刀，可心底到底虛。直到師姐攥我掌心往她心口死死一碾，那緊繃的起伏燙得我指尖蜷縮，她逼我只許看她，我這演出的男人哪還躲得掉？殼子早碎了，戲真底已由不得我演，只能認。可認了真，大會串我拿什麼骨相撐台？

第2日江聞鶴那對扇骨扛得死緊，我倒不怕，男兒殼子遇著真較勁反逼出我的實底；可白韻秋不同。她拿錦盒逼我，更逼我抬眼！那風流殼竟連她都擋不住，我連盒子都接不住，還拿什麼撐大會串的台？她死磕著要我瞧她，我這演出的男人拿什麼還她真心？退無可退，殼碎見底，我到底心虛了。

第3日她指尖劃我掌心那一路，這風流殼子到底是兜不住了。師姐偏來揭我底，逼視著要我認，我扣她拇指不退，心卻慌得發顫。人前那點滿不在乎的漂亮全是心虛，她非要拆穿，我還能往哪躲？這身坤生骨子被她攥住，退無可退，我倒真敢認了——殼子碎在她手裡，這心她拿走吧。

第4日江聞鶴那死力將我手腕攥得發疼，可我這殼子竟硬生生扛住了，膝蓋砸下氍毹那刻，這牌子我倆一塊釘死，心裡反倒踏實。誰知推開側門，卻見她在街角捧著一碗熱糖粥！我風流殼子遇著他那硬氣敢認，遇著她這軟和倒徹底卸了。她不進來，只站到我嚐一口為止……這溫軟比江聞鶴的力更攥我脈門。這殼子早碎在她手裡，會串的真底，我拿什麼還這碗粥？

第5日今夜這腕骨還在發燙。聞鶴逼我釘死牌子，我認了；韻秋那碗糖粥甜得發苦，我亦嚥了。可金鳳掐著我脈門討債，我竟由她攥著，允了隨她怎麼還。偏這時師姐偏不許我退，她揪我領口那下，逼得我風流殼子碎了一地——扣住她手喊「都在」那刻，我這身子真底全掏出來了。可欠金鳳的債賴不掉，師姐又死攥著不放，我夾在中間，這條路還能往哪走？

第6日夜深了，腕骨還燙著，師姐那十指卡死往她心口一拽，這殼子全碎了，我連退都不敢退，這真底交她手裡，賴定了。聞鶴那跪步硬得戳人，可我照單接了，不過是仗著心裡有底；韻秋那碗粥和袖口半寸溫存，嚐著是真甜，可甜也罷痛也罷，這身骨子我既認了不再退，金鳳的債便只能欠著，心慌也認。

第7日金鳳那碾還燙在腰上，掌心橫紋印著她的規矩，認了帳就賴不掉了。可師姐水袖揚起、扇骨抵我心口那瞬，十指像卡死拽著這身子不許退，我哪還敢躲？金鳳的債剛欠下，師姐就要全交，這身怎麼抵？殼子全碎在她手裡，甜也敢嚐，痛也敢攥，這底子我認到底不再退。哪怕利滾利還不清，心也得交。

金鳳 的帳歌女

第1日今兒真是晃了一天，沒半點要緊事，可我偏是一整天都靜不下心。台上那點真局、指尖摩挲脈門的勁道，全在腦子裡攪和。他既認了帳，這債由頭便是她親遞的把柄，我熬了這幾年，就等他親自來還！我原以為逼他認欠就痛快了，真聽他說出口才覺不過如此。這債我不鬆手，她就永遠還不清。今晚這晚香玉，是熬不住這躲了。

第2日今夜霞飛路的燈紅酒綠全惹不了眼，我就晃了一天，心卻全揪在他昨晚摩挲我脈門的勁道上。他指尖那一寸寸的算計，分明是認了帳，親遞了把柄給我！逼他認欠也不過如此，可這債我既不鬆手，他就得親自來還。晚香玉熬不住躲，我也熬得住。這局成了真，看他還能躲到哪去。

第3日今夜沒場子，晃了一天，倒讓那晚的勁道又漫上脈門。她指尖摩挲的燙覺沒散，這帳她認了，我偏不躲，一寸寸算分明，晚香玉怕也熬不住。本以為要的是她認欠，如今她既親遞了把柄，這債我死不鬆手，她就得拿一輩子來還。熬得住？我倒要看她怎麼還。

第4日今兒晃了一天，看似沒要緊事，心裡卻盡是他掌心摩挲我脈門的勁道。她指尖那一認帳，把柄便算親遞到我手裡了；我熬得住，非得她一寸寸親自來還。原以為逼她認欠才解氣，真聽了也不過如此，這債我不鬆手，她就永遠還不清。這局成了真，晚香玉也熬不住她這般躲，我倒要看她怎麼收場。

第5日他由著我掐，腕骨吃痛也不躲，我本以為要的是他低頭認帳，可他垂眼揉開我手指，低聲說隨我還時，那力道竟從我手背散了。逼出的認欠不過如此，可他這許諾究竟是蓋印的借據，還是哄我的虛招？這死結我攥了太久，反手扣住他拇指凑近時笑得狠，心裡卻慌：這局我掀了底，他若只是哄，我熬的這些年找誰填？這債，我偏不鬆手。

第6日今天晃了一天，心裡全是他那句「隨我還」。我以為逼他認帳就痛快，真聽了才覺不過如此，這債倒成了我獨自的死結。他揉開我手指卸了力，那力道透著哄，我偏不信。他既蓋了印許了怎麼還，我熬的這些年他終究得填。局是我掀到底，他由著我坐莊，這帳我不鬆手，他就永遠還不清。

第7日她認了帳，可這聲「認」聽進來，竟沒半分痛快。她腰肢往我懷裡一塌，賴著說利滾利還不清，那點小痣還燙在我指腹，她倒反手勾我頸項撒嬌。我逼出了她的認欠又如何？債成了我獨自的死結，帳本規矩全是我定的，偏算不出她拿什麼來抵！她說還不清要拿來抵，我倒要睜大眼看，這身子她究竟怎麼填。這局我掀到底，她休想再賴。

蘇映雪 的帳花旦

第1日她掌心貼在我心口的餘溫還燙著，那下微蜷的顫，早把我大半輩子的分寸碾得粉碎。我逼她抬眼，逼她聽清，可誰曉得胸腔裡這兜底的死攥，是我蓄了八年的孤注一擲？殼既是我親手砸的，這回大會串，我就要她跟我真唱到白頭，再不退那半步。

第2日她虎口遞來那股狠勁，我指尖一撥，卸的是她逼人的氣，也是我自己砸殼的顫。她跺板要鎮台心，我偏引她槍尖扎穩，不許她朝我衝。她叫我聽那聲悶響，我聽見的哪是板子？是我替她正領口時，退了半輩子的手終於借這三分氣托住了實意。你要站台心，我偏要搭著你，這回我不退了。

第3日他反手扣我拇指那下，我這半輩子拿分寸糊的殼全碎了。指尖順他掌心紋路劃到底，他偏不掙也不迎，倒教我不知要逼他說什麼。算了，殼既砸碎，我再不退半步。今夜大會串，我準接得住她，這回可不是拿分寸，是拿死心塌地撐她站穩台心。

第4日連翹頓槍要聽響，我便替她跺下腳跟鎮場。那聲板子實得沒半點虛，她立住了名字，我撐住了場。舊帳裡碎過的悶，倒讓我這下指尖穩得下來。她反手扣我拇指那顫還燙著，我砸了半輩子的殼，退夠了的分寸，如今就只認定她這台心。明天？我還要她再落步，我還要替她聽。

第5日今夜指尖還掐在她腕骨上，那聲「都在」燙得我半輩子的殼盡數碎了。我揪她領口逼她別退，哪裡是在問戲？分明是我自己再無路可退。這分寸換來的殼，原來只等這一刻碎給她看。殼碎了人老了，拿這半生換她一站台心，我也要定她真跟我登臺，再沒戲可擋。

第6日連翹那丫頭碾實板縫的狠勁兒倒叫人痛快，我替她抹實盤扣，兜得住她的輕狂。可真正叫我心口發燙的，是柳生春。她揪我領口的手卸了力卻不撤，我反掌卡死她十指，拇指死死抵住她掌心橫紋往心口一拽——她竟也由我！這半輩子端著的殼今夜算是碎透了，我再不退那半步，殼不要了，我也要把她那身防備一併扯碎，拽進我懷裡踏踏實實站著。

第7日連翹那槍桿直逼心口，我一把攥死她腕骨，她踩實了板，我鎮死了縫，這回誰也別想跑！生春那扇骨抵上肩頭，我水袖揚盡，被她一把拽進半步之內，聽她交了底。我砸碎半輩子的殼，死死扣住她倆的手，這口氣再不退半步。金鳳的帳翻篇了，往後台心這命，我來撐。

白韻秋 的帳客

第1日那角水紅綾子終究沒能見光，就被沈雪笙一掌壓死了。我原以為我的體面與真金，能敲開她們的門檻，可我越硬闖，越成了她倆聯手作局逼退的外人。柳生春攏斗篷是嫌燙手，沈雪笙護箱是守界，倆人一個退一個壓，把我連人帶心碾得稀碎。可我不甘心！我白韻秋的錦盒，早晚要擱進她那衣箱裡，誰也扣不住。

第2日我今兒把錦盒直抵她胸口，她倒笑我怕燙本錢！沈雪笙拿規矩當門栓，柳生春拿笑當擋箭牌，倆人一搭一唱，硬生生把我這真金白銀逼成了外人。可我白韻秋偏不信邪！我攢了幾個月的體面，真就連她師門箱蓋都碰不開？我越往死裡逼，越覺這局是倆人聯手退我。但那錦盒我抵死不收，這本錢我砸定了，她到底消不消受得起，咱們走著瞧！

第3日今天我全輸了。江聞鶴那冷臉倒罷，他算什麼？可我按住懷錶不退時，沈雪笙竟將戲折子平平推回！她說輪不到洋貨櫃檯來量。我這霞飛路的體面，到底只砸出了我夾纏不清的蠻橫。我越想替她爭那步台步，越成了她們眼裡不懂規矩的外人。可我不甘心，她到底想站哪步？我不另找場子，這局我非要攥在手裡。

第4日沈雪笙那幾句規矩算盤，我認！我的真金砸不碎她的板，那便不砸了。今夜捧碗糖粥立在街角，我倒要看看這熱氣能不能燙軟她的門。她推門撞見我，那句「站到幾更天」分明是惱中帶疼。我遞出半寸，只求她嚐一口。哪怕我的洋貨碰不開箱蓋，這碗糖粥定要換她年關前不設防的一笑，我等著。

第5日那口粥的甜，真真嚐著了。她指尖擦過我手背時，我險些端不住碗，只能死盯著她袖口，怕洩了底。可她竟就著我撩袖的手又近了半寸，將粥嚥盡還朝我亮了空碗底！我這滿箱真金砸不開的規矩，竟叫一碗糖粥燙出了她不設防的模樣。可大會串就在眼前，這半寸真心，怕也只是這碗粥的交情。管她的，明早我還要熬！

第6日夜深了，指尖還殘著她袖口的微溫。她順勢靠來那半寸不設防的懶散，真把我的魂都甜透了。她說粥比彩聲管用——我想著，是這糖粥甜，還是我這靠山甜？她肯賴著多歇半刻，總算當我是個比看客親近的人了吧。真金碰不開的箱蓋，教一碗粥燙出了縫，我心裡那點蠻橫也化成了癡，只盼她明日還肯靠過來。
