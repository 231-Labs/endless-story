序章

春雪社的這座戲台，原是清末一位官紳家的堂會戲台。改朝換代後，官宦人家的排場散了，這方戲台連著半進院子，被沈雪笙盤了下來，掛上春雪社的水牌。正樑上那塊舊匾額她一直沒換，燙金的字暗了，至今照舊掛著。

戲台最裡頭的後台，那幾口樟木戲箱，落了十五年的灰。十五年前沈雪笙封箱那日，班裡如今這批台前的人多半還是孩子。她沒對任何人交代緣由，只說往後這幾箱小生的行頭不再動了。班子靠著幾齣熟戲，一年一年也就過來了，台下的人換了一批又一批，戲單卻還是那張戲單。

今年不同。霞飛路那頭新起的戲園放出話來，年底要辦一場打對台的大會串。掛得上名的班子，往後的檔期、報上的版面、堂會的邀約，都在這一場上見高低。掛不上的，慢慢就沒人記得了。

沈雪笙把那口最底下的箱子開了一條縫。裡頭壓著的，除了那幾件沒人再穿的小生戲衣，還有一只早停了的懷錶。

戲箱要重開了。這一季，春雪社得排出一齣自己的新戲，趕在年底那場會串之前。至於箱底那些沒說完的舊事，沒有人交代該怎麼辦。

  1. 白韻秋白公館繡樓 → 練功房
    我是白韻秋，晌午本該去霞飛路逛洋貨，可心裡頭那樁事總放不下。我分不清自己要的是台上那個風流小生，還是卸了妝朝我笑的那個人。柳老闆這會兒正在練功房排戲脫不開身，我偏不去逛街了，去戲園後頭轉轉，哪怕遠遠聽一耳朵他的嗓音，也比我坐在洋行裡瞎琢磨強。
    要找 柳生春：尋個不礙事的角落守著，等她歇息的空檔，好好看看她卸了半妝、汗津津的真實模樣，再同她說幾句體己話
  2. 蘇映雪二樓書寓 → 練功房
    日午該去練功房排新戲，肚裡卻空著，得先去戲園前街尋個攤子打尖。何況生春這時辰定在練功房吊嗓走位，我端著點心過去，正好替她留一份，也順道對一對生旦的戲。先跟韻秋應酬一聲，免得失了分寸。
    要找 柳生春：把買來的點心遞給她，說路過順便買的，留了最好的給她，趁隙問她新戲走位合不合拍。
  3. 金鳳會樂里寓所 → 後台小廂房
    日午才醒，枕邊冷清。會樂里這會兒靜得只剩我自個兒，那盆晚香玉還在窗台，教我又想起柳生春。晌午本是理會堂會體己的時辰，可心裡那樁事壓著，不討句準話，做什麼都不踏實。先認準時辰，再去後台小廂房尋她，趁她午間歇息，當面要個交代。
  4. 沈雪笙沈宅小樓 → 後台妝閣
    日午了，按理該去後台妝閣坐鎮，看今日排不排戲、看帳看人。可這心口被那舊事堵得慌，白蘭走時車燈的影子總在眼前晃。先去妝閣，若柳生春在，便看看她近日的模樣，她那扇子太像當年，我想借她這出戲，定定自己這顆心。
    要找 柳生春：看看她今日的狀態，若她在吊嗓或練功，便就近看她幾眼，觀她扇子裡的火候與心氣
  5. 柳生春後台小廂房 → 練功房
    我眼下乏得厲害，肚子也空，偏生金鳳就在這屋裡。她是教會我這身子門道的人，我欠她一句了斷，繞著走了這些年，如今避無可避。可班主那邊排戲催得緊，師姐也在，我若在此刻跟金鳳糾纏，怕是難以脫身又惹師姐不快。先認準時辰，隨便尋口吃的墊墊肚子，再去練功房應差，順便躲一躲這屋裡的尷尬氣。
  6. 江聞鶴後進廂房 → 練功房
    日午本該去練功房吊嗓走位，可剛想起包廂那回滿堂叫好的慌，心裡怎麼也靜不下來。柳生春此刻也在，我且先去練功房，趁排戲前的空檔，看看她那口氣是怎麼練出來的，也定定我自己的心。
    要找 柳生春：趁無人時，直問她方才走身段的步法，想探探她那小生是怎麼拿命換的，也較一較勁
  7. 連翹戲班大通鋪 → 練功房
    日午正是練功的時辰，班主既叫了排戲，我這刀馬旦便不能怠慢。想起當年沈雪笙站上台心滿場皆靜，如今她雖下台算帳，我卻急著趁這身子還站得住，在台上掙出我的名字。先去練功房走位吊嗓，叫春雪社的人看看我這從雜技場滾出來的硬本事。
    要找 柳生春：借個位子走位，順道打量這位春雪社的小生有幾分真本事，值不值得我給他托戲

霞飛路的洋貨原是晌午的消遣，白韻秋卻連街也懶得逛，徑投戲園後頭來。心裡那樁事縈繞不散，台上那風流小生與台下那含笑之人，孰真孰幻，她實在分不清，只盼能遠遠聽一耳朵嗓音，好強過在洋行裡瞎琢磨。踅到練功房外，裡頭身影騰挪，是柳生春正應差排戲。

柳生春方才從後台小廂房脫身。屋裡那個金鳳，是教會她身子門道的人，欠了一句了斷，繞著走了這些年，如今避無可避；可班主催得緊，師姐又在前頭，若在此刻糾纏，定惹師姐不快又難以脫身。她腹中空乏，只得先尋口吃的墊墊，硬生生躲了那屋裡的尷尬氣，這會兒正強打精神在練功房裡耗著。

白韻秋自角落輕步走近，將一條熨得平整的月白汗巾子與一盒玫瑰露香膏，不著痕跡地擺在她手邊的長凳上，輕聲道：「柳老闆，擦擦汗，當心招了風。」

第1日·黃昏
本時辰 · 各人的決定與去向
  1. 白韻秋霞飛路 → 後台妝閣
    這會兒是黃昏，柳老板剛得閒歇在後台小廂房，我那包廂也早訂好了。我先定準時辰，隨後動身去戲園。雖說我進不去他的廂房，但守在後台妝閣一帶，總能碰著他出來透氣。我想弄明白自己要的到底是台上那個人，還是卸了妝朝我笑的那個人，總得見著他卸妝後的模樣才甘心。
    要找 柳生春：守在妝閣外頭等他出來透氣，想看他卸了妝、不設防的樣子，若見著了，便輕聲問他今兒累不累
  2. 蘇映雪雲錦台戲台 → 二樓書寓
    黃昏散了工，本該回二樓書寓歇口氣，可方才一眼瞧見金鳳還在台上，心裡那筆舊帳又翻湧上來。我偏不上樓，就在這雲錦台待著，看金鳳到底要做什麼。她若還賴著不走，我便也守著——我倒要瞧瞧，生春不在時，她一個人在這台上能尋出什麼滋味來。
    要找 金鳳：不動聲色地走近她，似是隨意寒暄，實則探她為何此時還留在戲台，言語間暗中敲打她與生春的那些舊事
  3. 金鳳雲錦台戲台 → 會樂里寓所
    我還在雲錦台，本該回會樂里理妝預備出局，可瞧見江聞鶴與連翹在，心裡惦著柳生春，便想先探探口風。她那小廂房就在後頭，我偏不去等，就守在這戲台邊，看那冷淡人今日回不回轉。要是不在，我再回會樂里不遲。
    要找 江聞鶴：問他今日可見著柳生春，順便打探春雪社排戲的動靜
  4. 沈雪笙後台妝閣
    黃昏該理帳，但見白韻秋在此，我這後台妝閣便不是清靜地。方才舊事上心，那隻停了的懷錶像塊寒冰壓在胸口，教人喘息維艱。且先問準時辰，再定奪是陪這位綢緞莊千金敷衍幾句，還是收了帳本去衣箱房裡對著那樟木箱子喘口氣。
    要找 白韻秋：擱下筆，看她一眼，淡淡問她這時辰來後台是有何貴幹，還是單來聽戲。
  5. 江聞鶴雲錦台戲台 → 後進廂房
    黃昏散了工，我看見連翹還在戲台，心裡卻總繞著柳生春那口氣。本該回後進廂房歇著，可年底大會串將至，我這身紹興班的老本事到底還能不能叫上海新看客買帳？不如先回房靜一靜，再細想那回包廂叫好時心裡的慌，理理這幾日排戲的勁頭。
  6. 連翹雲錦台戲台 → 戲園前街
    黃昏散了工，戲台上靜下來，我這心裡反倒靜不下。方才見沈雪笙坐在包廂算帳的模樣，叫我更急著要在這大會串前亮出真本事。先看準時辰，再回大通鋪換身利落衣裳，去前街小吃攤尋口熱湯——那兒人多嘴雜，興許能打聽到會串的底細，也好盤算我這刀馬旦怎麼在上海灘站穩台心。

霞飛路的洋點心透著西式香氣，隨白韻秋一併落進了後台妝閣。她微微側身，將手裡那匣子擱上妝台，輕聲道：「班主好眼力，我哪敢添亂，不過是來給柳老板送點霞飛路新到的洋點心，嘗個鮮罷了。」話雖說得軟，眼波卻只在這戲園後台尋覓，一心想見著那人卸妝後的模樣。

沈雪笙原守著帳本理帳，舊事上心，只覺胸口的懷錶寒冰似的壓著喘息維艱。這會兒見了來人，這妝閣更非清靜地了。她將那匣子往妝台邊推了推，指尖輕叩兩下桌面，涼涼道：「洋點心甜膩，唱小生的嗓子最怕這個，你替她嘗了罷。」

話落，室內靜了一瞬。白韻秋指尖微蜷，將那匣子不動聲色地攏回身側，垂眸淺笑：「班主說的是，是我欠考量了。那我自個兒帶回去受用，總不至於糟蹋了好東西。」

沈雪笙見她攏回匣子，便不再看那點心，只拿起妝台上的摺扇在手心裡輕敲了一下，看著鏡子裡她的人影，話裡透著霜意：「你是明白人，東西帶回去受用，總好過送到嗓子眼裡作病。」這明白二字，既是敲打，也是了局，這後台妝閣裡的暗潮，便皆收在這一記扇敲之中了。

第1日·入夜（入夜）
本時辰 · 各人的決定與去向
  1. 蘇映雪二樓書寓 → 後台小廂房
    入夜了，本該歇著，可腦子裡全是那年除夕的水袖暗號和她沒喊出口的字。新戲的旦角要緊，可沒有生春對戲，這角兒立了也空。我穩了一輩子，今夜偏想去後台小廂房尋她，把那份生分拿水袖挑開，哪怕只對一折也值。
    要找 柳生春：找她對一對新戲的生旦身段，特意使出水袖第三道的暗號，看她接不接得住這份舊情
  2. 白韻秋後台妝閣 → 包廂茶座
    我守在後台妝閣，原是想等生春得閒出來，看他不設防的模樣。可眼下沈班主在這兒，我一個千金小姐死守著後台太著痕跡。罷了，我先回包廂聽戲，那兒本就是我入夜該待的地方。若生春今兒有戲，台上也能見；若他歇了，待會兒散了戲我再來妝閣外頭守著，那會兒班主興許不在，我還能輕聲問他一句累不累。
    要找 柳生春：守在包廂看戲，若他今夜登台便看他的眼風；待散戲後再去妝閣外守他透氣，想看他卸了妝的模樣，輕聲問他一句今兒累不累
  3. 金鳳會樂里寓所 → 霞飛路歌場
    入夜了，該是上霞飛路歌場掛頭牌的時辰。這個月的堂會得撐住，會樂里的門面不能塌。可臨出門，看見窗台那盆晚香玉，又想起她把我摟過去的那夜。得先問準時辰，再動身去歌場。柳生春今夜若也在後台，唱完堂會我總要去討她那句欠我的話。
  4. 沈雪笙後台妝閣
    入夜了，肚裡空得發慌，心口又被白蘭走那晚的舊事揪了一下。我得先認清時辰，再去戲園前街尋個攤子吃口熱湯暖暖胃，順便看看外頭的動靜。今夜大會串在即，柳生春那柄扇子太像當年的我，總讓我心驚，吃了東西還是回後台妝閣坐鎮，守著這戲班的人心。
  5. 江聞鶴後進廂房
    入夜了，待在後進廂房心裡總是不踏實。離大會串只剩六天，那回聽滿堂為柳生春叫好心裡的慌還沒散，嘴上不服歸不服，我倒想再去看看她這口氣到底是怎麼養出來的。先問清時辰，再去她那後台小廂房尋她，哪怕只是隔著門較勁幾句心裡也安生。
    要找 柳生春：去找她較勁，看看她夜裡都在琢磨什麼戲，話裡藏著那股子不服，其實是想探探她拿命換的本事究竟是什麼樣
  6. 連翹戲園前街 → 戲班大通鋪
    入夜了，我先定準時辰。當年那個滿場皆靜的名角如今在包廂裡算帳，我非得趁自己還站得住，站上台心給她看不可。大會串在即，我這刀馬旦的亮相絕不能只剩熱鬧。先回大通鋪歇著，心裡盤算明早怎麼在練功房把槍花和翻身練出個叫上海不得不看見的準頭，這是我替自己掙名字的營生。

那記扇敲的餘韻猶在妝閣裡沉澱，白韻秋卻已轉身抽離了那片逼仄的暗潮。千金之軀死守後台終究太著痕跡，倒不如退回本該待的去處，守個進退皆宜的餘地。過場只在一挪步間，包廂錦墊已承接了她的身姿。

戲台光影搖落，滿座喧闐皆作了虛設。白韻秋倚進軟墊，茶盞擱在指節間，倒似捏著一方涼透的玉，忘了沾唇，也忘了案上那縷茶煙。她一顆心全懸在台口，目光越過那些明滅的脂粉與水袖，不去尋別個，只尋她摺扇展處那點眼風。那扇骨开合的瞬息，才是她今夜入戲的憑據。若柳生春今兒有戲，這眼風便是隔著萬重光景的輕聲問候；若她歇了，這滿台的繁華亦不過是待會兒散戲後、再赴妝閣外頭守候的熬煎罷了。戲腔穿雲而來，白韻秋的指節只隨那扇影微轉，半闋茶，一更漏，皆懸在那一抹眼風裡。

〔心〕這身子是她一寸寸暖回來的，如今我卻連正眼瞧她都覺得燙。

  6. 連翹後台妝閣 → 練功房

  7. 連翹雲錦台戲台 → 戲班大通鋪
    黃昏散工，今夜大會串定生死，我那出武戲終於站台心，力已用盡只剩咬死。那指腹紅印的準勁刻進肉裡，我得先回大通鋪卸下這身硬甲，養足了勁。腦中閃過蘇映雪白日裡那句寬心話，不知她這嗓可真備妥了？去瞧她一眼，再回鋪子歇著。
    要找 蘇映雪：今夜是生死局，我那武戲站台心，你的嗓子也得撐住，來問一句穩當話。

扇骨抵著旗牌，半寸裡逼出那句「真刀真槍才過癮」；那頭妝閣帳桌前，亦是半寸不讓。白韻秋將那錦盒擱下，蓋子沒合嚴，露著半截水紅綾子，她一雙眼只看向帳桌後的人：「沈老闆，我這心意乾淨，您替她收了，可是替她作得了主？」

沈雪笙端坐帳桌後，眼風未抬，只將那錦盒蓋嚴，修長指節正正按上那半截水紅綾子，便往回推。白韻秋豈容她就這般推還回來，當下一把按住錦盒蓋，指尖順著那截水紅綾子往回捋，直抵住她按著的指節，逼得兩下相觸，這才抬眼迎上帳桌後那沉沉的目光。

沈雪笙指節未退半分，反倒反手一翻，穩穩壓住她那截指尖，將這錦盒連同那截水紅綾子一併扣死在兩人之間，聲音不高卻字字分明：「白小姐的心意乾淨，可春春的戲衣向来只進自己的箱。」水紅綾子紋絲不動，生生被夾在兩女交疊的指下，誰也沒鬆這口氣。

    要找 柳生春：趁他登台前堵他，問他既認了心虛欠我，這債打算怎麼還，看他在我面前還躲不躲得開
  2. 蘇映雪雲錦台戲台
    入夜了，今夜霞飛路就要打對台，這一場見高低，心裡的帳也該有個了斷。我守在雲錦台等生春，他扣我手帶那半寸的私心被我兜了底，我退的半步也是真怯了，今夜再不許他拿水袖把話兜過去。我先認準時辰，就在這兒守著他來，非要他當面把話說開不可。
    要找 柳生春：直盯著他逼問：我退那半步是真怯了，可你扣我手帶那半寸也是真，今夜登台見高低，你這輩子的心到底肯不肯真給我？不許再拿水袖把話兜過去。

    要找 柳生春：等她備戲出來，當面跟她把壓腕換步的勁道再對一對實處，告訴她今夜台上死力換的跪步配上雲步的活氣，咱倆這牌扛到底。
  4. 白韻秋後台妝閣
    入夜本該去包廂聽戲，可我推的錦盒被退、他按脈門又說唱不起，這不甘心哪能就這麼退場？此刻他既在後台小廂房得了閒，我偏不守規矩去包廂坐著，得去後台尋他，問清楚那聲「太貴」是他自己劃的線，還是替誰守的門。沈班主和江小生在妝閣，我避開他們直接去廂房。
    要找 柳生春：問他那聲「唱不起」究竟是他自己心底的線，還是替旁人守的規矩，我這甘願的真心，到底哪一點是他還不起的。
  5. 沈雪笙後台妝閣
    入夜了，今夜霞飛路打對台，我本就該在後台坐鎮。白韻秋和江聞鶴都在妝閣，我且先看清眼下時辰與局勢。韻秋那未合嚴的錦盒和沒說開的話，還有今夜春春的台，都得我兜著底。我既信了連翹能站住台心，便先成全韻秋的體面，看看她這錦盒裡究竟要替春春擋多少風浪。
    要找 白韻秋：端坐帳桌後，目光落在那半露水紅綾子的錦盒上，等她把話說全，看這白家千金今夜究竟要用多少體面來護春春，我自兜著這茶涼的底。
  6. 柳生春後台小廂房 → 霞飛路歌場
    夜深了，今夜大會串就要見高低。江聞鶴那實打實的跪步、師姐逼到眼前的盤扣，還有金鳳那句欠了太久的交代，全壓在心口。這身風流殼子再也兜不住了，我得先認準時辰，去霞飛路找金鳳把這筆心債了結，哪怕她正忙著，我也要把那半寸啞聲替自己掰扯清楚。
    要找 金鳳：等她唱罷下台，迎上去把話說開：欠她那句了斷，還有我這身風流殼子底下的心虛，今夜都給她交個實底。
  7. 連翹戲班大通鋪 → 後台妝閣
    今夜是見高低的最後關頭，我那出武戲準能站台心，是沈雪笙替我認的準勁，也是我拿槍掙來的。入夜了，我得先確認時辰定準心神，再去後台妝閣找她。指腹那紅印還刻在肉裡，上台前我倆得再對一對這咬死的勁，力已用盡，今晚只許成。
    要找 沈雪笙：上台前再見她一面，對一對這咬死的勁，今夜台心是她的也是我的，定要站穩了。

那截水紅綾子還僵在兩女指下，這頭金鳳的指尖已另起了一處局。她趁柳生春登台前將人堵在霞飛路歌場，抬手拈住她戲服衣襟，指尖不輕不重地搭上她後腰那點，半笑不笑地盯著她眼：「柳老闆，認了帳可不算完，這債你打算怎麼個還法？」柳生春脊背微僵，卻不躲她指尖那點勁道，只低眸看她一眼，笑意仍舊漂亮地掛著：「金鳳姐姐的債，幾時輪到我說了算？」金鳳沒接話，只拿沉默將這纏鬥的弦又繃緊半寸。柳生春見她不作聲，反手扣住她搭在後腰的那隻手，拇指壓上她腕骨，指尖不輕不重地摩挲著那處脈門，貼近她耳根低聲道：「怎麼還，妳一寸一寸算出來的，還要問我？」

歌場這寸寸算計的脈門尚教人攥著，後台妝閣那頭亦是按實了勁。沈雪笙替連翹正了正靠額的片子，掌根順勢壓上她虎口那道紅印，按得極實。連翹反手扣住她腕子，沒推開，只將那道紅印死死抵回她掌心，掌心向上，把勁全卸在自己這頭。沈雪笙任她扣著腕子，另隻手端起几上涼得正好的梨湯，送到她抵著自己掌心的那道虎口邊上。連翹低頭就著她的手將梨湯飲盡，嚥了一口，握腕的手卻沒鬆半分。戲衣箱畔的水紅綾子未解，這廂交疊的腕與虎口亦未鬆，皆是一分一寸地咬死在今夜的檯面底下。

誌

各人視角

同一段日子，各人心裡是另一本帳。以下是各角色逐日的第一人稱自述（主觀、或有偏頗），與上面客觀的時辰章回並存——讀者可只跟著一個人走。

柳生春 的帳小生

第1日今兒那方月白汗巾和玫瑰香膏，到底還是收了。白韻秋那目光越過戲台追著我，我哪能不知？明知是惹不得的殷勤，我竟照單全收，就貪圖被人捧著的心軟。了了舊債又欠新債，這風流債何時還得清？我這身子還要演多久才夠？戲比天大，台下不能塌，可這心，怕是早不知哪般滋味了。

第2日今兒師姐替我理鬢角，那聲「師姐」我唱得比許仙還順，扣她手背那下我是真捨不得退，可還是退了。轉頭金鳳逼問晚香玉，我認了養，也得認那六七年的心虛。繞著會樂里走哪是排場，分明是怕，可「心虛」兩字今兒終是說出了口。白韻秋的債還掛著，但我這風流殼子既裂了縫，欠金鳳的交代，這身子究竟還能不能守住個真心？熬著吧。

第3日今兒師姐攥著我脈門說「可長」，逼到跟前我竟犯了慣性後仰，這半步一退，欠她的交代更不敢給了。轉頭替白韻秋攏袖，指尖蹭過那瞬暗火生了根，明知是眼風惹的，我偏連這份殷勤也照單全收。風流殼子是她們縱出來的，可真要掏心時我卻只敢往後躲，這身子哪面是真更糊塗了，還守什麼真心。

第4日今夜心口還燙著，師姐替我攏袖那瞬，我捉住她的手按實了，這風流債終究是真的。半步未退，那亂脈便是我的底，可欠金鳳的交代更不敢給了。江聞鶴那下跪步實在狠，他磕的膝蓋比我這風流殼子真，我擲扇截他，倒像截自己的心虛。今兒台上還沒上妝，戲倒演全了。

第5日江那託氣死力是真的，可我攥他襟口時心裡全是虛，風流殼子到底兜不住真話。白小姐那帕子沾了蜜，我嚐著甜卻只敢當是逢場作戲。最要命的還是師姐——我扣住她手、拇指碾過她指節時啞聲說沒躲過，她卻抽手退開，連那半寸都不留給我！指尖替我理扣子那下比金鳳隔開我更冷，她非要把欠的交代翻成現眼，我攥得越緊越是空，這心虛真要把我逼瘋了。

第6日江那股子死力是真的，可師姐的袖比他膝頭更硬，我冷眼看著罷了。倒是白韻秋，我拇指碾著她脈門推開時，那半寸空忽然漏了底。風流殼子能擋殷勤，遇著真較勁倒逼出我的實底——我說唱不起她的脈案，啞聲竟成了真話。欠金鳳的交代連殼都替我遮不住了。可那又怎樣？托不住，便不配掛這牌。

第7日那灰鼠斗篷的餘溫還黏在肩上，白小姐這筆賒帳真重，我笑著收了，心裡卻直發虛。江聞鶴遞來的真刀我敢接，可金鳳扣在我後腰的手才叫逼債，我摩挲她脈門討饒，欠她的交代到底無處躲。最要命是師姐，我將她的手往心口貼，本想逼出個底，她反倒反扣住我直視眼底。風流殼子遇著她那較勁便碎，這落不落的戲，真底已由不得我演了。

金鳳 的帳歌女

第1日今天霞飛路晃了一日，沒半點要緊事，心裡反倒空得慌。會樂里的堂會得撐著，可妝鏡裡看著，眼角到底添了細紋。帳本是了了，可我金鳳也老了，這嗓子撐到餘下幾年，究竟還要唱給哪個聽？台下那幫人捧的是風流爽利，誰真懂我的心？十年金銀堆不出個真心，我認準的死扣從不鬆手，只是夜深了，難免苦澀。

第2日她親口認了心虛，我原以為要的就是這句，聽見了倒覺著不過如此。繞著會樂里躲我這些年，一句心虛就打發了？晚香玉她說養，那就養著吧，反正是她搬來的，她不許叫花替她乾熬，我倒要看看這花熬不熬得住她那躲法。認了欠我，往後幾年我就有個討債的由頭了。柳老闆，你躲得了一時，這債你可賴不掉。

第3日今兒晃了一天，場面上照舊笑得爽利，心裡卻盡是他昨日認虧的聲氣。本以為要的是她認欠，真聽進耳裡竟覺不過如此。如今討債的由頭是捏在手裡了，可這晚香玉熬得住她那躲法嗎？我還剩幾年去熬她？霞飛路的金銀堆不起我的心，認準的事我拖多久都不鬆手，哪怕只剩我乾等。

第4日今兒晃了一天，淨想她那句心虛。她認了欠，我本以為痛快，真聽進耳裡竟覺不過如此。討債的由頭是有了，可她那躲法，晚香玉熬得住，我還剩幾年熬？我金鳳向來不鬆手，可拿著這由頭討一輩子，算贏還是算拖？罷，哪怕只剩幾年，這債她賴不掉。

第5日今兒晃了一天，心裡卻淨是他那句心虛。他認了欠我，我以為要的就是這句認帳，真聽進耳裡倒覺不過如此，空落落的。討債的由頭是有了，可他連晚香玉都不敢正眼瞧，就這麼躲法，我還剩幾年好熬？我金鳳不哭不鬧，認準了就不鬆手，他欠我的，這輩子別想賴掉。

第6日晃了一日，今兒沒要緊事，可腦子裡淨是她昨兒那句認心虛。她既親口認了欠我，這討債的由頭算落了地，可晚香玉熬得住她這躲法？我剩幾年陪她躲？我以為要的是她認欠，真聽到了才覺不過如此。罷了，債主是我，她躲多久我都不鬆手。

第7日她反手扣我腕骨那下，指尖摩挲脈門的勁道，燙得我心裡一顫。我原以為逼她認帳就贏了，真聽她低聲說我一寸寸算出來的，才覺不過如此。認帳有什麼用？這債她既親遞了把柄，我便絕不鬆手。這幾年晚香玉我熬得住，往後她親自來還，我看她躲到幾時。

蘇映雪 的帳花旦

第1日今天晃過就完了，什麼也沒發生，可心裡總懸著。排新戲的旦角要出彩，雲錦台的場子得掙下來，我懂。可閒下來滿腦子卻是她水袖遞來的氣息。大會串前，多盼能再跟她對一場生旦，哪怕只多挨著一寸，也是好的。這心思我不認，穩得住場的殼，總得死死扣著。

第2日替她理鬢角，指尖才沾著髮根的溫，我掐著勁收了手，誰知她反手扣我手背那下，直勾得我心顫。她偏退開半步，笑我最吃她這套聽話——我這輩子，確實是栽在這退不開的半步裡了。白蛇出塔的步位還沒合穩，多對戲的私心倒越發收不住；全上海都說我蘇映雪穩得住場，可她髮根的熱還在我指尖繞，這殼，早從裡頭裂了。

第3日她拇指按上我脈門那下，白蛇出塔的氣全散成了她的熱。我腕子被攥著，那句私心竟被她聽成了真話。她問我捨不捨得，我這退了八年的半步哪還有路可退？我笑著替她攏鬢髮，說這輩子可長，其實心裡慌得發顫。她扣著我脈門說沒騙我，我卻怕她眼裡真有我，真有我，我那拿分寸換來的殼可就要碎了。

第4日她捉我的手按上心口說不退了，那一瞬我這半步便成了懸崖邊最後一寸，進退皆由她。替她攏扣子時我手多穩，裡頭的脈就多亂。她偏還蹭我手背，漫不經心要我順脈，眼裡哪有半分做戲？我笑著理平她袖口，拿一輩子的分寸換回殼裡，可那心口燙人的私心還在發顫。我不退了，妳可得認帳。

第5日今夜那半寸，險些拆了我的殼。她拇指碾過指節時，我脈搏全亂了，逼人的話倒被她兜了底。她說沒躲過，我竟心怯，抽手退開，拿金鳳刺她，只怕自己真敢信。指尖虛虛理著那粒皺扣子，明明想攥緊，卻偏替自己搭回殼裡的梯。柳生春，我退了這半步，你何時才肯再進來？

第6日今日無事，我卻晃得心慌。滿腦子全是他昨日扣我手帶、拇指碾我指節的觸感，他說沒躲，我拿金鳳刺他，可真怕的是自己信了那份私心。我替他理那壓皺的扣子，指尖虛虛搭著，裡頭脈搏早亂得不成樣，我卻還得笑得滴水不漏。我這穩得住場的殼，終究是我先怯了半步才退回來的梯。我真想不管不顧，下次他再近前，我偏不退這半步。

白韻秋 的帳客

第3日她替我攏袖時指尖蹭過手背，那點熱像生了暗火，燒得我半宿沒褪。糖粥她終究沒接，可那聲「金貴」和那一攏，便是受了我的心意罷？班主敲扇截禮時我原以為自己只是被擋在門外的俗物，可她沒躲我的眼風，反倒先替我攏袖……我的體面原只是甘願低進塵埃的藉口，可她既受了這暖，這場子我更退不下了，我就是要一寸寸把這心意填進她心底去。

沈雪笙 的帳班主

第1日夜深了，那匣洋點心的甜膩還膈應在心口。我替春春擋了，像替當年沒人護的自己鬆了手。可白韻秋攏回匣子時手太穩，明白人眼裡那點忍下的委屈，我偏不愛看。我越界護人成了癮，連盤點心都要替人拿主意，到底是大哥還是糊塗帳？這回大會串，我非得替自己唱一出口心合一的戲不可。

第3日今夜她攥錶亮架的狠勁，直把我的心都勒緊了。那停擺十五年的錶交出去，竟像遞了刀，替我那沒開的扇續了命。她腕骨一轉說要上弦，脆是脆，可那股拼勁教我揪心。上弦容易，我怕她這泥裡打出的身骨，真把十五年的弦繃斷了。我這越界護人的手是收不回了，只盼她挑得起這樑，也留得住自己。

第4日今夜我拇指還殘著她腕骨的倔，那股收命的死勁終算卸給了槍，我這懸著的心才落定。可白韻秋那盅燕窩燙著了我的手！她直迎我審視，偏說白家補品乾淨不圖綁票，我替連翹撥軟釘子竟成了多事？我護了十五年的風骨，哪容她來礙！那錶我攏進袖底，停擺的半生既交了出去，就看連翹自己接不接得住，至於我，可還能再開回扇？

第5日連翹腕上那道紅痕硌得我心底發緊，可看她把槍咬死在虎口，替我擰了三圈懷錶，那句「敢不敢使力」倒真把我停擺的半生逼出了走字的心跳。我這手原是多事替人撥釘子，如今倒成了被她上弦的人，真盼她站穩這台心。至於白韻秋那盅補品，什麼乾淨心意，我偏不收！軟釘子紮回去，全是替春春擋的刺，我的心意才不讓她白家隨便買。這扇到底敢不敢再開，就看連翹這弦挑得穩不穩了。

第6日她把錶按回我掌心，說三圈擰死，往後台心是她的也是我的。我攥緊那錶，替她理鬢髮時心裡竟泛起舊癡，嘴上卻只叮嚀槍別生鏽。她亮出虎口紅印，準勁咬死不鬆，我指腹重重一捺認了這底，隨即收手撇去茶沫。這血熱與茶涼的滋味全得我自個兜住，攥錶的手再收不回那替人撥釘子的慣性，可這停擺的半生既由她上弦，我總算盼到人站穩了。

第7日白韻秋那水紅綾子想往春春箱子裡塞，我偏扣死不退，誰的戲衣誰作主。可轉頭瞧見春春虎口那紅印，我掌根按實了替她撐，她倒扣我腕子不鬆，就我手飲盡那碗涼甜梨湯。這血熱與茶涼我一併替她嚥穿了，我這替人擋風的手早收不回來，她骨子裡的涼硬，如今是浸著我這口血撐起的台心。

江聞鶴 的帳小生

第1日今天晃了一日，什麼也沒幹。街上的照相機仍舊閃，我嫌刺眼，窩在屋裡聽見外頭柳生春的唱片聲，心裡煩。大會串一天天近了，我這膝蓋空落落的，不練就發慌。我還能拿命換幾回跪步？這新上海的熱鬧不認真本事，可我偏要他們看見。明日，我定要再上台走一遍。

第2日今天晃了一圈，這熱鬧城裡盡是些輕飄飄的看客，眼裡只裝得下拍照灌唱片。我沒碰戲，可心裡耗得慌。大會串逼在眼前，我這雙膝蓋還能拿命換幾回跪步？嗓子亮著，台步穩著，就怕新上海沒人懂得看這拿命換的真乾淨。今天算是白過了，明天得上台，偏得讓他們看看什麼叫真小生。

第3日今天晃晃悠悠就過了，沒台也沒戲，可我心裡那根弦沒一刻鬆過。瞧著柳生春在那兒被太太小姐們圍著，我不眼紅，只覺得荒唐。她懂什麼？我這紹興男班的跪步，是拿命在台上砸出來的。空蕩蕩晃了一天，膝蓋反而隱隱作痛，像在催命。大會串眼看就到，我還能撐幾回？怕只怕，我把命豁出去換了個滿堂彩，這身硬本事到了新上海，終究是留不住幾年。

第5日她扇骨指膝逼我，我硬折跪步卻借勢起身箝住她扇骨。她竟攥死我襟口，眼底笑意碎盡直逼我眼！我偏不避，挺脊樑頂住她這股子蠻力。她以為攥襟就是贏？我這舊本事的氣硬生生托住了她那死力，釘得她動彈不得！值了，這般交鋒才撐得住台。我還要她明白，少年郎立得住，靠的是這口托人的真氣，不是蠻勁。

第7日今夜這刀遞得痛快，她反手抵扇接了我的狠勁，眼底三分煞氣，到底是我的對手！我原怕這身跪步在新上海成了白費的死力，可她不躲，這小生牌便不是各打各的虛場面。台上見血不見淚，誰卸力誰栽跟頭，她不栽，我也不栽。真刀真槍拚出來的活氣，才托得住我這少年郎的骨，明儿台上，我非跟她見個真章不可！
