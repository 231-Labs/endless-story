序章

春雪社大會串告捷，戲箱重啟、滿堂紅彩剛落，《白蛇傳》的叫座聲還在弄堂裡打轉。

霞飛路新起的戲園趁勢落成，東家放話開園首日便排《白蛇傳》，要拿同一齣戲在上海灘搶這口新開的氣。

新園子包銀開得高，角兒跟班底皆在風口上，戲園子對台唱戲是規矩，搶的是客、爭的是勢。

春雪社剛穩住的檯面與箱底，如今外頭有了真刀真槍的對家，這場對台戲是避不過的世道硬局。

  1. 柳生春後台小廂房 → 會樂里寓所
    日午了，按營生本該去練功房吊嗓排戲，可心裡那筆糊塗帳逼得我坐不住。她要拔金鳳的暖，我問拔淨還剩不剩魂，這劫得當面過。這會兒金鳳在會樂里得閒，我得先去見她認了這身子債，再回來排戲也站得住腳。

  2. 金鳳會樂里寓所
    晌午才醒，柳生春竟在我會樂里寓所。他既來了，便是我手裡捏著的借據又送上了門。那糊塗賬討不回心，可他脊背往我掌心陷的那一寸，我非得再試一回不可。看他是躲還是貪，身子總比嘴老實。
    要找 柳生春：走近他，指尖搭上他後腰那顆小痣的位置，看他不由自主的顫，逼他認這筆欠我的糊塗帳。
  3. 蘇映雪二樓書寓 → 後台小廂房
    日午該去練功房吊嗓走位，可我滿心都是生春那身暖過的骨肉。去後台小廂房找她，趁排戲前把這筆帳討了，非揪著她衣領聽個心跳，把金鳳留的寸寸暖意拔乾淨，看她拔盡後還剩不剩我陪她立台心。
    要找 柳生春：揪住她衣領逼到牆角，手指探上她鎖骨聽心跳，逼問她身上金鳳的暖意拔不拔得乾淨，到底還剩不剩我。
  4. 白韻秋白公館繡樓 → 雲錦台戲台
    日午本該去霞飛路逛街，可沈雪笙那塊停擺的懷錶死死壓在我心口，她翻掌停駐的瞬間和拍出的舊時辰，比洋貨更叫我定不下心。柳生春扣我指尖不躲不避，她們倆的規矩我砸不開，但我這不退讓的底氣非得親自去認一認。我不逛街了，去戲園前街買碗熱糖粥，再去雲錦台候著，我這真金砸不碎的死規矩，就拿糖粥的暖意去探她們的底。
    要找 沈雪笙：捧著熱糖粥遞到她跟前，直直看著她的眼，問她那停擺的懷錶究竟是什麼時辰，拿我這不退讓的底氣去撞她那拍出舊時辰的手。
  5. 沈雪笙沈宅小樓 → 後台妝閣
    日午了，我這替人擋風的手既已收回，便該去後台妝閣坐鎮。昨夜掰開連翹指節按回銀洋的涼意，反扣死了我自己掌心，那拿心填的深淵得由她自己去頂。開了閣門看帳看人，也看看春春和她們今日排戲的底氣。
  6. 江聞鶴後進廂房 → 練功房
    日午該去練功房吊嗓走位，班主叫了排練脫不開身。可我滿腦子還是方才那陣真火，掌心砸進台板的死力還燙著虎口。這身紹興老骨血既已砸進去了，就得到場子上把那口真勁唱透。我要去練功房，找柳生春，把那半步裡的硬勁再砸實了。
    要找 柳生春：走到她跟前，攥緊剛才砸紅的掌心，直問她：咱倆這真勁既同砸同接了，排戲走位時敢不敢把這股死力全豁出來？我要真刀真槍跟她搭這齣戲。
  7. 連翹戲班大通鋪 → 練功房
    日午正是排戲走位的時辰，該去練功房。箱底空檔是她讓的，暗扣我認了，如今得靠身子站穩這塊板。我那七步半走到台心的腳感，今日得在排練裡當著眾人踩實了，讓他們看看這空板我是怎麼碾響的。江聞鶴在這，正好搭個手走個位。
    要找 江聞鶴：叫上他搭手走個生旦對陣的位，試試我這七步半到台心的步子穩不穩，順道看他對我這新來刀馬旦的身手是什麼眼色。

日午練功房裡，靠旗隨腳尖一挑霍地甩開，連翹衝江聞鶴揚起下巴：「江老闆，勞駕搭把手，走個生旦對陣的位，讓我試試這七步半到台心的步子穩不穩。」江聞鶴抬手虛虛搭住她腕子，腳下踩出半步讓出身位，沉聲道：「來。」連翹腳下踩出頭三步，借他讓出的空檔猛然擰身逼近，眼神如槍尖直逼他面門，刀馬旦壓場的煞氣登時逼出，步子落板，卻穩得沒一絲多餘晃動。江聞鶴順她煞氣往後讓了半步，腳跟剛沾地便硬踩回來，身形不塌，眼神穩穩迎上去，低聲道：「步子夠穩，就是這煞氣太直，少了個迴旋。」

私 · 床會樂里寓所　柳生春×金鳳

日午的會樂里寓所，日影沉沉。柳生春倾身凑近，额头抵上金凤的肩，声音低得像叹气：「暖拔净了，这壳子就是空的。空了，拿什么装她？」金凤不接这话，掌心顺着她后颈滑下，指尖精准地搭上后腰那点，不轻不重地按了一按。她脊背一颤，下意识往她怀里缩了半寸，眼睫垂落掩住眼底水光，低声道：「凤儿……你晓得的。」

她指尖在那点小痣上不放，甚至更重地揉了一揉，另一手却托起她的下巴，逼她抬眼：「我晓得什么？晓得你这身子只认我的手，心倒替旁人愁？柳老板，空壳子会颤么？」被她按着那点痣，她身子不由自主地软下来，却咬牙偏过脸躲开她的眼，手探入她衣襟寻到胸前那团软腻、狠狠一把攥住，声音又哑又乱：「颤……全认得你。你如今还要讨什么话？」

分鏡 · 5 拍

柳生春他倾身凑近，额头抵上她的肩，声音低得像叹气：「暖拔净了，这壳子就是空的。空了，拿什么装她？」

〔心〕这身子是你暖回来的，可魂是她的。你两样都要，偏偏两样都欠。

金鳳掌心顺着他后颈滑下，指尖精准地搭上后腰那点，不轻不重地按了一按

〔心〕那一寸陷进来的到底是躲还是贪，你身子认得我的手，心却还满嘴是那个她

柳生春脊背一顫，下意識往她懷裡縮了半寸，眼睫垂落掩住眼底水光，低聲道：「鳳兒……你曉得的。」

〔心〕她一按，這身子便不聽使喚地認了。欠她的，欠師姐的，哪筆還得清？

金鳳指尖在那點小痣上不放，甚至更重地揉了一揉，另一手卻托起他的下巴，逼他抬眼：「我曉得什麼？曉得你這身子只認我的手，心倒替旁人愁？柳老闆，空殼子會顫麼？」

〔心〕你欠我的，你這輩子也還不清。

柳生春被她按著那點痣、身子不由自主地軟下來，卻咬牙偏過臉躲開她的眼，手探入她衣襟尋到胸前那團軟膩、狠狠一把攥住，聲音又啞又亂：『顫……全認得你。你如今還要討什麼話？』

〔心〕這身子早賣給你了，魂是你替她守的，我還剩什麼可給。

了斷柳生春：她要拔金鳳的暖，這殼子若被掏空，還能裝得下她的魂嗎

本時辰 · 各人的決定與去向
  1. 蘇映雪後台小廂房 → 雲錦台戲台
    此刻我在生春的小廂房，白韻秋這外人在場，我偏不避。我滿心都是生春那讓金鳳暖過的身子，非要揪她衣領，把金鳳留下的暖意寸寸拔乾淨不可。班主的排戲拉力再大，也不及我此刻要將她釘進骨縫的執念。先問時辰定準心，再管眼前這不該在場的白韻秋。
    要找 白韻秋：冷眼看她，端起師姐的架子逐客：「韻秋小姐，生春這兒不是聽客待的地方，請回吧。」
  2. 白韻秋雲錦台戲台 → 霞飛路
    我原該去霞飛路閒逛，可那停擺的懷錶和她不設防的笑死死扣著我的心。方才眼角瞥見蘇映雪也在戲台，她既在，柳生春想必也不遠。我不甘就這麼退場去逛街，得去探探映雪，旁敲側擊柳生春如今的去處與心思，好尋準時機再遞我的底氣。
    要找 蘇映雪：上前與蘇映雪搭話，套問柳生春今日的行蹤與神色，旁敲側擊她們師門裡那停擺懷錶的事。
  3. 沈雪笙後台妝閣 → 衣箱房
    晡時該坐鎮后台，可那停擺的懷錶、按回銀洋的涼意，和連翹那口氣，全攪得我掌心發燙。那丫頭指尖攥死銀洋被我按回，這檯面她得自己頂，我倒要去衣箱房看看她，這靠旗暗扣的空檔她到底接不接得住。
    要找 連翹：守在衣箱房等她來，看這攥過銀洋的手如今穩不穩，那靠旗暗扣的空檔與我按落的涼意，她究竟怎麼去填。
  4. 金鳳會樂里寓所
    晡時午後本是我的閒空，肚裡也空了，可偏生柳生春就在這寓所裡。這人連本帶利都栽進了我糊塗賬，脊背陷進我掌心那點顫還烙在我手上，我哪還顧得上別處？尋吃食的念頭且放一放，他既在跟前，我便要再試試他，看他這欠債的身子是躲還是貪。
    要找 柳生春：走近他，指尖若無其事地搭上他脊背，貼著那處舊印，看他是躲還是貪，耳語問他這會子躲在我這兒，是避外頭的雨，還是避我心裡的帳
  5. 江聞鶴練功房 → 雲錦台戲台
    班主叫了排戲，這時辰我本該在雲錦台，可心裡那把火還燒著。昨兒跟柳生春掌心砸實、逼出真勁的滋味我嚥不下去，非得再找她把話說透：這小生牌既然血肉一塊釘了，對台前這幾天的戲得怎麼搭？我這舊功夫要有人真刀真槍硬接才算落地。先問準時辰，再動身去戲台找她。
    要找 柳生春：我要跟她把昨兒掌心對砸的那股勁說明白：既然咱倆這命都釘死在台上了，排戲就別留手，我要她真刀真槍接我這小生的跪步，看這舊功夫在新上海立不立得住。
  6. 連翹練功房 → 雲錦台戲台
    班主叫了排戲，這時辰該去雲錦台對戲，我這桿槍認了台心，營生便脫不開身。但臨走前，我得先在練功房把這口氣理勻——昨夜碾響的空板還在腳底，蘇映雪那句「不許拿」壓著我的樁步，我領口撥正、靠旗的暗扣已認實，踩進快靴前得先穩住這股勁，再去台上把這樁戲接穩。
    要找 蘇映雪：她壓著我那句「不許拿」，我得在她上場前，當面把話扣實：我這樁步踩實了，大會串的台心我自己碾響，不勞妳再盯，但這空檔我認了。
  7. 柳生春會樂里寓所 → 雲錦台戲台
    此刻人在會樂里寓所，眼前是金鳳，心裡掛著那夜身子與生死的糊塗帳。可班主嚴令排戲，師姐也在台上等著拔我這身暖。這一個時辰有限，我再黏纏，這身骨頭便真軟了起不來。先認清時辰，再當著金鳳的面認下這筆身債，隨後動身去雲錦台，把她和這債都擱下，上台去攥我的魂。
    要找 蘇映雪：歸班排戲，迎上師姐的眼風，任她來拔金鳳留的暖，這身子認帳，魂也一併交她手裡掀底。

步子落板，卻穩得沒一絲多餘晃動。江聞鶴順她煞氣往後讓了半步，腳跟剛沾地便硬踩回來，身形不塌，眼神穩穩迎上去，低聲道：「步子夠穩，就是這煞氣太直，少了個迴旋。」蘇映雪沒接他這半句話，只將戲服袖口一捋，越過連翹肩頭，指尖叩了叩她身側那面斑駁的戲箱，聲音壓得極穩：「空板我認了，妳只管看腳下。台心那三步，我自己碾。」連翹腳尖碾上那塊空板，薄底快靴踩實了悶響，直直迎上她的目光：「板響不響，我自個碾，不勞妳盯。」蘇映雪收回手，順勢將水袖一抖掖進腰間，眼底波紋不顯：「好，妳自個碾。」連翹抬腿一腳將那塊發空的台板踏實釘死，順勢踢開戲箱銅扣，箱蓋彈開露出裡頭壓箱的舊靠旗：「箱底這空檔，妳還替誰藏著？」這話落地，江聞鶴那邊的火已按捺不住，把袖口一捋，將昨兒砸紅的虎口直伸到柳生春眼前：柳老板，昨兒掌心對砸那股勁，心裡的氣咱拿本事算清——排戲別留手，我真刀真槍接妳，妳那小生的火也照實燒過來，看這舊功夫在雲錦台上立不立得住！柳生春拿摺扇骨輕輕一撥他伸來的虎口，眼皮都不抬，笑得涼薄：江老板，拿砸台板的狠勁來算氣？那您可算錯了行——戲裡的火候是心火，不是這股蠻力。江聞鶴不退反進，踩回原位吼出「接得住」。柳生春摺扇骨在他虎口上狠狠一敲，不再收勢，扇面嘩地甩開直抵他下頷，逼他仰頭：江老板，你這身蠻勁我今兒就接——真刀真槍，我也來！

了斷江聞鶴：掌心實砸互扣，她硬勁逼出我眼底發紅，這真火燒透了虎口。

了斷江聞鶴：我踩回原位吼出「接得住」，老戲跟小生牌釘死在這半步裡了。

    此刻我該去雲錦台排戲，可生春昨夜那聲「拿命還」釘在脈門上，這筆帳不砸實我上不了台。連翹拿槍尖逼我的舊帳也還在骨縫裡作痛。我且先問時辰，再去戲台，若生春在，我就當著排戲的由頭把她扣死，把昨夜沒說開的疼全討回來。
    要找 柳生春：趁排戲尋她，扣住她手腕按實脈門，逼問她昨夜那聲拿命還究竟是真是假，殼既碎了，這半輩子的疼今夜就要她全接住，誰也別想退半步。
  2. 白韻秋霞飛路商店街 → 後台妝閣
    晡時本該在霞飛路閒逛，可我滿心都是雪笙那句同扛風浪與她覆在我手背的冷指尖。這會子她應當在後台妝閣打理戲班帳目，我偏不去買什麼洋貨，就去後台守著她。我那三分熱的底氣既扛得起她的死局，就不該只在街面上乾轉，得去她跟前再認一認這筆風浪裡的欠債。
    要找 沈雪笙：等她忙完手邊的事，我要問清楚她掌心那塊錶既已攏住，這同扛風浪的底我倆究竟怎麼個扛法。
  3. 沈雪笙戲園前街 → 後台妝閣
    我原在戲園前街透氣，看著白韻秋與連翹在側。可連翹攥錶的那股死勁還梗在我心口，那紅印子像烙在我掌心，這事懸著我便定不下神。眼下晡時，我該回後台坐鎮，正好去大通鋪尋連翹，順順她那口繃得太狠的氣，把這樁同扛風浪的命真正說開。
    要找 連翹：等她練功回來，看著她攥錶的手，替她順一順那口繃得太狠的氣，告誡她大會串的台心要沉，別讓勁把自己傷了。
  4. 連翹後台妝閣 → 雲錦台戲台
    方才在台板上我把話砸實了，她交出玉扣，這帳我認了！可雪笙方才掰開我指節按回銀洋的涼意還扎在骨頭裡，她鬆手退縮，我偏要死扣！班主叫排戲，我這就拔步去雲錦台，先問準時辰，再上台板把這身硬靠穿實，等她來對戲，定要她親口應下這台心不許躲！
    要找 沈雪笙：攥住她手腕不教縮回去，逼她應下大會串台心同站的勁，這筆帳今兒釘死扣實，不許再藏袖底！
  5. 江聞鶴練功房 → 雲錦台戲台
    我人在練功房，原該去雲錦台排戲，可柳生春就在眼前。方才她扇骨指心口說接我的話還燙著，這蠻勁得趁熱再砸實一回。不去台前虛應，就守在這兒，把這小生牌釘死的事跟她當面鑿穿！
    要找 柳生春：攔住她，直問方才扇骨抵心接下真刀真槍的話算不算數，霞飛路打對台這場，敢不敢實打實跟我把這小生牌釘死，別留半點閃躲。
  6. 金鳳會樂里寓所 → 後台小廂房
    晡時閒空，本該在寓所歇著，可腦子裡全是他那聲低啞的「認帳」和掌心下他腰脊的軟。他認了身子本能，那筆情債倒成了我獨自解不開的死結。他這時辰多半在雲錦台備戲，我得去後台小廂房尋他，聽聽他除了「認帳」，那句欠究竟打算怎麼還，逼不出個心，也要他再認個清清楚楚。
    要找 柳生春：趁他備戲時堵他，指尖再搭上他腰側，逼問他既認了本能，這筆賴不掉的情債他究竟拿什麼抵、怎麼還
  7. 柳生春練功房 → 雲錦台戲台
    班主催排《驚夢》，江聞鶴那跪步的真勁還撩著我，心裡掛著要把許仙這段跟他合出個真章。可金鳳昨兒咬頸逼債的勁還沒散，腰膝發軟。我得先認準時辰，動身去雲錦台戲台，見著聞鶴就把這跪步的勁接死，拿戲裡的硬骨頭撐住我這快兜不住的風流殼子。
    要找 江聞鶴：趁熱勁走許仙跪步這段，我要拿實刀真勁接住他的力，把這骨頭撐硬了，倆人的勁得合到一處纔算立住。

腕間脈門被那兩根指死死扣住，蘇映雪逼得她退了半步，脊背堪堪抵上戲台的紅漆柱子。她眼眶早逼得通紅，喉間卻只擠出一絲氣音：「昨夜那句拿命還，算不算話？」

柳生春反手掙開她按在脈門的指，身子卻不退，反倒向前傾了傾，將額頭重重抵進她肩窩，嗓音悶在那層衣料裡，帶著認命的沉：「算。」

蘇映雪額頭抵著她發頂，空出的那隻手緩緩覆上她後腦，掌心貼著她髮髻輕輕往下按了一按。再抬起時，指尖只順著她鬢角捻過一寸便收了回來，嗓音微啞：「這話要是真的，往後那第三道水袖，你再接不住試試。」

柳生春抬手握住她收回的那隻手，將那微涼的指尖重新按回自己頸側脈動處，低聲道：「師姐的手，我哪回沒接住？」

戲台這廂寸寸交鋒，後台妝閣裡則靜得只剩算盶撥珠的輕響。白韻秋守在一旁，直等沈雪笙擱了筆，方將手邊那盞剛續過熱水的茶輕輕推到她手畔，開口道：「沈班主，既許了同扛風浪，這扛法總得有個準數。」

沈雪笙指尖在懷錶上停了一停，終是推開掌心，將那停擺了十五年的錶擱在茶盞與她之間的案面上：「準數在這兒，停了十五年的死局，你拿什麼上發條？」

白韻秋抬眼定定看向那停擺的懷錶，又望向她，將手覆在錶面旁的案上，不碰那錶，只認認真真道：「霞飛路白家的綢緞莊，經得起幾場風浪的本錢，我拿得出。」

沈雪笙將手覆上她的手背，指尖冷，按得實，將那停擺的懷錶連同自己的掌心一併圈在她掌中：「白老闆，這發條你既上了，可就別再鬆手。」

了斷沈雪笙：欠她的不再是單方交代，這氍毹風浪，如今是我倆一併扛的命。

  1. 連翹雲錦台戲台
    散了工，我這會兒該回大通鋪歇口氣，可心裡那筆涼茶帳沒釘死，腳下就踩不踏實。蘇映雪日晡才把玉扣拍在我掌心，說是了結，可她眼底的怯我看得真切。今兒非得去二樓書寓尋她，把這空板舊釘拔淨，不許她再拿誰的疼來抵這帳！
    要找 蘇映雪：把她拍給我的玉扣攥實了遞回她眼前，逼她承認這殼不是為金鳳碎的，是為自個兒。我拔我的舊釘，她不許再藏袖底，這帳今兒必須扣死！
  2. 白韻秋後台妝閣 → 包廂茶座
    黃昏了，我本該去包廂聽戲，可心裡那樁同扛風浪的欠債沒結清。雪笙方才將懷錶擱在案上推還給我，這動作是撇清還是託付？她既沒上發條，這停擺的時辰終究得我親手去接。我偏不按她規矩退場，先問準時辰，再守在這妝閣當面問她，這錶既推回來，這風浪我們到底怎麼個扛法。
    要找 沈雪笙：盯著案上那塊停擺的懷錶，不退不避地問她：「妳掌心既攏了又推開，這停擺的時辰妳若不接，我便自己替妳上發條。這風浪的底，妳許了同扛，今夜就跟我把話說到底，別拿規矩再擋我。」
  3. 江聞鶴雲錦台戲台
    黃昏散了工，我這膝蓋還磨著日午砸出的真話，肩頭硬接的債更重。柳生春還在台上，那扇骨逼喉的痴勁全漏了，我這舊功夫得有人同砸同接才算真落地。趁天未全黑，我得上前去，跟她把這肩頭接住的痴債釘死了！
    要找 柳生春：上前直問她，我肩膀硬接了她扇骨漏出的痴勁，這債誰也賴不掉，霞飛路對台那場，敢不敢跟我同砸同接，把這小生牌真釘死在台板上！
  4. 蘇映雪雲錦台戲台 → 後台小廂房
    我這兜底的手，今夜再不許旁人掀空板。生春既扣死我脈門說拿命還，這黃昏我便去她小廂房，把她逼進牆角，替她將那退半步的殼生生砸碎，攥死這骨肉。連翹那邊的爛帳且由她流自己的血，金鳳的恩情債也壓不住我今夜往前闖的實勁。
    要找 柳生春：拽她領口逼到牆角，扣死她手腕抵住脈門，冷聲質問她退半步的分寸今夜還往哪躲，非要她這骨肉全交我來攥。
  5. 金鳳後台小廂房 → 會樂里寓所
    此刻我人在他廂房，撞見蘇映雪也在。心裡掛著他認了身子是本能，那句欠仍壓舌根。這筆情債討成了我獨自的死結，她倒是他心裡的歸處。先看清眼下時辰，傍晚該回會樂里理妝出局，可這口氣堵在這兒，我偏要看看蘇映雪在他的地盤做什麼，再定奪走不走。
    要找 蘇映雪：冷眼看著她，問她來柳生春廂房做什麼，試探她在他地盤的底氣
  6. 柳生春雲錦台戲台 → 會樂里寓所
    黃昏散工，肚裡空得發慌，心裡頭金鳳逼討的債和江老闆接扇的癮攪成一團，更兼師姐就在這兒。我先認準時辰，再去會樂里尋金鳳——她那顆痣按著的債我認盡了，身子交底魂卻不敢掏，可這會兒她得閒，我非得去見她一面不可，躲不成也不想躲。
    要找 金鳳：去尋金鳳，任她按著頸側那顆痣逼討心債，身子由她扣著，拿六七年的熟門道應她，看這筆帳怎麼個了結法，魂卻仍不敢掏底。
  7. 沈雪笙後台妝閣
    此刻是第四日黃昏，距對台僅剩三日，我理當坐鎮後台妝閣理帳。可方才腦中忽地閃過連翹那桿槍般繃直的脊梁，與那反扣我腕子的狠勁——她那死磕的勁能接住死局，我這停擺的半生既被她硬上了弦，便不能再只隔著帳本看人。帳本且放一放，我得去大通鋪尋她，會一會她那撐得住台心的底氣，親眼瞧瞧她這會串的戲究竟拿什麼扛。
    要找 連翹：找她對一對那反扣我手腕的狠勁，問她既硬拿走我的錶與心，這霞飛路打對台的三日死局，她究竟拿什麼跟我一併扛穩台心。

那掌中懷錶的涼意尚未焐熱，連翹扣在她腕上的手倒先收緊了幾分，不容那指節有半寸退縮，另隻手反拍上自家背上那桿扎實的靠旗，脊梁挺得如槍桿一般：「扛台心？沈班主，我拿这七步半走到站不住的骨头，您拿什么？」

問聲落，妝閣裡的昏影似也被這錚錚骨氣逼退了半寸。沈雪笙不接那話頭裡的刺，只反手扣住她的腕子往下一沉，將掌心實實按上自家心口那件舊小生褶子底下的懷表輪廓，金屬硬硌著皮肉，恰抵著那跳得發沉的腔子：「我拿十五年没咽下的那口气。」

話音不重，卻似壓了千鈞。連翹指尖在她腕子脈門上重重一按，眼裡那團灼人的火忽地沉進骨底，反倒淬出幾分死生不計的定，另隻手反過來將她按在心口的掌背一把攥實，死死兜住：「好，您这口气我替您擂鼓，今儿这台心我站给您看。」

金鳳指尖驀地收緊扣住她後腰那顆痣，扯散她大褂盤扣，啞聲道：柳生春，這身子認我的手，你賴不掉——拿話來填。

〔心〕顫了。隨他心裡裝著誰，這點本能他賴不掉，我也要他親口認下這筆帳。

柳生春反手扣住她腕子，拇指壓住脈門不掙不脫，啞聲笑：拿什麼填？這身門道全是你教的，我認——可金鳳，你真要我把心掏出來稱，你敢接麼？

〔心〕她要的是那句交代，可我這句認到底的話，比交代更重——這身子的債我認盡了，魂裡欠的師姐那筆，我今夜也不敢藏了。

金鳳脈門被她拇指壓得發酸，卻不肯退半寸，反倒貼上前拿胸口抵住她，空出的那隻手順著她扯開的衣襟直探進去，指腹精準地摩過她肋下軟肉，貼著她耳根咬字極輕極狠：「我要你那顆心做甚？我只要 你認 欠我。」

〔心〕心掏出來稱？你那心裡裝的是別人，我接來也是塊烙鐵。可這身子瞞不了人，你抖什麼，柳生春。

柳生春被她指尖摩過肋下，脊背猛地發顫，扣她腕子的手驟然收緊，卻不推開，反倒順著她扯開的衣襟將自己貼進她懷裡，啞聲貼著她耳畔低啞道：欠你？好……我認。

〔心〕她要的不過是一句認，可這身子貼上來的熟，全是當年她一寸寸暖出來的，我怎麼敢讓她往裡再看一寸？

金鳳聽見那聲「我認」，搭在她肋下的指尖驟然一停，隨即那股狠勁全洩了，滿手只剩滾燙的顫，順著她脊背一寸寸撫上去，死死扣住她後頸，將她臉扳向自己，眼底紅透，唇幾乎咬著她的唇角迸出一句：「這話是你自己遞的——柳生春，往後少拿本能搪塞我，這一點一滴，全是我逼出來的情分！」

〔心〕他認了……可這句話拿到手，怎麼像生吞了塊炭，燙得五臟六腑都在疼。

〔心〕晚香玉……那是她會樂里窗台上那盆。澆了幾年的水，我竟當作她順手的事。連翹若在門外聽見這番討債，我這風流殼子全漏了底。

同一段日子，各人心裡是另一本帳。以下是各角色逐日的第一人稱自述（主觀、或有偏頗），與上面客觀的時辰章回並存——讀者可只跟著一個人走。

第1日鳳兒掐著那顆痣逼我認帳，身子抖了十年到底只認她的門道，可心虛的殼子今夜硬是被她按碎了——我認，這身債賴不掉。可門外她聽壁角討債的笑，全撞上師姐替我攏領口的那寸暖。魂是師姐給的，身子卻攥在金鳳手裡，我拿什麼去還？江聞鶴那蠻勁倒逼出我真底，明日雲錦台，骨頭得自己撐死。

第4日江聞鶴那砸落的跪步我只當硬碰硬的戲，拿命抵的話脫口也不覺疼；可師姐將手覆上我後腦時，我這脆骨頭竟真敢把命交底。誰知金鳳偏來攔腰撕開這風流殼子！她指腹摩過肋下那刻，我脊背的顫全洩了底，只能貼進她懷裡認了欠。她說這情分是她逼出來的，可我那聲顫明明是自己的！身債認了，可被她逼討出的心虛，下回再遇，我還站得住嗎？

第5日江聞鶴那死力碾進脈門，逼我認這脆骨頭的底，我倒真敢攥死不退；可金鳳指腹只往後腰一壓，我這身殼子竟本能地軟了。魂是師姐的，身是她的債，今日全逼到門板上討乾淨。可連翹偏偏撞見這漏底模樣，風流殼子碎了一地！那輩子的真心我本不敢認，如今被她討得連顫都藏不住，還能往哪躲？甜痛都攥死，這身債我認絕了。

第3日今兒蘇映雪認了涼茶帳，可她非扯金鳳，拿空板扎她，還笑我攥暖是空！我偏踏死那板，釘子紮腳我自個拔，不拿誰的疼來抵！沈雪笙替我掖襟扣靠，卻把懷錶縮回去，叫我別接她沒遞的。她沒遞又怎樣？我虎口死死扣實她手腕，她躲不掉！這帳與這勁，我不等誰施捨，非親手拿不可！

第4日夜深了，我反覆攥著自個兒的手，腕上還殘著她扣下來的沉勁。她拍著心口那塊舊褶子底下的懷表，說是十五年沒嚥的氣。好，那口氣她既交出來，我便替她死死擂鼓！今兒我這桿槍認了台心，七步半的硬骨頭走到站不住也絕不縮。靠旗再舊，板子是我自個碾響的；涼茶帳我替她討，這台心我替她站定了，一筆不攪！

第5日她那口梨湯我沒喝，她倒替我嚥了，七步半的台心她讓出來，這釘子我替她釘死在骨裡。可江聞鶴那廝橫手撥開我，拿話砸她輕骨頭！她輕不輕輪不著他拿身子砸！這過節我替她扛，我站死台心撐的樁，便算作數了，誰也別想再逼她退半步。

第6日他較命砸斷扇骨也嚇不退我，我偏扣死他虎口不退半步。他嫌我硬架子護不住她，笑話，我替她扛煞看樁，用的正是自家骨縫裡的勁！誰也替不得我定生死，這台心板子響不響，得我親腳踩出來才算。兩天後他砸他的死扣，我接我的槍，我走我的路，用不著他來替我扛！

第7日江聞鶴那桿槍我撈了，他較他的命，我紮我的台板，誰也替不得誰！可柳生春偏要怕踩塌我，她攥我腕、扣我指，說心是漏的，我便死死把她手背壓上我鎖骨——我這硬骨頭自家撐台心，塌不了，她只管靠！蘇映雪替她繫嚴了扣子，這破殼子往後能不能立著？能！我的樁我自家打，她的命我也一併扛了，年歲不等人，這板子我非得碾出響不可！
