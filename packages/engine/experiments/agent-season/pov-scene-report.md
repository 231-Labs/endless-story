# POV-scene probe — 同一場撞破，三個鏡頭

> 第1日·黃昏 @ 後台小廂房 · 修羅場（蘇映雪聞聲趕來、破門闖進，撞見金鳳×柳生春）

> **蘇映雪**：扶住門框站定，目光在兩人交纏處一掠而過，隨即垂下眼，聲音穩得像什麼也沒撞見：「金鳳姑娘，班主在前頭找你呢。」

> **柳生春**：趁金鳳轉身的當口，一把攥住她的手腕，力道緊得骨節都泛了白，頸邊青筋一跳啞聲道：「金鳳……別走。」

## 蘇映雪 的版本

我扶住門框的時候，手心裡全是冷汗，可我站得穩穩的。目光只一掠，便像被烙鐵燙了似的垂下來——生春的後腰，金鳳的指尖，還有她們交纏的影。我看見了，可我絕不能讓她們知道我看見了什麼。我聽見自己的聲音穩得像塊沒裂紋的玉：「金鳳姑娘，班主在前頭找你呢。」

金鳳那根指頭，正按在生春後腰那顆痣上。那顆痣，我替她擦洗過揉腫的腿時見過，她抽條後我卻連目光都不敢再留。金鳳按得不輕不重，像是宣示，又像是挑釁，這才慢條斯理地抽手。我盯著那截收回的手，胃裡翻絞得厲害——她們這是多久了？金鳳熟門熟路的模樣，怕是早就摸遍了生春身上每一處。她轉身對我笑：「勞蘇姑娘傳話，這就來。」我也笑，滴水不漏。

生春突然攥住金鳳的手腕，骨節都泛了白，頸邊青筋一跳，啞著嗓子喊：「金鳳……別走。」這句話像刀子，直直戳進我嗓子眼。別走？她留她做什麼？留她繼續把方才沒完的事做到底？我想起那個男人壓上來時我滿腦子都是生春的手，可如今生春的力氣全用在留金鳳。我恨這三個字，更恨自己聽得分明。

我抬手抖落臂上的帕子，上前一步。金鳳轉身去了，我不去看她，只看生春。領口盤扣鬆著，後腰那塊紅痕就那麼敞著，刺眼得很。我抬手替她繫扣子，指尖只碰布，不碰她。一扣一扣繫上去，把金鳳留下的痕跡嚴嚴實實擋住。我聽見自己聲音穩得挑不出褶皺：「師妹，扣子散了，仔細台前人笑。」我接的是她的場，擋的是她的難堪，可我更想擋的是那塊紅——那是金鳳替我蓋的章。

生春鬆開了金鳳，垂著眼任我繫扣子，不敢看我，低低應了聲：「曉得了。」她不敢看我。當年戲園前街，她看見我挽著顧敬亭，抬起手想招呼又放下，默默掉頭走了；如今換她坐在這，身上留著別人的痕，連眼都不敢抬。我替她繫好最後一粒扣子，收回手。距離剛好，分寸剛好。我穩住了場，像滿上海人說的那樣。可我心裡清楚，那年我先逃的，如今她後腰那塊紅痕，正燒在我自己心口上。

## 金鳳 的版本

門框邊多了一道影子，我眼尾都沒抬，指尖就擱在柳生春後腰那顆小痣上。全上海就我識得這地方，我不輕不重一按——她身子裡那點微顫，順著指腹直鑽進我骨縫裡。她心再淡，身子總認得我的手，這點作不了假。蘇映雪就站在門口，目光往我們交纏處一掠，隨即垂下眼，聲音穩得像什麼也沒撞見：「金鳳姑娘，班主在前頭找你呢。」

我慢慢抽回手，轉身對門口那個波瀾不驚的人笑：「勞蘇姑娘傳話，這就來。」話還沒落地，手腕忽地教人死死攥住。柳生春的力道緊得我骨節都泛了白，頸邊青筋一跳，啞著嗓子喊我：「金鳳……別走。」這三個字扎得我心頭一顫。她求我？跑了這些年龍套，如今紅了，倒在我跟前露這種嚇壞了的可憐相。可她攥得再緊，眼睛卻不敢往門口看——我猜她是怕，怕那花旦真看見了什麼。

蘇映雪沒應聲，只抬手抖落臂上的帕子，走上前來。她不疾不徐地替柳生春繫領口那粒鬆了的盤扣，擋住了後腰那處紅痕，聲音穩得挑不出一絲褶皺：「師妹，扣子散了，仔細台前人笑。」這聲「師妹」喊得又穩又親，替人繫扣子的手半點不慌。我冷眼看著這出戲，原來她心裡的那個人，連撞見這種場面都能這樣體面地替她遮掩，這份妥帖，我金鳳捧場十年也學不來。

柳生春的手鬆了。她就那麼任師姐替自己繫扣子，垂著眼不敢看她，只低低應了一聲：「曉得了。」

手腕上還留著她攥過的生疼。我那口笑還掛在嘴邊，心裡卻涼得透透的。柳生春，你攔我別走，是捨不得我，還是捨不得那點有人護著的暖？你倆這出戲，一個替你擋，一個乖乖挨，我倒成了多餘的那個。我要的不是你鬆手，我要你當面認一句欠我的——可你連這點不敢看人的怯樣，都是衝著她去的。等哪天你真把那句話吐出來，我金鳳留不留，還真說不準呢。

## 柳生春 的版本

門框那抹熟悉的影一落下，我便曉得要遭。師姐的目光只那樣輕輕一掠，連停頓都不曾有，就從我和金鳳交纏的身子滑過去了。可那聲音越穩、越不當一回事，我心裡越發毛——她若真撞見了什麼，罵我一聲反倒好；她這樣若無其事，倒像是我這見不得光的事，根本不值她多放半點心。金鳳的指尖還撥弄著我後腰那顆痣，那是她頭幾年就摸熟的門道，一按我便得僵。偏偏這會兒這份僵，叫師姐那句「班主找你」釘死在原地，像把我剝光了擺在她跟前。

金鳳那一下不輕不重的按壓，帶著點常人聽不出的炫耀，隨後慢條斯理地抽手轉身。我看著她轉過去的背影，心口猛地一揪。這女人教會我這身子的事，曉得我哪處輕哪處重，卻從來由著性子來去，總篤定我會在她身後望著。我一把攥住她的手腕，攥得骨節泛白，頸邊青筋直跳，啞著嗓子喊「別走」——這話喊的是金鳳，可骨子裡，我更怕的是她就這樣把我留在師姐眼底，丟下這攤子見不得人的難堪讓我獨自去接。

師姐沒看金鳳，反倒走近來。帕子從她臂上抖落的動作，輕得連一絲風都不帶。她替我繫領口那粒鬆了的盤扣，指尖隔著布料將後腰那處紅痕嚴嚴實實擋住。這動作太熟悉了，散了戲多少回，都是她替我理這身行頭。可這一回，她指尖的溫度冷得像在替死人斂衣。她的聲音穩得挑不出半絲褶皺，說「仔細台前人笑」——我聽見的卻是：你這身風流的殼子，裡頭早爛透了，只有我還替你遮著。

我鬆了金鳳的手，任她走，只覺得自己這隻手黏膩又骯髒。師姐替我繫扣子的時候，我垂著眼，死也不敢往上看。我怕一看，她眼裡哪怕只有一丁點嫌惡，我這幾年裝出來的滿不在乎就再也立不住；更怕她眼裡什麼都沒有，那我連在她跟前心虛的資格都沒有。我低低應了句「曉得了」，聲音連自己都聽不出是喪氣還是認命。金鳳走了，扣子繫嚴實了，可我覺得自己比那處露著的紅痕還要赤裸。
