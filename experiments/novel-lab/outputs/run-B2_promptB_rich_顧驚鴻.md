# Run B2 ── Prompt B（重設計）× rich 材料 · 顧驚鴻 POV（同一事件，另一人）

> 用來驗「角色版各自成書」：**同一樁事**，顧驚鴻版必須揭他自己的私帳、與柳生春版互補不重複。

---

我以為這一回考的是功夫。

八年了，許仙是我的。不是誰賞的，是我一槍一槍掃出來的。孟雲屏說許仙要挑個配得上的那夜，我沒往心裡去——這班子裡還有誰比我更配？我練了一夜的〈水鬥〉把子，只等今日台上見真章。

她沒比把子功。她點了現燈，說：「誰先別過臉，誰就不必唱了。」

白光躥起來的那一刻，我別了眼。

我這輩子在台上見過刀山火海，我會怕一道假光？我別眼，不是怕白蛇。是那一瞬我沒去看台上的白光——我去看了台口的她。八年了，我在台上托過她百次，水袖翻過來我接得住，她翻下高台我穩得住。我只想在這一眼裡確認一件事：她到底要的是我顧驚鴻，還是要的是這齣能紅遍上海的《白蛇傳》。

我看見了答案。她的眼睛沒在我身上。她在看那個沒別過臉的後生。

就這一眼，我輸了。

我把槍橫過來，擱在箱上。柳生春接過了那張戲折，手抖得像頭一回上台的雛兒。我沒看他。我要是看他，怕自己臉上掛不住——倒不是恨他，這後生眼睛是真沒別，這一點他配。我恨的是我自己：練了八年功夫的人，臨了輸在一個「我先去看了她、沒去看戲」的念頭上。武生的眼睛該先看威脅、先看戲、先看台，我倒先看了一個人。這毛病，我藏了八年，今日當著全班露了底。

散場後我一個人留下掃台。槍掃地的聲音空落落的。許仙我讓了，這沒什麼——讓給配得上的人，是規矩。可那道我藏了八年的念頭，今夜被那盞現燈照了出來，往後每回看她在台上翻水袖，我都得想起：我曾經為了看她一眼，輸掉了我自己的戲。

這筆帳，比讓一個許仙難還得多。
