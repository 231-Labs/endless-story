# Run E ── 日常 01 · 溫情回 · 柳生春 POV（Sequel 模板，非競爭）

> 接事件 03 走向乙之後。沒有事件、沒有資源易手。驗「安靜的戲怎麼不空」。
> deltaType = the-unsaid：那件一直繞開的事,第一次被擺上桌,又收住。

---

散戲後人都走空了。妝閣只剩一盞燈,師姐還沒卸裝。唐桂蘭今晚回鄉下,卸頭面、收水袖,平日是她的活,今晚沒人。

「我來。」我說。

師姐「嗯」了一聲,在妝凳上坐直了些。我先卸頭面。點翠的鳳釵一支支取下來,擱進絨盒,釵腳上還沾著她的鬢油,溫的。她今天唱了一整場《遊湖》,跟江聞鶴對的戲——錄音間定下的那一對,要先在台上磨合。我取釵的手沒停,也沒問今天磨得怎麼樣。她也沒說。

水袖鬆了一條。是右邊那條,綁帶滑了結。我蹲下去替她重綁。這條水袖我繫過幾百回了,閉著眼都繫得齊。她低頭看我繫,妝閣靜得能聽見綢子過手的聲音。

「明兒起,」她忽然開口,又頓住,「江老闆的水袖,是他自己管,還是……」

「衣箱管。」我說,「男班的規矩,跟咱們不一樣。」

「哦。」她應了一聲。我們都知道她問的不是這個。她問的是:明兒起進錄音間替她繫這條水袖的,還是不是我。可這話繞了一圈,落在「衣箱管不管」上,輕輕放下了。

我把那個滑開的結重新繫好,繫得比平日緊一分。繫完了,我沒鬆手。就按著那條水袖,按了一下。綢子底下是她的手腕,跳著很輕的脈。

她沒抽回手。

「生春,」她說,聲音低下去,「要是有一天……」

燈花爆了一下。她沒往下說。我也沒抬頭。「有一天」後頭那半句,是「我不跟你搭了」,還是「你不跟我搭了」,還是別的什麼,她沒說,我沒問。可這三個字一旦出了口,就像妝閣的門被推開了一條縫——那件我們繞了三天的事,頭一回擺到了兩個人中間的妝檯上。沒人去碰它。可它在那兒了。

我終於鬆開手,站起來,替她把那盒鳳釵蓋上。「夜深了,」我說,「明兒還有戲。」

她「嗯」了一聲,起身,水袖垂下來,齊整得像沒人動過。走到門口,她回頭看了我一眼——那一眼裡有句話,還是沒說。

我吹了燈。黑下來的那一瞬我忽然想:替她繫水袖的時候,我用不著爭、用不著贏、也用不著這身男裝——那是我唯一不必扮誰、就覺得自己是真的的時候。這樣的時候,還剩幾回,我數不清了。
