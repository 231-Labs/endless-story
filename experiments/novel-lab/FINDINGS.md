# 旁支解耦實驗 · 結論（實驗1 自由行動 / 實驗2 記憶條數）

> 這兩個實驗各自獨立於主迴圈（reuse `sim/llm` + `sim/cast`），用來回答兩個方法問題：
> 1. 不用發牌限制角色操作，純讓 LLM 自由決定行動，敘事推不推得動？
> 2. 開場記憶更多更豐富，劇情複雜度與人物厚度會不會提升？幾條開始明顯？
>
> 跑法見 `README.md`。本檔記**結論**；落地對應見 `ALIGNMENT.md`（新增 A7 / D6）。

## 實驗 1 · 自由行動 vs 發牌（`free-action/`）

**做法**：拿掉手牌與固定姿態，每個角色每拍「做任何事」（cheap LLM 自由產生一個具體行動），
再由一個 LLM 導演讀完所有人行動 → 裁決客觀結果、更新現況、丟懸念、自評有沒有推進。

**結論：能推故事，但會丟掉三樣靠機制守住的東西。**

| 面向 | 自由行動 | 發牌＋決定性判決（sim/） |
|---|---|---|
| 敘事推進 | ✅ 4/4 拍都 `advanced`，導演判得也算公正 | ✅ 同樣會推 |
| 行動豐富度／戲味 | ✅ **更豐富**——角色會結盟、佈局、撂狠話，不被 6 種姿態框住 | ⬜ 受牌型限制 |
| 決定性／守恆 | ❌ 裁決可漂移、可能被「文筆好」帶偏，無法保證稀缺標的守恆 | ✅ 計分決定性、capacity 守恆 |
| 可上鏈的狀態 | ❌ 結果是散文，沒有可錨定的 scarce-resource 持有權變更 | ✅ verdict → 標的持有權，可上鏈 |
| 強制收束 | ❌ **會偏題**——本來爭「誰灌唱片」，自由演著演著漂成一場關係對峙，標的沒結算 | ✅ spine 逼著在既定標的上見分曉 |

**取捨判斷：採混合制（hybrid）。**
- **骨架用發牌＋資源判決**：負責收束（逼角色在既定標的上見真章）、守恆（capacity-1 不每拍翻盤）、上鏈（持有權變更是可錨定狀態）。
- **血肉用自由行動文字**：在判決定了「誰贏什麼」之後，容許角色用一句自由的、人設化的行動文字去**演**這個結果（結盟/佈局/撂狠話的質地），餵給 POV 當素材。
- 一句話：**判決定走向，自由文字定戲味**——不是二選一。

**附帶修掉的生成 bug**：自由行動版 POV 曾把「再做一版，更貼合要求：」連同草稿一起吐進正文。
已在 `free-action/run.mjs` 的 `povSystem` 加守門：「只輸出最終一版正文」。這條同樣該進真實 POV prompt。

## 實驗 2 · 初始記憶條數消融（`memory-depth/`）

**做法**：固定同一角色（柳生春）、同一場戲（散戲後替蘇映雪繫水袖，愛而不得），
餵入「前 N 條」記憶（pool 依重要性由深到淺排），各生一篇 POV，再由評審 LLM 打厚度/複雜度分、指出明顯躍升的檔位。

記憶池的排序刻意分三層：
- **1–5 核心**：傷口／情／身體秘密（男裝才是真正的我、倒倉的嗓、戲裡才能牽手、怕被說破、藏著的肺氣）
- **6–10 關係與世界**：師姐妹搭檔、班主在二樓算唱片、衣箱看得穿她、上海報館唱片行、江聞鶴來搶小生位
- **11–15 質地與癖性**：戲箱刻「春」字、不扔的舊褶子、磨白邊的方巾、厚底靴壓住虛軟、學戲原為口飯

**結論：厚度與複雜度在不同檔位分兩段躍升；配方比條數重要。**

- **N≈3 → 厚度躍升**：拿到核心傷口與情，POV 從「寫眼前繫袖的動作」變成「動作有來歷」——
  每個眼神、每次遲疑都能回扣過去。**心一進來，人就立起來。**
- **N≈10 → 複雜度躍升**：關係與世界（搭檔、班主、勁敵江聞鶴、上海碼頭）一進來，
  這段私情**接上了外部利害**——愛而不得不再是真空裡的情緒，而是「被行當/搶位/碼頭規矩夾著」的兩難。
- **N≈15 → 飽和**：質地癖性（刻字、舊褶子）是上好的點綴，能讓文字更有體溫，
  但**邊際效益明顯遞減**，沒有再帶來結構性的厚度或複雜度。

**取捨判斷：開場記憶不是越多越好，而要按配方湊齊四類。**
最划算的不是「給 15 條」，而是確保前幾條就覆蓋：
1. **傷口（wound）**——人物的核心痛/缺，撐起厚度；
2. **情／關係（relationship）**——他在乎誰、跟誰綁定；
3. **世界利害（world-stakes）**——他被什麼外部結構夾著（行當、搶位、碼頭、契約），撐起複雜度；
4. **質地癖性（texture）**——體溫與可信度的點綴，少量即可。

**創世記憶 prompt 應強制這四類各至少一條**，而不是放任產一堆同質的背景。
覆蓋四類的 6–8 條，勝過同質的 15 條。

## 兩個實驗合起來對主迴圈的指示

1. **生成側（記憶）**：創世種記憶時按 wound/relationship/world-stakes/texture 四類配方，
   保證每個角色開局就「心＋關係＋外部利害」齊備——這是厚度與複雜度的地基。（→ `ALIGNMENT.md` A7）
2. **機制側（行動）**：維持發牌＋決定性判決當骨架（收束/守恆/上鏈），
   在判決之後加一層「自由行動文字」當血肉餵 POV，取自由演的戲味而不丟守恆。（→ `ALIGNMENT.md` D6）
3. **生成守門**：POV/餘波/合本 prompt 一律加「只輸出最終一版正文」守門，杜絕草稿/修改說明洩漏。（併入 B1/B2）
