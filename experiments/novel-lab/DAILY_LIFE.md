# 非事件日常戲 · 溫情戲 · 鋪陳戲怎麼寫（研究 + 材料模板）

> 你問的第二個大問題：競爭事件之外的**感情戲、溫情戲、日常鋪陳**怎麼辦？
> 我前面的 scene/sequel 框架是**競爭驅動**的（賭注/轉折/代價），但小說不能整本都是打擂台——
> 那會換一種單調。本檔解決「安靜的戲怎麼不變回『一段觀察』」。

---

## 一、先認清：你的系統現在只有「Scene」沒有「Sequel」

小說的兩種基本單元（Dwight Swain，被公認的中層結構）：

| | **Scene（場景·動）** | **Sequel（餘波·靜）** |
|---|---|---|
| 結構 | 目標 → 衝突 → **災難/轉折** | 反應 → 兩難 → **決定** |
| 性質 | 外部、競爭、推進事件 | 內部、消化、推進**人** |
| 你的系統 | event/storylet（雖然壞，但有） | **完全沒有** |
| 對應你的痛點 | 「競爭戲」 | 「**日常戲/溫情戲/鋪陳**」 |

**關鍵認知**：日常戲不是「沒有結構的戲」，它是 **Sequel**——一個有自己結構的單元。
好小說是 Scene 和 Sequel **交替**的（全是 Scene 會累死讀者、全是 Sequel 沒有脊椎）。
你現在的問題是：只生 Scene（還是壞的），Sequel 一個都沒生 → 所以「日常」要嘛沒有、
要嘛被硬塞進競爭框架、要嘛就退化成你最初抱怨的那種「一段觀察」。

來源：[Swain scene/sequel](https://www.septembercfawkes.com/2021/10/sequel-structure-according-to-swain.html) ·
[scenes vs sequels 平衡](https://writershelpingwriters.net/2022/03/scenes-vs-sequels-whats-a-good-balance/)

## 二、安靜的戲靠什麼不空——「狀態 delta」四選一（鐵則）

競爭戲的 delta 是**資源易手**（誰贏了名額）。日常戲沒有資源易手，但**仍然必須改變某樣東西**，
否則就是你最初抱怨的「可有可無」。安靜的戲，每一場至少要移動下面**一項**：

1. **親密度**（intimacy）：兩人更近 or 更遠了一步（一個動作跨過了某條線，或退回某條線）
2. **理解**（understanding）：一個誤讀產生了，或一個一直看不清的人忽然被看清了
3. **未說出口的事**（the unsaid）：某件事**第一次變得可以說**了，或**從此再也不能說**了
4. **一個私下的決定**（decision）：角色因為這一刻，悄悄決定了一件之後會結果的事（＝Sequel 的「決定」）

> **判準**：寫完一場日常戲，問「這四項裡，哪一項在開頭和結尾不一樣了？」
> 答得出＝戲；答不出＝又寫成觀察了。**這就是日常戲的「結局」**——不是誰贏，是某樣關係/認知變了。

來源：[安靜場景也要推進劇情或加深人物](https://www.inkitt.com/writersblog/a-fun-guide-to-writing-powerful-calm-scenes-in-your-story/) ·
[潛台詞＝沒說出口的比說出口的重要](https://staceycarroll.org/intermediate-author-writing-advice/whispers-between-the-lines-how-subtext-fuels-romantic-tension)

## 三、溫情戲的引擎＝「共同的瑣事 + 潛台詞」（不是直球告白）

成功的溫情戲幾乎都長一個樣：**兩個人一起做一件具體的瑣事**（繫水袖、對詞、收戲箱、分一碗餛飩），
**真正的對話在針線/動作底下進行**。情感從不直說，靠：
- 避開某個話題（兩人都不提那件事）
- 說一件事、意思是另一件事
- 用一個手上的小動作，替沒說出口的話收尾
- **一次小小的冒險**：有人多伸了半寸手、多留了一句話——而對方接不接，就是這場戲的「轉折」

**梨園的天然道具庫**（你的世界自帶，這是優勢）：水袖、頭面、靠旗、戲箱、嗓子、對詞、胡琴一弓、
鼓點一停、後台窄廊、二樓包廂、一盞沒吹的燈。每一樣都能當「一起做的瑣事」+「潛台詞的載體」。

來源：[溫情藏在摺衣、做飯這類瑣事裡](https://dupple.com/blog/how-to-write-intimate-scenes-examples) ·
[誰敢多冒一點險＝張力來源](https://www.shyeditor.com/blog/post/how-to-write-love-scene)

## 四、四種非競爭章回（給你的章回分類補上另一半）

事件回（競爭）之外，補這四種。每種都有自己的「結局＝delta」：

| 章回種類 | 是什麼 | delta 落在哪 | 範例（春雪社） |
|---|---|---|---|
| **餘波回** | 一樁事件結算後，角色獨自/兩人消化代價，做出一個私下決定 | 決定 | 江聞鶴輸了灌錄權那夜，獨自吊嗓，決定留下來 |
| **溫情回** | 兩人一件瑣事 + 潛台詞，親密度移動一步 | 親密度 / 未說出口 | 柳生春替蘇映雪繫水袖，誰都沒提江聞鶴的事 |
| **鋪陳回** | 埋一個之後會結果的種子（習慣、物件、承諾） | 未說出口（埋種） | 班主的懷錶第一次被柳生春瞥見，當時不懂 |
| **轉折回** | 沒有外部事件，但一個誤讀/揭露改變了一段關係 | 理解 | 蘇映雪整夜沒睡，被柳生春撞見，從此知道師姐在怕什麼 |

**餘波回特別重要**：你現在的事件「結算完就斷了」，沒人消化後果——所以即使事件有結局，
**情感的後座力沒被寫出來**，這也是「不像小說」的一個原因。每個重要事件後面**接一個餘波回**，
小說感會立刻不一樣（事件給骨，餘波給肉）。

## 五、這在你的自治系統裡材料從哪來（好消息：大半現成）

日常戲的材料**不需要 drama event**，它接的是你**已經在跑、但只拿來算經濟/關係、沒拿來寫小說**的東西：

| 日常戲材料 | 系統現成來源 |
|---|---|
| 兩人同場互動 | **SOCIAL phase**（observe/talk/idle）已每 tick 在跑 |
| 親密度 delta | **relationship memory** 的變化（speaker/target observation 已在寫） |
| 潛台詞的「真心話」 | 角色的 **`secret` 欄位**（創世已寫好） + reflection |
| 溫情的「給予」 | **GIVE/ASK phase**（接濟）本身就是溫情 beat，現在只當經濟事件 |
| 餘波的「決定」 | **PLAN phase** 的 plan 更新（角色因剛發生的事改了打算）＝現成的「決定」 |

**觸發時機**（類比劇照的「越張力門檻才截」）：
- **餘波回**：某事件本 tick 結算 → 下 1-2 tick 自動為主要輸/贏家生一篇餘波。
- **溫情回**：SOCIAL phase 某對角色的 relationship memory **跨過親密度 delta 門檻**（從 neutral→ally、
  或一次 talk 觸到對方 secret 相關詞）→ 生一篇溫情回。
- **鋪陳回**：低頻（每 N tick 或 showrunner 指定），在事件稀疏期填節奏。

→ 意味著：**日常回不是另寫一套引擎，是把 SOCIAL/GIVE/PLAN 的輸出，用「Sequel 模板」織成章回**。

## 六、日常戲材料模板（Sequel 版，對照事件的 scene 模板）

事件回用 `beatStructure{stakes,turn,outcome,cost}`；日常回改用 `sequelStructure`：

```
sequelStructure {
  occasion:   兩人/一人在做的那件具體瑣事（繫水袖、對詞、收箱、吊嗓）
  undercurrent: 這場戲底下真正在進行的那件沒說出口的事
  risk:       誰多冒了半寸險（多伸的手、多留的一句、多看的一眼）
  deltaType:  intimacy | understanding | the-unsaid | decision   ← 四選一，必填
  delta:      開頭→結尾，那一項具體怎麼變了
}
privateLedger: 這個角色的 secret 在這場戲裡被掀開的「一角」（不全揭）
```

可運行的範例見 `materials/daily-01-rich.md`，生成樣本見 `outputs/run-E_溫情_柳生春.md`。

## 六、五 · 溫情/關係 beat 的存取模型（私密戲＝付費深度）

一場像「柳蘇繫水袖」這種**沒有公開事件、只在兩人之間**的戲，在內容模型裡的歸屬（對齊 CONTENT_PIPELINE §1 三條軸）：

| 問題 | 答案 | 理由 |
|---|---|---|
| 是 BudgetEvent（稀缺資源爭奪）嗎？ | **不是** | 沒有標的易手；它是 SOCIAL phase 長出的**關係 beat**（Sequel），不是 spine 事件 |
| 會進公開**公報**嗎？ | **不會** | 公報＝導演客觀視角、報館頭條；這是後台無人時的私密一刻，導演的鏡頭根本不在場、也不該在場 |
| 誰看得到？ | **訂閱該角色的人，看該角色的第一人稱 POV** | POV 章回 gated（owner+訂閱者）。訂柳生春→看柳的版本；訂蘇映雪→看蘇的版本 |
| 兩人視角會織成公開**合本**嗎？ | **不**（與競爭事件不同） | 競爭合本是公開漏斗、刻意藏私帳；但感情戲的賣點**就是**那份私帳——公開了就毀了。它的「合本」應是 gated 的雙視角並陳，或乾脆不織，留兩條獨立 POV |

**這反而是強設計**：柳蘇之間「都動了心、都沒說」的戲劇性反諷，**只有同時訂閱兩人的讀者才拼得出全貌**——
愛而不得的「不得」，正好對應內容的「不公開」。私密的情＝付費的深度，機制與情感同構。

→ 系統觸發：SOCIAL phase 某對角色 relationship delta 過門檻（或一次 talk 觸到對方 secret 相關）→
生成**雙方各一篇第一人稱 gated POV**（溫情回），**不**發公報、**不**開 BudgetEvent。

## 七、落地建議（補進主報告 §五）

6. **加 Sequel 章回類型**：在 content pipeline 補「餘波/溫情/鋪陳/轉折」四型 chapter kind，
   材料用 `sequelStructure`，引擎接 SOCIAL/GIVE/PLAN 輸出，不新開 LLM 決策。
7. **每個事件後掛一個餘波回**：最低成本、最高小說感回報——事件給骨、餘波給肉。
8. **showrunner 管節奏**：書級大綱除了排事件，也要**交替排日常**（避免全競爭的新單調）。
   經驗值可參考 scenes/sequels 大致 1:1 到 2:1，依緊張弧調整。
