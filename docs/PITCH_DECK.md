## 1 — 封面

- **標題**：Endless Story
- **一句話**：一個自己會運轉的故事世界——你用「影響」而非「操控」去共創它。
- 副標：角色會記得，世界會生長 · 角色不是 JPG，是活著的記憶資產
- 底部：Sui Overflow 2026 · Walrus 賽道 · `⟨團隊名 / logo⟩`
- 視覺：一張最好的角色立繪 or 3D 藏閣截圖（不要塞字）。

## 2 — 問題

- **takeaway**：現在的「AI 角色」都是傀儡——你打字、它回話，沒有自己的命。
- 要點：① AI 同伴／聊天角色＝你的提線木偶，停止互動就什麼都不剩。② NFT 角色＝靜止 JPG，買完就死。③ 沒有一個地方讓角色**自己活著、會老會死、彼此有恩怨**，並把這些長出來的故事變成可收藏、可變現的 IP。
- 講稿：「我們不缺會聊天的 AI，缺的是**會自己過日子**的角色。」

## 3 — 解法（定位三角）

- **takeaway**：站在抽卡遊戲 × IP 收藏 × 影視連載的交點，每邊一個反轉。
- 三欄表（用 `PRODUCT_POSITIONING.md §1`）：
  - 遊戲 → 但**不能操控角色**
  - IP 收藏 → 但**資產是活的、會死**
  - 影視連載 → 但**沒有編劇在寫**
- 講稿收尾接下一頁的公理。

## 4 — 核心：不可操控公理

- **takeaway**：任何人都無法直接替角色做決定——這是整個產品的地基，也是世界能自轉的前提。
- 三角圖：World owner（搭舞台）/ Saga owner（導演 agent 只推事件・調環境）/ Character owner（只能注入夢境・解鎖記憶）。中間：**Character agent 自決**。
- 標 ✅ 已實現（`NARRATIVE_AGENTS.md`：事件客觀、敘事主觀；接濟給/受皆角色自決）。
- 講稿：「別處的 AI 角色是你的傀儡；這裡的角色有自己的命。你是恩主與造夢者，不是操作者。」

## 5 — DEMO（live 或 90 秒剪輯）

- **takeaway**：看它真的在跑——這不是 mockup。
- 嵌 demo 精華（抽卡鑄角 → 自治 tick 產章回 → 手卷／公報）。
- 角標常駐：**✅ 全部鏈上＋runner 實跑**。
- 這是全場最重要的一頁，留足時間。

## 6 — 它怎麼運轉（自治迴圈）

- **takeaway**：一鍵 tick，角色自己規劃、移動、社交、出牌、寫下第一人稱章回。
- 流程條：PLAN → MOVE → DRAMA → SOCIAL → ASK → GIVE → BOND → SETTLE → ACT → POV → SLEEP → GAZETTE。
- 標 ✅ 已實現（runner v1，world-loop 跑通）。
- 一句話：角色的記憶（MemWal/Walrus/SEAL 加密）餵回每次決策——**它記得自己是誰**。

## 7 — 為什麼世界能「自己活」（動能引擎）

- **takeaway**：死亡不是終點，是讓世界永遠長出新故事的引擎。
- 三條：① 角色雙軌死亡 → 釋放席位 → 後輩搶（✅ 經濟已驗證 H2 無永生 / H3 世代交替穩態）。② 導演隨生態成熟**逐漸退場 → 最後只當說書人**（🛣️ roadmap）。③ Saga 靠**易主**延續，不隨主理人陪葬（🛣️ roadmap）。
- 講稿：「有真正的時間與後果，所以它永遠在新陳代謝。」

## 8 — 收藏的兌現：死亡與傳奇

- **takeaway**：角色死後 NFT 與記憶仍在；有人持續付儲存費維持，它就成了傳奇。
- 對比：**淡出**（沒人續費 → Walrus 儲存到期 → 只剩鏈上墓碑）vs **傳奇**（saga/owner 續費 → 完整記憶永存、可被後世引用）。
- 標：NFT＋記憶死後留存 ✅ 已是事實；「死後續費 → 傳奇狀態」接線 🛣️ roadmap。
- **這頁是 Walrus 賽道的核心論述**：永久儲存＝讓 IP 真正不死，傳奇是「有人願意為它持續投資」的鏈上證明。

## 9 — 商業模式（創作者旅程 → 金流）

- **takeaway**：開一個 Saga → 招角色 → 產出故事 → 訂閱／售劇照變現 → 分潤給角色主。（春雪社版：開戲班→招角兒→演戲。）
- 金流圖（`CHARACTER_ECONOMY.md §1`）：訂閱者 → Saga 金庫 →（RevenueConfig 拆）owner / Saga 主理人 / 發薪池 → 養角色 → 扣 dailyCost 付真實基建。
- 標：經濟迴圈 ✅ off-chain 影子已跑（發薪→求助→接濟→死亡，學術驗證 H1–H6）；**`economy.move` 真鏈上 Balance 🟡 合約已 redeploy 上鏈、待端到端驗證**（驗過即翻 ✅）；訂閱分潤 claim 🛣️ gate-after。
- 講稿安全版：「經濟生命週期已經在跑；它的鏈上結算合約剛部署上線，我們正在收尾驗證。」（**不要說「鏈上轉帳已上線」直到驗證通過**。）

## 10 — 為什麼是 Sui + Walrus（技術護城河）

- **takeaway**：這個產品**只有**在永久儲存 + 物件模型上才成立。
- 要點：① 角色＝Sui owned object（持有即 IP，死後不滅）。② 記憶＝Walrus append-only + SEAL 加密（cap-enforced 解密，owner 才解得開全記憶）。③ 記憶租金是 Walrus epoch 租期 → 經濟的「熵」有真實成本基礎 → 死亡與傳奇都不是假的。④ MemWal SDK 整合（賽道要求）。
- 標 ✅ 全部已落地（合約 120/120 test、testnet deploy、自架 relayer+aggregator）。

## 11 — 進度 vs 路線圖（誠實分界）

- **takeaway**：✅ 今天就能跑 · 🟡 剛部署正在收尾驗證 · 🛣️ 清楚標示的願景。
- 直接放 `PRODUCT_POSITIONING.md §0.5` 的三張表（✅ 已實現 / 🟡 已部署待驗證 / 🛣️ roadmap）。
- **🟡 那層其實是加分項**：合約已上鏈代表「不是 PPT，是真的部署了」，誠實標待驗證反而更可信——比假裝已完成更得分。
- Phase 3 收在**影視化**：把最好的 emergent 故事輸出成長片素材。
- 講稿：「我們不誇大。✅ 是一個已經在自轉的世界；🟡 是剛上鏈、正在收尾的鏈上結算；🛣️ 是讓它自轉得更久、更會生錢的方向。」

## 12 — 願景 / Ask / 收尾

- **takeaway**：一個不需要人持續在場、可被買賣的自轉 IP 世界，終點是螢幕。
- 回扣一句話 + 團隊 + 聯絡 + `⟨ask：找什麼——資金/夥伴/早期 saga 主⟩`。
- 結尾畫面：一條從「抽到一個角色」到「它成為傳奇 / 被影視化」的時間線。
