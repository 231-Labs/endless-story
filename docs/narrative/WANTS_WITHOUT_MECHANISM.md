# 心願無門 —— 角色想做、卻還沒有物理機制的事

> 一份活的清單：世界能讓角色「生出」某個願，卻還沒給他「做這件事」的動作或地點。
> 每補上一個機制，就把一條心願從「只能靠場景散文碰運氣」變成「有專屬途徑、可靠地發生」。
> 源出 [`ENGINE_CORE`](./ENGINE_CORE.md) 的機制盤點；隨接入進度更新。

## 角色現在真正能做的事（動作面）

一個願要能「落地」，得靠下列其中一條途徑把它推到 `judgeWantResolved` 認可：

| 途徑 | 由誰驅動 | 能解什麼願 |
|---|---|---|
| 移動 `decideMove` | 角色自選（私宅 welcome 閘） | 去某處、赴某人所在 |
| 場景言行 `actBeat` | 角色逐拍 | 靠同場、私下協商推進心事 |
| 親密協商 `intimacy`（advance/accept/decline） | 兩人私下 | 情/愛層的踰越與成雙 |
| 物件效果 `objectEffects`（move/hand/state） | 角色在場 | 把隨身物交給同場的人 |
| 銀錢命令 `purchase`／`pay`／`contract_*` | 角色在場 | 買目錄物、給錢、簽/拒/還價契約 |
| 開放行動 `ActionKind`（propose/join/compose/rehearse） | 角色一拍 | 提戲、入夥、寫本、排戲 |

**注意**：`seek_person`／`perform`／`personal` 這三個開放行動標籤，目前在 tick 裡是 **no-op**——角色會「說」他要去找某人，但機制上什麼都不發生。

## 想做、卻沒有途徑的願

按「離北極星（自主、耐看、真實、感情不被工作蓋過）的距離」排序。

### 一、感情／關係（最該補，正在補）

| 心願 | 現況 | 缺什麼 | 進度 |
|---|---|---|---|
| **找人商量／傾訴心事**（夜訪師姐） | 只能當普通同場散文，聽者連「聽到了什麼」都沒被建模 | 一個 confide 媒介：私下二人場景吐露，聽者只記「說出口的版本」，重用既有 `evolveSecret` | 🔨 建置中 (#37) |
| **舊情復燃**（去金鳳處溫存） | 場內親密協商是活的，但「這兩人是舊情人」不持久 → 每次都得重新協商 | 持久 `establishedPairs` + 夜裡對老情人開 `consummate` register | 🔨 建置中 (#35/#36) |
| **送一件她會懂的東西**（買非目錄的花／物） | 只能把「已在隨身」的物交出去，或買目錄裡的固定品項 | 攤販／商鋪當賣家，可買現做／特定物（接 vendor 帳） | 📋 排入 食肆 (#32) |
| **資助／搭救某人** | `pay` 能給錢，但「主動決定要不要救、對方收不收」的自主判斷是眠置的 | 接 `decideAid`／`decideAccept` 自主座席 | 📋 待接 |
| **和解／賠罪** | 只有泛用場景散文，沒有專屬動作 | 一個「示好／賠不是」的動作，帶關係修復語意 | 📋 待議 |

### 二、儀典／信仰（新地點，正在設計）

| 心願 | 現況 | 缺什麼 | 進度 |
|---|---|---|---|
| **求神／許願／對神明說出口的願** | 完全沒有——沒有廟、沒有祈願動作 | 廟／教堂地點 + 祈願動作（把「說出口的願」記成 Prayer）+ 前端願牆收羅 | 🔨 設計中 (#33) |
| **還願／酬神** | 同上，且需先有許願 | 祈願落地後的回訪 | 📋 隨 #33 |
| **悼念／奔喪** | 沒有死亡 → 沒有悼念的觸發 | 需先接壽數/病亡（`stepVitality`），才有可悼之人 | 📋 低優先 |

### 三、世界紋理（暫緩）

| 心願 | 現況 | 缺什麼 | 進度 |
|---|---|---|---|
| **立誓／守諾** | 沒有 vow 追蹤，只有散文 | 一個輕量誓約物件（記下、日後可驗成/背） | 📋 低優先 |
| **報復／傷害對方** | 完全沒有暴力/傷害機制（只有健康耗竭的間接死亡） | 需審慎設計——先不做，避免破壞戲的調性 | ⏸ 暫不做 |
| **過節／慶祝** | 沒有曆法/節氣/節慶系統 | 從零打造 calendar 層 | ⏸ 暫緩 |
| **遠行／離城** | 場景是固定集合，走不出地圖 | 需要「地圖外」的抽象處理 | ⏸ 暫緩 |
| **明確地「去找某人」** | `seek_person` 動作回傳目標卻不生效（no-op） | 讓 seek_person 真的路由 + 跨拍守候（`waitingFor`） | 📋 待接 |

## 讀法

- 🔨 建置中 / 設計中：本輪正在做。
- 📋 待接 / 排入：機制已存在或已規劃，等排期接入。
- ⏸ 暫緩 / 暫不做：刻意留白，等世界更成熟或調性需要時再議。

高產出的缺口集中在 **感情/關係**（傾訴、舊情、贈物、資助）——正是「工作機器別蓋過感情線」這條北極星最直接的著力點。
