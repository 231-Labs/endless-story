# 心願無門 —— 角色想做、卻還沒有物理機制的事

> 一份活的清單：世界能讓角色「生出」某個願，卻還沒給他「做這件事」的動作或地點。
> 每補上一個機制，就把一條心願從「只能靠場景散文碰運氣」變成「有專屬途徑、可靠地發生」。
> 源出 [`ENGINE_CORE`](./ENGINE_CORE.md) 的機制盤點；隨接入進度更新。

## 角色現在真正能做的事（動作面）

一個願要能「落地」，得靠下列其中一條途徑把它推到 `judgeWantResolved` 認可：

| 途徑 | 由誰驅動 | 能解什麼願 |
|---|---|---|
| 移動 `decideMove` | 角色自選（私宅 welcome 閘） | 去某處、赴某人所在 |
| 場景言行 `actBeat` | 角色逐拍 | 靠同場、私下協商推進心事 |
| 親密協商 `intimacy`（advance/accept/decline） | 兩人私下 | 情/愛層的踰越與成雙 |
| 物件效果 `objectEffects`（move/hand/state） | 角色在場 | 把隨身物交給同場的人 |
| 銀錢命令 `purchase`／`pay`／`contract_*` | 角色在場 | 買目錄物、給錢、簽/拒/還價契約 |
| 開放行動 `ActionKind`（propose/join/compose/rehearse） | 角色一拍 | 提戲、入夥、寫本、排戲 |

**注意**：開放行動標籤中，`seek_person` 已入機制（#58，`seekRouting` 旗）：宣告去尋某人會記成跨拍的「尋人掛心」（`seeking`），移動時以軟提示路由、同場即了、三日不遇於日結擱下（記成當事人私有一筆）。`perform`／`personal` 仍是 **no-op**，但 tick 現在會逐拍記錄（`action noop: …`），不再靜默吞掉。

## 讀法

- 🔨 建置中 / 設計中：本輪正在做。
- 📋 待接 / 排入：機制已存在或已規劃，等排期接入。
- ⏸ 暫緩 / 暫不做：刻意留白，等世界更成熟或調性需要時再議。

高產出的缺口集中在 **感情/關係**（傾訴、舊情、贈物、資助）——正是「工作機器別蓋過感情線」這條北極星最直接的著力點。
