# 三臂實驗 —— 訂題演出 vs 純湧現的裁決協議

> 一份可獨立執行的實驗手冊：不需要任何對話上下文，照做即可完成資料蒐集、
> 量測與裁決。量測器在 [`scripts/lab-ab-metrics.py`](../../scripts/lab-ab-metrics.py)。

## 要回答的問題

**產品走向**：這個世界是只能「訂好題目讓 LLM 演」，還是能「讓 LLM 完全自己
生活、自己湧現」？正常人經濟壓力大不會因此就沒了感情——如果角色會，
那是命題害的、還是引擎缺路？

## 三臂設計

| 臂 | 季框 | 引擎旗標 | 測什麼 |
|---|---|---|---|
| **A 控制** | `spring-snow-market`（命題=生計） | 舊機制 | 基準線（已測） |
| **B 開放命題** | `spring-snow-open`（命題中性化，機制全同） | 舊機制 | 命題是不是主因 |
| **C 開放＋解鎖** | `spring-snow-open` | 勾：叩門夜訪＋借賒有據＋尋人掛心＋劇本產出 | 引擎解鎖後湧現是否成立 |

跑法一致：seed `spring-snow`、6 拍/日、跑滿 3–5 日、真 LLM（Poe）、
「診斷導出」取 .md。

## Arm A 基準（2026-07-20 實測，GLM-5.2-N，2 日 7 拍）

- 夜間去向：獨居 6 · **登門 0** · 工作/公開 5（登門率 0%）
- 私處二人場景 0 拍次；相許 0；願牆 0
- **心事層 情感:營生 = 15:9（情感佔 62%）**——欲望在，行動 0%
- 敘事質感：同角色動作重演（磕鏟沿 ×4、摸花串 ×3）、數字回聲
  （三十四圓半 ×8、二十七圓六 ×5）

## Arm C 實測（2026-07-21，run `q4sn`，GLM-5.2-N，3 日 15 拍）

> 注意：這卷用的是**命題 seed `spring-snow`（生計）**、非中性化的 open 季框，
> 但四旗全開（叩門夜訪＋借賒有據＋尋人掛心＋劇本產出）。也就是說它同時壓測了
> 「命題在、引擎解鎖」——比純 Arm C 更強的證據：命題還在，只要通路開，感情就湧現。

| 維度 | Arm A 基準 | Arm C（q4sn） |
|---|---|---|
| 夜間登門率 | **0%** | **17%**（4 次真的走進別人私處） |
| 私處二人場景 | 0 | 1（一整場二十拍的床戲） |
| 相許 / 願牆 | 0 / 0 | **1 / 0**（柳安春×金鳳 成了） |
| 情感:營生 | 15:9（願在、行動 0%） | 9:8（情感佔 53%，且**願真落地**） |
| 數字回聲 | 三十四圓半 ×8… | **歸零** |

機制真的在被角色調用（引擎日誌實錄）：`尋人` 一路宣告→路由→同場即了
（白韻秋/沈雪笙/江聞鶴 皆「尋著了柳安春」）；`邀約` 響了（白韻秋向柳安春遞話
「今夜可來白公館繡樓」）；`門路` 被耗（蘇映雪用掉一次後台小廂房的門路）；整條
情感鏈完整跑通：柳安春 `尋` 金鳳 → 持常鑰進她私寓 → 入夜二人私處 → `相許`。

**戲本身**：一場從六年疏離、除夕的債、「那幾年是真的嗎」逼問推到床笫的長戲，
把搬進引擎的經濟／機制詞彙代謝成情慾語言（還債→「我是回來澆水的」；叩門→
「舌尖在唇縫抵一下就收回，像叩門」…下拍「這回不是叩門——是進去的」；晚香玉養了
六年＝等她回來六年）。雙 POV 心下各自成立。

## 量測

```bash
python3 scripts/lab-ab-metrics.py armA.md armB.md   # 兩臂對照
python3 scripts/lab-ab-metrics.py armC.md            # 單臂
```

輸出兩組維度：
- **感情行動**：夜間登門率、私處二人場景、相許/願牆、情感詞密度、episode✓
- **敘事質感**：重複意象率（同角色 ≥3 拍重演同一動作片語）、數字回聲
  （同一銀錢數字全卷 ≥4 次覆誦）——#171 身段換樣戒律的療效指標

## 裁決樹

1. **B 登門率↑、私處二人↑** ⇒ 命題是主因 → 產品可走「開放湧現」，
   季框別寫成命題作文即可。
2. **B 仍≈0、C 顯著↑** ⇒ 引擎死結是主因 → 「純湧現」成立但需要
   世情動詞層（叩門/邀約/借賒），開放世界必配引擎解鎖。
3. **B、C 皆≈0** ⇒ 湧現不足恃 → 走「訂題演出」：重寫季框戲劇脊椎
   （柳-蘇-金鳳三角＋沈雪笙舊傷做成會升溫、會逼攤牌的主線，經濟為背景）。
4. **敘事質感**：C 的重複意象/數字回聲相對 A 應下降；未降 ⇒ 文筆二階
   （把角色「近拍已用意象」動態餵進 beat prompt，不只靜態戒律）。

## 裁決（2026-07-21，依 Arm C q4sn）

> **落第 2 支——引擎死結是主因。** q4sn 用的是命題 seed（生計），卻在四旗全開後
> 長出滿滿感情戲（登門 0→17%、相許 0→1、床戲 0→一整場）。所以 Arm A 的「感情戲零」
> 不是命題害的，是引擎缺路（估門、無邀約、seek 是 no-op）。
>
> **產品走向**：不必把季框寫成命題作文，開放湧現可行——**前提是世情動詞層在位**
> （尋人／邀約／叩門／借賒，皆已搬入 #56–#59、#166–#172）。
>
> **敘事質感（第 4 支）觸發**：數字回聲已歸零，但重複意象**未降反顯**——GLM 在
> 長床戲裡逐拍複讀自己的身體落點（金鳳「空著的那隻手」16 拍佔 5、「聲音從喉嚨底
> 勻出來」多拍；柳安春「著的那隻手」佔 7）。關鍵：此病灶是「同角色、整場密集」，
> **任何混說者的 5 拍窗都抓不到**。→ 文筆二階已接（#179）：窗口＝該角色本場自己
> 的拍，`recurringImagery` 抽反覆 5-gram 指名餵回 beat prompt。療效待下一卷驗。
