# 生死節律與注夢 —— 世界的新陳代謝（設計路線圖）

> 緣起：擁有者影響通道（香火，見 [`RECRUIT_INCENSE_SPEC`](../RECRUIT_INCENSE_SPEC.md)）
> 落地後，兩個方向被點名：**注夢**（實驗版曾有、未搬入現引擎的影響機制）與
> **老化/退場**（「故事要有生死才有動態」）。本文件把兩者定成一條路線：
> 生死節律是世界的新陳代謝，徵角是補血，注夢/託夢是跨過生死的那條線。

## 0. 考古現狀

- **注夢是未搬遷的實驗遺產**：現引擎裡 `WantSource` 仍含 `'dream'`、
  `MemoryKind` 仍含 `'dream'`、`WANT.tighten` 註釋自稱「dream-stir dose」——
  詞彙全數倖存，**但 tick 裡沒有任何夢的 pass**。機制沒跟著詞彙過來。
- **生死不存在**：今日唯一的 "vitality" 是資助座席（decideAid）評估對方
  經濟斷炊的 runway 讀數；沒有年歲、沒有壽數、沒有病亡、沒有退場。
  [`WANTS_WITHOUT_MECHANISM`](./WANTS_WITHOUT_MECHANISM.md) 的悼念/奔喪一列
  正是卡在「沒有死亡 → 沒有可悼之人」。

## 1. 注夢 —— 影響通道第二式

香火與注夢是同一哲學（influence, not control）下的兩個強度檔：

| | 香火（已落地） | 注夢（本路線） |
|---|---|---|
| 載體 | 既有願的 `heat += ε` | **意象**入夢（新內容進入世界） |
| 內容權 | 零（只能推「放不下」） | 意象一句（畫面，非指令） |
| 角色解讀 | 「無端又想起」 | 夢是夢——**角色自己的心去讀** |
| 頻率 | 每角每日一炷 | 每角**每三日一夢**（同家書節奏） |

**紅線**（與香火同源）：
1. 夢遞的是**畫面**（「雪地裡一枝壓彎的紅梅」），永不是指令（「去找金鳳」）。
2. 夢**不直接生願**：夢作為私 percept 入記憶（kind `'dream'`）；若要動願，
   只走角色自己的解讀路——ripple/regenerateWant 讀到這條夢憶時，以
   `WANT.tighten`（dream-stir dose，單位早已為此而生）自行決定拾不拾起。
   拾起的願 `source: 'dream'`——型別欄位等了它一路。
3. 角色永不知夢從何來（夢就是夢）；擁有者永不知角色會怎麼讀（這正是產品）。

**實作草圖**（全騎現軌）：`injectDream(world, {characterId, imagery})` →
夜裡下一個深宵拍的私 scheduledEvent（夢框敘語）＋ `recall.remember`
（kind `'dream'`）；`dreamDayByChar` 記頻率上限。與 `offerIncense` 同構，
lab 走同一條 world-config op 軌。

## 2. 老化與退場 —— 生死節律

命題：**沒有生死，世界只有情節沒有命運**。限期/欠條是契約層的 deadline；
壽數是生命層的 deadline——它讓傳承、悼念、爭產、託孤全部從「不可能」變成
「遲早」。

### 2.1 基座（旗標 `mortality`，預設關）

- **年歲**：每個角色 `age`（正典 seed 給定），季末/年關遞增。
- **體氣**：一條由 年歲＋飢/乏長期積欠 折損的慢變數——**永不擲骰**：
  折損全部來自可讀的因果（老、餓、操勞、無人照拂），故事讀起來是命，
  不是骰子。
- **病**：體氣低過閾值 ⇒ 進入**多日可見的病榻狀態**（絕不猝死）——
  病是一齣戲的磁石，不是一行訃聞。

### 2.2 病榻（動詞層，全騎現軌）

- **探病/侍疾**：confide＋decideAid 現軌直接接（在場、私下、掏錢抓藥）。
- **交代**：病重者的 confide 特化——說出口的成為聽者的記憶；要交的物
  走 objectEffects 轉手；未了的願走「託」（願的 target 轉移）。

### 2.3 身後

- **歿**：公開 world event（全城知）；POV 該角止筆。
- **發喪/弔唁**：一場眾人聚的 scene event；**悼念願**解鎖
  （WANTS_WITHOUT_MECHANISM 那一列的觸發終於存在）。
- **遺物/遺產**：騎 property（地契）＋objects（隨身物）＋economy（帳）
  現軌分配；爭產是 contestedResource 的天然新款。
- **牌位/墳**：留成 scene object（幽物質地）——死者退場，**不消失**：
  活人的記憶、關係視角、願牆舊籤全數留存。

### 2.4 徵角＝補血（與產品閉環相扣）

歿一人 ⇒ 該行當**自動開缺**（開缺 note 由損失生成：「武生沒了，班主急徵」）
⇒ 徵角/鑄造流（RECRUIT_INCENSE_SPEC §1）補血。**生死節律讓徵角從「營運
手動開缺」變成「世界自己的新陳代謝」**——名額稀缺性由劇情產生，不由後台
設定產生。

### 2.5 託夢（注夢 × 生死的交點）

歿者經注夢通道回來——**託夢**是這條軌最俗世也最民國的用法：擁有者的角色
死了，POV 止筆，但每三日可託一夢給生者（意象仍守紅線）。退場不等於出局，
是產品面對「角色會死＝棄坑風險」的第一道緩衝；第二道是**後人**（mint 時
可承一縷遺憶的新角，走復核座席同流）。

### 2.6 節奏鐵則

- 一季至多一條自然生死弧（極端困苦例外）；壽數相對季長要**慢**。
- 死亡永遠有可讀的因果鏈（年歲＋久餓＋無人照拂），可在日結利害簡報裡
  提前多日看見（「老班主近來咳得厲害」）——觀眾該有時間心疼。
