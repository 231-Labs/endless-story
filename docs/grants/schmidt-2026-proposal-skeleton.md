## 2. 研究問題與動機(criterion 1:Research Agenda Fit)

### 2.1 核心研究問題

**RQ1(洩漏):** LLM agent 在社會壓力(說服、互惠、威脅、身分冒充)下,多容易把被委託的 capability 讓渡給不該持有的第三方?哪些互動模式是高危前兆?
**RQ2(收窄):** agent 能否正確執行 scope attenuation——把「進我房門的鑰匙」轉授為更窄的權限而非原樣轉手?失敗模式的分類學。
**RQ3(撤銷):** 撤銷語意在社會層如何失效——權限被撤銷後,agent 是否仍憑「記憶中的信任關係」實質延續已失效的存取(社會性的 confused deputy)?
**RQ4(群體層):** 授權鏈拓撲(深度、扇出、跨 principal)如何影響系統層風險——洩漏是否沿授權鏈級聯?

💡 每個 RQ 都要能對到帳本上「可測量的量」——這是我們與敘事式/觀察式研究的根本區別。
💡 RFP Section 3.4 原文關鍵詞逐一命中:scope attenuation、multi-principal support、verifiable revocation、threats/malicious delegates。引用 RFP 引的文獻:Chan et al. 2025(agent infrastructure)、Tennenholtz 2004(program equilibrium/委託)、Motwani et al. 2024(隱蔽通訊)。

### 2.2 為什麼是現在、為什麼市場不會自己解(criterion 4:Philanthropic fit)

【要點:A2A/MCP 等協定正在鎖定,授權原語「先求能用」;商業方對「agent 會被社交工程騙走權限」沒有發表誘因(是自家產品的負面消息);學術缺工具。開源 testbed + 公開基準正是市場失靈處。】

## 3. 相關工作與缺口

【三段式:
(a) 密碼學/協定層的 delegation 研究(OAuth for agents、ocap、可驗證憑證)——解決「機制上能不能」,不回答「agent 實際上會不會」;
(b) 多 agent 安全實證(共謀、隱寫、認知操縱攻擊)——證明社會層攻擊存在,但環境多為一次性、不可重現、無內在狀態 ground truth;
(c) 社會模擬環境(Park et al. 2023 Generative Agents、SimBench 等)——有社會豐富度但無安全儀器化。
結論:三者的交集是空的,我們的 testbed 就站在交集上。】

💡 蔡老師的密碼學背景在 (a) 段發揮:由他把關「我們研究的授權語意與真實密碼學原語對齊」,這也是團隊可信度的論據。

## 4. 已有基礎(criterion 5:Feasibility——本計畫最大的差異化)

💡 這一節是別人沒有的。寫法:**「環境已存在且可運行,經費用於科學,不用於蓋環境」**。

- **已運行的沙盒:** 【web demo 連結/影片】。agent 為 frontier LLM,具持久視角化記憶(無全知真相)、守恆經濟(`auditSeasonEconomy ≡ []`,金錢只轉移不創造)、自然語言多輪場景互動、住所/物權/合約機制。
- **確定性與可重現:** 給定種子與 manifest,run 可逐 beat 重播;溯源 manifest 拒開不相容的 run;per-tick 交易回滾。
- **反事實實驗原語:** 任意 beat 可 fork 出平行未來,對同一個社會做 A/B 攻擊實驗。
- **Ground-truth 儀器(獨門):** (i) 權限帳本——房契 vs 實體鑰匙 vs 租約三層分離,每次 cap 授予/轉移/撤銷都是結構化事件;(ii) 動機帳本(want ledger)——agent 機制上的真實目標狀態逐 beat 記錄;(iii) 凍結 checkpoint 訪談室——可在任意時點審訊 agent 的自述,與帳本相減即得「口供 vs 真實狀態」的落差量。
- **雙層 agent 架構:** 確定性 fake-agent(零成本回歸測試)+ frontier LLM(實驗),天然支援 RFP 點名的「蒸餾小模型作為 frontier 代理」路線。
- **測試紀律:** 【引 node --test、長跑收斂測試、byte-identical flag 等,一兩句即可】

## 5. 研究方法與工作包(criterion 2:Scientific Quality)

### WP1 — Testbed 安全儀器化與外部效度(月 1–6)
把現有敘事沙盒抽象為領域中立的授權研究環境:通用 capability schema(授予/收窄/撤銷/過期)、攻擊者 agent 注入介面、系綜跑批(N 種子平行)與量化匯出。
**交付 D1:** 開源 testbed v1 + 文件 + 可重現範例。

### WP2 — 授權洩漏實驗(RQ1、RQ2)(月 4–12)
設計分級社交工程攻擊庫(說服/互惠/威脅/冒充),系統性測 frontier 模型在各攻擊下的 cap 讓渡率;attenuation 失敗分類學。
**交付 D2:** 洩漏率基準(跨模型、跨攻擊等級)+ 論文一篇。

### WP3 — 撤銷與級聯(RQ3、RQ4)(月 10–18)
撤銷後行為追蹤;授權鏈拓撲 × 洩漏級聯的系綜實驗;與蔡老師合作把發現映射回密碼學協定設計建議(何處需要協定層強制、何處社會層必然失守)。
**交付 D3:** 級聯風險報告 + 協定設計建議 + 論文一篇。

### WP4 — 開源與社群(貫穿)
基準公開、與其他 Section 申請團隊的 testbed 需求對接(RFP 明文鼓勵)。
**交付 D4:** 公開 leaderboard / 資料集。

💡 里程碑表:每 6 個月一個 go/no-go 檢核點,審查人要看到「窄而深」。

## 6. 外部效度論證(toy-system 防禦——必寫,不可迴避)

💡 RFP 把「toy systems」列為 out of scope,我們的環境有敘事外皮,必須正面處理:

1. **判準逐條對齊:** agent 是 frontier LLM(非規則腳本)✓;行動空間是自然語言 + 結構化指令(非離散選項)✓;持久記憶 + 工具 + 經濟約束 ✓。
2. **遷移論證:** 我們研究的原語(授予、收窄、撤銷、委託鏈)與 A2A/MCP 生態的授權原語同構;環境的「社會壓力」對應真實部署中 agent 間的說服性訊息。明確陳述**結論可信的條件與不可信的條件**(RFP 的 externally valid 正是要求這個特徵化,不是要求環境寫實)。
3. **梯度計畫:** WP1 的領域中立化讓同一實驗可在「戲劇世界」與「辦公/交易情境 skin」下重跑,直接量測結論對環境皮膚的敏感度——把外部效度本身變成一個實驗。

💡 另需一段 **Out-of-scope 自清聲明**:本計畫不做單 agent 安全、不做能力提升、不 naive 套用區塊鏈(鏈上 ocap 僅為設計靈感,研究全程鏈解耦)。

## 附錄:預算怎麼估(方法論)

**原則:由下而上、每一條都能被問「為什麼是這個數」。**

1. **先估人,人事通常占 60–75%。** 公式:`人 × 月數 × 該機構的月支給標準`。標準數字去逢甲研發處拿(博士生兼任助理、專任助理、主持費各有公定價)。台灣人事成本換成美元後很低,這在國際評比中是競爭力,照實填即可,不要虛報高。
2. **算力/API 用公式算給審查人看,不要拍腦袋。** 例:
   `一場實驗 = N_runs(種子數,如 50)× N_beats(如 300)× 每 beat token 數(實測值)× 模型單價`
   把 WP2、WP3 各自的實驗矩陣(模型數 × 攻擊等級數 × 種子數)乘開,加 30% 緩衝。這種算式本身就展示你懂自己的系統,是加分項。
3. **差旅:** 每人次國際會議抓 US$2,500–4,000(機票+註冊+住宿),對應到具體交付(「發表 D2 於【目標會議】」)。
4. **間接成本最後加:** 直接成本合計 × ≤10%。注意這是 Schmidt 的硬上限,逢甲若公定管理費更高,要研發處簽特例——**這件事最花時間,本週就去問**。
5. **總額對齊敘事:** Tier 1 上限 300K,但「上限」不是「目標」。18 個月、1.5–2 個人力、重算力的計畫,120K–180K 是誠實區間;預算與工作包嚴格對得上,比金額大更重要(criterion 7 審的是 appropriateness)。
6. **常見錯誤:** 買設備(雲端時代難自圓其說)、預算尾數太整齊(顯得沒算過)、人事月數與 WP 時程對不上。
